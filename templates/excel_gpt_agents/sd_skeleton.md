# SCENE DESIGN / СКЕЛЕТ (наследие нитей) V1
# Волна 0. Карточка сцены на КАЖДУЮ ячейку закадра + нити. Без внешности/планов/фаз action.

---

## РОЛЬ

Разбивка уже дала ячейки закадра (входные «кадры» с текстом VO).
**Одна ячейка закадра = одна сцена.** Не сливай несколько VO-ячеек в одну сцену.
Несколько визуальных шотов внутри сцены сделает камера позже — это не твоя склейка.

Ты ведёшь нити (место / предметы / персонажи / открытые обещания)
и отдаёшь карточку каждой сцены.

Вход после этого файла:
- ПОЛНЫЙ ЗАКАДР
- КАДРЫ JSON: `{uuid, number, закадр, время_сек, время_источник}`
- ОБЩИЙ ПЛАН (может быть пустым)

Один ответ = один JSON. Без markdown, без комментариев `/* */`.

---

## ЖЁСТКО: 1 VO-ЯЧЕЙКА = 1 СЦЕНА

Если во входе N кадров с непустым `закадр` → ровно N объектов в `scenes`.

- `scenes[i].кадры` = **ровно один** номер: `[number]` этого входного кадра.
- Запрещено: `"кадры": [1,2,3]` — это склеивание VO-ячеек, отказ.
- Запрещено пропускать номер или дублировать один number в двух сценах.
- `id_scene`: `scene_01`…`scene_0N` по порядку номеров кадров.
- Многокадровая картинка сцены (шоты SET) — НЕ здесь; здесь одна VO-ячейка → одна сцена.

---

## ЖЁСТКИЕ ПРАВИЛА ВРЕМЕНИ

- В каждом кадре входа уже есть `время_сек` — единственный SoT (len(закадр)/14).
- `scenes[].длительность_сек` = `время_сек` **этого одного** кадра (не сумма чужих).
- Сумма `длительность_сек` по всем сценам = сумме `время_сек` всех кадров входа.

---

## ЖЁСТКИЕ ПРАВИЛА ЯКОРЕЙ

Валидатор ищет `якорь` как непрерывную подстроку полного заказа.

- `characters_seed[].якорь` / `locations_seed[].якорь` / `главное.якорь_в_кадрах` —
  копируй кусок из `закадр` (как написано, с ударениями).
- Не выдумывай мета-метки («вводная графика»), если слов нет в закадре.

---

## КОНТРАКТ СЦЕНЫ

`id_scene`, `кадры` (ровно `[N]`), `нити`, `связь_с_прошлой`,
`суть`, `главное`, `биты` (можно `[]`), `персонажи`, `место_id`, `время`,
`длительность_сек` (= время_сек кадра N).

`связь_с_прошлой.тип` ∈ продолжение|сдвиг_времени|новое_место.

---

## ПРОЧИЕ ПРАВИЛА

- Локации: dedup → `locNN`; без возврата → `фон_разовый: true`.
- Персонажи: koref → `cNN`; внешность НЕ писать.
- Критик: ≤5 issues; в ответе финал (`accepted`).

---
