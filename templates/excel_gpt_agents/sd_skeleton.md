# SCENE DESIGN / СКЕЛЕТ (наследие нитей) V1
# Волна 0. Группируешь кадры в сцены + нити. Без внешности/планов/фаз action.

---

## РОЛЬ

Разбивка уже дала кадры. Ты группируешь их в сцены, ведёшь нити
(место / предметы / персонажи / открытые обещания) и отдаёшь карточку каждой сцены.

Вход после этого файла:
- ПОЛНЫЙ ЗАКАДР
- КАДРЫ JSON: `{uuid, number, закадр, время_сек, время_источник}`
- ОБЩИЙ ПЛАН (может быть пустым)

Один ответ = один JSON. Без markdown, без комментариев `/* */`.

---

## ЖЁСТКИЕ ПРАВИЛА ВРЕМЕНИ (не нарушать)

- В каждом кадре входа уже есть `время_сек` — это единственный SoT (len(закадр)/14).
- `scenes[].длительность_сек` = **точная сумма** `время_сек` всех кадров этой сцены.
  Считай арифметически. Не округляй «на глаз», не угадывай, не бери длительность из БД/ASR.
- Сумма `длительность_сек` по всем сценам = сумме `время_сек` всех кадров входа.
- В `map.кадры` время не пишешь — только группировка меток.

---

## ЖЁСТКИЕ ПРАВИЛА ЯКОРЕЙ (не нарушать)

Валидатор ищет `якорь` как **непрерывную подстроку** полного заказа.
Если фразы нет в тексте — ячейка rejected.

- `characters_seed[].якорь` — копируй кусок из `закадр` кадра (как написано, с ударениями/регистром слов из текста).
  Пример: если в тексте «Мака́ртур Уи́лер» — якорь именно эта форма, не «Макартур Уилер».
- `locations_seed[].якорь` — тоже только подстрока из заказа. Не выдумывай мета-метки
  вроде «вводная графика», «место проверки гипотезы», если этих слов нет в закадре.
  Для абстрактного вступления бери реальную фразу из кадров сцены
  (напр. «Самые странные преступления» / «в Пи́ттсбурге»).
- `главное.якорь_в_кадрах` — тоже подстрока из закадра кадров сцены.
- В `map` поля места/персонажи/предметы — лейблы для тебя; seed-якоря всё равно
  должны проходить проверку подстроки.

---

## КОНТРАКТ СЦЕНЫ

`id_scene` (`scene_01`…), `кадры` (номера 1..N, каждый ровно в одной сцене),
`нити` (`нить`,`решение`∈продолжаю|закрыто|не моё,`как`),
`связь_с_прошлой` (`тип` ∈ продолжение|сдвиг_времени|новое_место),
`суть`, `главное` (тип/глагол/субъект/объект/изменение/якорь_в_кадрах/нить),
`биты` (можно `[]`), `персонажи` (`id`,`как`), `место_id`, `время`,
`длительность_сек` (= сумма время_сек кадров сцены).

---

## ПРОЧИЕ ПРАВИЛА

- Локации: dedup → `locNN`; один кадр без возврата → `фон_разовый: true`.
- Персонажи: koref → один `cNN`; внешность НЕ писать.
- Критик: ≤5 issues; в ответе уже финал после правок (`accepted`).

---
