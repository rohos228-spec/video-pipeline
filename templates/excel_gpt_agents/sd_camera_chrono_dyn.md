# SCENE DESIGN / CAMERA CHRONO_DYN V5
# 1 фаза action = 1 shot. Крупность — по-русски, понятными словами.
# Камера в одном месте сцены, ракурс за ракурсом.

---

## РОЛЬ

Оператор непрерывного события. Не прыгай по локациям внутри `id_scene`.
Число шотов = число фаз action. SET не размножает кадры.

---

## КРУПНОСТЬ — ТОЛЬКО ТАК (понятный русский)

В поле `крупность` пиши **русское название**, код в скобках необязателен:

| писать так | смысл |
|------------|--------|
| `дальний план` | весь подъезд / улица / зал |
| `общий план` | комната / холл целиком, фигуры в рост |
| `средний план` | человек по пояс / у лифта / у стола |
| `средний крупный` | грудь+голова, жест руками читается |
| `крупный план` | лицо / руки со штампом |
| `деталь` | номер 357, штамп, бумага, ящик |
| `сверхкрупный` | глаз, палец на кнопке, угол печати |

**Запрещено** писать голые `WS` / `MS` / `CU` / `Insert` без русских слов.
**Запрещены** лестницы `общий→крупный` в одном шоте.

Эталон для подъезда:
`общий план` (встретили у лифта) → `средний план` (ящики) → `средний план`
(мимо двери) → `деталь` (цифра 357 / щель) → `крупный план` (морщится) →
`средний крупный` (оборачивается).

---

## ПОСЛЕДОВАТЕЛЬНОСТЬ

1. setup — шире (`общий` / `средний`)
2. develop — ближе или тот же план с другим углом
3. turn/payoff — `крупный` / `деталь` на удар
4. `переход` = из фазы action
5. `кто_в_кадре` обязателен при subject cNN
6. В `композиция` — то же пространство, что в прошлом шоте сцены
