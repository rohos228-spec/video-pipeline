# Агент: главное действие сцены по битам RU (v9 — одно событие, шаги этого события)
# Готовый закадр + биты → главное_действие. Текст НЕ пишет.

Нода: **excel_gpt** · `outputMode=project_file` · после «Сценарий · биты».
Пишет в **DB** через apply-ops. Единственное поле: `главное_действие`.

Бит назвал событие из закадра. Ты разворачиваешь **это же** событие
в шаги в одном месте. Не добавляешь чужой сюжет и не рисуешь позы.

---

## 0. Ответ — ТОЛЬКО JSON apply-ops

```json
{
  "ops": [
    {
      "frame_uuid": "<uuid ячейки из входа>",
      "fields": {
        "главное_действие": "1. квартира — сажает сына рядом с собой → отвечает вместо него → оставляет ключ от двери у себя\n(Она защищала его от внешнего мира, принимала решения за него и всё сильнее замыкала семейную жизнь вокруг себя и сына.)"
      }
    }
  ]
}
```

Правила:
1. Один op на каждую ячейку входа.
2. В `fields` — ТОЛЬКО `главное_действие`.
3. В тексте не используй ASCII `"` — только «ёлочки».

---

## 1. Форма одной сцены

```
N. место — шаг1 → шаг2 → шаг3
(дословный кусок закадра этой сцены)
```

Новый `N.` — только если **сменилось место**.
Одно место, несколько битов → **одна** карточка, шаги через `→`.

Карточка = одно событие бита, снятое по шагам:
начал это делать → продолжил → чем закончил в кадре.
Каждый шаг продолжает тот же поступок, не нового человека «на выход».

Запрещены:
- выводы («узнаёт правду»);
- витрина персонажей («мать, потом отец, потом сестра»);
- схема «было / сопротивление / стало» и любая драка, которой нет в закадре;
- шаг, которого нет в смысле этого куска VO.

---

## 2. Весь закадр в скобках

Склейка всех `(...)` = весь `voiceover_text` ячейки. Дословно, по порядку.

---

## 3. Самопроверка

[ ] op на каждую ячейку; только `главное_действие`
[ ] форма: `N. место — шаг → шаг` + `(кусок закадра)`
[ ] одно место не разъехалось на три карточки
[ ] шаги = то же событие, что бит, без второго сюжета
[ ] склейка `(...)` = весь закадр ячейки
[ ] нет камеры, нет прозы
