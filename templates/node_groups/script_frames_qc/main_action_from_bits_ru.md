# Агент: главное действие сцены по битам RU (v11 — одно действие сцены)
# Готовый закадр + биты → главное_действие. Текст НЕ пишет.

Нода: **excel_gpt** · `outputMode=project_file` · после «Сценарий · биты».
Пишет в **DB** через apply-ops. Единственное поле: `главное_действие`.

**1 VO-ячейка = 1 сцена**, пока съёмочное место реально не сменилось.
Биты — повороты внутри этой сцены, не отдельные сцены.

Сцена имеет **одно общее действие** (что происходит в этом месте за этот
кусок закадра). Шаги через `→` — только продолжение **этого** действия:
следующее видимое состояние того же сета. Не альбом людей.

Кадр может быть дверью, стулом, двумя бумагами, коридором — не обязан
быть «человек делает глагол». Не добавляй чужой сюжет.

---

## 0. Ответ — ТОЛЬКО JSON apply-ops

```json
{
  "ops": [
    {
      "frame_uuid": "<uuid ячейки из входа>",
      "fields": {
        "главное_действие": "1. квартира — дом замыкается: засов на двери → ключ лежит на столе → стул отца отодвинут от стола\n(Она защищала его от внешнего мира, принимала решения за него и всё сильнее замыкала семейную жизнь вокруг себя и сына.)"
      }
    }
  ]
}
```

Правила:
1. Один op на каждую ячейку входа.
2. В `fields` — ТОЛЬКО `главное_действие`.
3. В тексте не используй ASCII `"` — только «ёлочки».

---

## 1. Форма одной сцены

```
N. место — общее действие: шаг1 → шаг2 → шаг3
(дословный кусок закадра этой сцены)
```

После `—` сначала **общее действие сцены** (одна смена, которую можно снять),
потом двоеточие, потом шаги. Все шаги — звенья этой смены. Шаг N+1 продолжает
шаг N в том же сете: дверь → засов → пустой стул, не «мать / отец / сестра».

Новый `N.` — только если в закадре есть **склейка съёмочного места**
(вышли из дома — больница; из больницы — другой город). Упоминание имени,
года или человека в речи ≠ новая сцена.

Одна ячейка, одно место → **одна** карточка. Несколько битов в одном месте
не плодят новые `N.`

Запрещены:
- витрина «мать, потом отец, потом сестра»;
- шаг на каждую фразу закадра;
- выводы («узнаёт правду»);
- драка и второй сюжет, которых нет в закадре.

---

## 2. Весь закадр в скобках

Склейка всех `(...)` = весь `voiceover_text` ячейки. Дословно, по порядку.
Код режет закадр кадра по точке или запятой (13–80). Не режь VO сам
середине словосочетания.

---

## 3. Самопроверка

[ ] op на каждую ячейку; только `главное_действие`
[ ] у каждой карточки одно общее действие; шаги только его продолжают
[ ] нет витрины персонажей
[ ] новый N. только при смене съёмочного места
[ ] склейка `(...)` = весь закадр ячейки
[ ] нет камеры, нет прозы
