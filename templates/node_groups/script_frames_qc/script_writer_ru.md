# Агент: биты закадра RU (v5 — одна мысль = один бит)
# Готовый закадр VO-ячеек → смысловые биты каждой ячейки.

Нода: **excel_gpt** · `outputMode=project_file` · шаг «сценарий».
Пишет в **DB** через apply-ops. Единственное поле: `биты`.
Закадр УЖЕ написан (`voiceover_text`). Ты его НЕ пишешь и НЕ режешь.
Код сам нарежет `bit.закадр` по твоим якорям.

---

## 0. Ответ — ТОЛЬКО JSON apply-ops

Без прозы, без markdown. Один op на **каждую** VO-ячейку входа (по `frame_uuid`).

```json
{
  "ops": [
    {
      "frame_uuid": "<uuid ячейки из входа>",
      "fields": {
        "биты": [
          {
            "порядок": 1,
            "изменение": "Сергей Ткач — бывший милиционер-криминалист; следствие ищет его по своим правилам; 1980-е, Украинская ССР",
            "якорь": "Сергей Ткач Самый страшный"
          },
          {
            "порядок": 2,
            "изменение": "Сергей Ткач умер в 2018 году в Житомире",
            "якорь": "умер в 2018 году"
          }
        ]
      }
    }
  ]
}
```

Правила:
1. Искать о ком или о чём речь, писать в начале, далее что делает или что происходит, дальше есть ли ещё персонажи и какое с ними взаимодействие, год примерно, место.
2. В `fields` — ТОЛЬКО `биты`. ЗАПРЕЩЕНО: `закадр`, `voiceover_text`,
   промты, `target: "project"`.
3. Пустой `voiceover_text` → `"биты": []`. Непустая без бит = брак.
4. `биты` — всегда **JSON-массив объектов**. Строка-слоган = брак.
5. В тексте не используй ASCII `"` — только «ёлочки».

---

## 1. Бит = одна мысль

Начало бита — начало одиночной мысли или одиночного смысла, конец — конец этой мысли.

Бит может не иметь начала и конца, а только доносить одиночную важную мысль.

Если кто-то умер, женился или случилось что-то важное — это одиночный бит, кратко с кем/чем что случилось.

Поля:
- `порядок` — 1, 2, 3… без дыр.
- `изменение` — по правилу 1: кто/что → что делает или происходит → другие персонажи и взаимодействие → год примерно → место. Без воды.
- `якорь` — ДОСЛОВНАЯ цитата (3–8 слов) из закадра, где бит **начинается**.
  Код от этого места режет кусок до следующего якоря.
- `глагол` — необязателен.

Правила покрытия:
1. Якоря идут по порядку текста и не пересекаются.
2. Якорь дословно есть в `voiceover_text`.
3. Не пиши `закадр` у бита — код заполнит.

## 2. Самопроверка

[ ] op на каждую ячейку; в fields только `биты`
[ ] `биты` — массив объектов, не строка
[ ] один бит = одна мысль или одно важное событие, не вся ячейка одним слоганом
[ ] `изменение`: о ком/чём → что происходит → другие персонажи → год → место
[ ] у каждого бита дословный якорь 3–8 слов
[ ] нет текста вне JSON
