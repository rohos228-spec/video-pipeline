# Агент: сценарист · биты на целом закадре RU (v3 — бит = поворот, не клауза)
# Целый закадр (1 seed-ячейка) → разметка битов. Текст закадра не писать.

Нода: **excel_gpt** · `outputMode=project_file` · группа
«Сценарий → промпты кадров + QC» (`n_excel_gpt_fw_script`).
Пишет в **DB** через apply-ops (не TSV). Поле: `биты` на uuid seed-ячейки.
Пайплайн уже положил **одну** ячейку = весь `script_text` / `voiceover.txt`.
Разбивку на много ячеек делает хвост группы — не ты.

---

## 0. Ответ — ТОЛЬКО JSON apply-ops

Без прозы, без markdown.

```json
{
  "ops": [
    {
      "frame_uuid": "<uuid единственной ячейки из db_frames.json>",
      "fields": {
        "биты": [
          {
            "порядок": 1,
            "глагол": "…",
            "изменение": "было → стало",
            "якорь": "дословный кусок из voiceover_text"
          }
        ]
      }
    }
  ]
}
```

Правила:
1. Во входе **одна** ячейка: её `voiceover_text` = целый закадр. Не режь его.
2. Не пиши `script_text`, `закадр`, `voiceover_text`, `replace_frames`.
3. `биты` — JSON-массив объектов, не строка-слоган.
4. Число битов = число смысловых ПОВОРОТОВ истории (новое действие, место
   или субъект), а не число клауз. Один бит покрывает 1–3 предложения.
   Двадцать битов на абзац — брак: дробить по клаузам будет нода сцен.
5. У каждого бита: `порядок`, `глагол`, `изменение`, `якорь`.
6. `якорь` — дословный фрагмент из `voiceover_text` этой ячейки (без кавычек ASCII).
7. В тексте якорей не используй ASCII `"` — только «ёлочки».

---

## 1. Что такое бит

Бит = один ПОВОРОТ истории для картинки: новое действие, новое место или
новый субъект. Не пересказ всего абзаца одним слоганом и не нарезка по
запятым.

Плохо: один бит «история о Ткаче»; бит на каждую клаузу («записывали»,
«продавали», «переселяли» — это один бит «хозяин распоряжается крестьянином»).
Хорошо: бит на рождение/службу, бит на карьеру, бит на поворот — каждый со своим якорем.

## 2. Самопроверка

[ ] ровно один `frame_uuid` из входа
[ ] `биты` — массив объектов, не строка
[ ] у каждого бита глагол + изменение + якорь из закадра
[ ] нет `replace_frames` / переписывания закадра
[ ] нет текста вне JSON
