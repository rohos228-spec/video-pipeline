## 0. Ответ — ТОЛЬКО JSON apply-ops

```json
{
  "ops": [
    {
      "frame_uuid": "<uuid ячейки из входа>",
      "fields": {
        "биты": [
          {
            "порядок": 1,
            "глагол": "защищая / замыкая",
            "изменение": "мир доступен → дом закрыт вокруг матери и сына",
            "якорь": "Она защищала его"
          }
        ]
      }
    }
  ]
}
```

Правила:
1. Один op на каждую VO-ячейку.
2. В `fields` — ТОЛЬКО `биты`.
3. Пустой VO → `"биты": []`. Непустая без бит = брак.
4. `биты` — массив объектов, не строка-слоган.
5. ASCII `"` в тексте запрещены — только «ёлочки».

## 1. Что такое бит (McKee / Назайкин)

Бит — **самое мелкое событие сцены**: обмен **действие → реакция**
в поведении. Не пауза в диалоге. Не ярлык из двух слов.

- Действие — не движение тела, а **что человек (или сила) делает
  по сути**. Пиши герундием: прося, настаивая, игнорируя, вытесняя,
  объясняя, направляя.
- Реакция — ответ мира / другого / бумаги / суда. Тоже герундий.
- Поле `глагол` = `действие / реакция`. Это и есть бит.
- Бит **длится, пока поведение то же**. Новый бит — только когда
  поведение явно сменилось (просил → требует; игнорирует → смеётся;
  защищает → замыкает; дома → увезли).
- Цепочка битов меняет отношения и ведёт к повороту сцены.
  Последний бит ячейки — поворот.

`изменение` — заряд ценности этого бита: каким мир **был** на входе
в бит и каким **стал** на выходе. Без смены ценности бита нет
(McKee: сцена/бит без turn = non-event).

Не бит:
- поза («стоит → сидит»);
- пересказ фразы закадра;
- оценка без обмена («семья неблагополучная» без ответа);
- выдуманный второй сюжет.

Поля:
- `порядок` — 1, 2, 3… без дыр.
- `глагол` — `действие / реакция`, герундии.
- `изменение` — ценность: было → стало.
- `якорь` — дословный старт куска в VO (2–8 слов).
  `закадр` у бита не пиши — код заполнит.

Якоря по порядку текста, дословно есть в VO.
