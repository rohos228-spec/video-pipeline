# Агент: сцены → кадры RU (v9 — скелет = шаги действия; VO 26–80 / перебивка 10–30)
# Цепь сцен → список кадров. Текст НЕ генерирует. Камеру допишет код.

Нода: **excel_gpt** · `outputMode=project_file` · после «Главное действие».
Пишет в **DB** через apply-ops. Единственное поле: `кадры`.

Один кадр = один видимый шаг из `главное_действие` (`вошёл → сел → открыл`).
**Число кадров ≈ число шагов действия этой ячейки** (скелет). Закадр режется
по кадрам кусками 26–80 (обычный) / 10–30 (перебивка). Не схлопывай фильм
в 1–5 кадров, когда в `главное_действие` 15–30 шагов: это брак недобора.
Не паркуй действие всего фильма на одну VO-ячейку: шаги и закадр — **этой** ячейки.

Лимиты 26–80 — про **длину текста одного кадра**, не про «потолок числа кадров».
Перебивка / деталь / эмо: 10–30 или короткий пустой закадр. Parent — чтобы
дети наследовали место / людей / свет с PNG родителя.

Если `кадры` сильно неполные относительно шагов действия (напр. 1 из 21) —
код **не** допишет молча и **не** примет soft: нужен добор GPT / retry.
Мягкий WARN только при почти полном покрытии (≥70%). Не выдумывай шаги
действия и не вставляй silent «общий вид».

            "объект": "тело",

          },
          {
            "id": "5-S1-K3",
            "parent_id": "5-S1-K1",
            "порядок": 3,

Правила:
1. Один op на каждую ячейку.
2. В `fields` — ТОЛЬКО `кадры`. Запрещены биты, главное_действие, промты.
3. `id` = `{number}-S{сцена}-K{n}`. Первый кадр места: `parent_id: null`.
   Дальше на том же месте: `parent_id` = id первого кадра этой локации.
4. В тексте не используй ASCII `"` — только «ёлочки».

## 1. Как резать

1. Возьми шаги из `главное_действие` **этой ячейки** (`→`). Один шаг = один кадр
   (скелет = шаги). Не режь число кадров до `floor(len(VO)/26)`, если шагов больше.
2. `действие` — этот шаг, без повтора соседнего. Не выдумывай шаги и не тащи
   действие соседних ячеек / всего фильма.
3. `объект` — строго одно из: `место` | `тело` | `двое` | `предмет` | `лицо` | `взгляд`.
   Согласуй с глаголом: вошёл → место, сел → тело, открыл папку → предмет,
   говорит с кем-то → двое, лицо реакции → лицо, смотрит на улику → взгляд.
4. `закадр` — дословный кусок ячейки. Жёсткие лимиты **на один кадр**:
   - обычный / длинный шаг: **26–80** символов, цель ~45;
   - перебивка: **10–30** символов **или** короткий эмо/реакция-кадр (можно пустой закадр).
   Число кадров = шаги; VO распределяй по кадрам (короткие/перебивки ок),
   не схлопывай в 1–5 при длинной цепи. Склейка непустых кусков = весь `voiceover_text`.
   Не вали весь VO в один кадр, если шагов и длины хватает на 2+.
   Короче 10 — только осознанная перебивка; иначе склей с соседом.
   Длиннее 80 — ещё кадр (или перенеси хвост на соседний шаг).
5. `план` (если пишешь) — только канон:
   `ДАЛЬНИЙ` | `ОБЩИЙ` | `СРЕДНИЙ` | `СРЕДНЕ-КРУПНЫЙ` | `КРУПНЫЙ` | `ДЕТАЛЬ`.
   Выбор по ситуации (место/вход → ОБЩИЙ; жест тела → СРЕДНИЙ; диалог → СРЕДНЕ-КРУПНЫЙ;
   эмоция → КРУПНЫЙ; предмет после жеста → ДЕТАЛЬ), не тупо «объект→план».
   Запрет соседних склеек: ОБЩИЙ↔СРЕДНИЙ и СРЕДНИЙ↔СРЕДНЕ-КРУПНЫЙ; не два одинаковых подряд;
   не прыжок через 3+ ступени. Иначе оставь план пустым — код выставит/починит.
6. Не копируй T0–T10 и не вставляй шаблон «общий вид {место}» ради схемы.

## 2. Самопроверка

[ ] кадров ≈ уник. шаги действия ячейки (скелет); не 1–5 при 15+ шагах; не 50 пустых на короткий VO
[ ] нет двух кадров с одним и тем же действием
[ ] объект из enum и сходится с глаголом
[ ] склейка закадр = весь voiceover_text ячейки
[ ] 26–80 обычный на кадр; перебивка 10–30 или эмо/пустой; пустых оболочек почти нет
[ ] parent_id null только у первого кадра нового места
[ ] действие и VO только этой ячейки, не всего фильма
