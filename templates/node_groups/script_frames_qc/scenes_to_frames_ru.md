# Агент: сцены → кадры RU (v8 — шаги общего действия сцены, не T0–T10)
# Цепь сцен → список кадров. Текст НЕ генерирует. Камеру допишет код.

Нода: **excel_gpt** · `outputMode=project_file` · после «Главное действие».
Пишет в **DB** через apply-ops. Единственное поле: `кадры`.

Один кадр = один видимый шаг **общего действия этой сцены**
(`засов → ключ на столе → стул отодвинут`). Кадры сцены — последовательность
одного действия, не альбом поз. K2 продолжает K1 в том же сете.

Не покрытие master+дети ради схемы T0–T10. Parent — только чтобы дети
наследовали место / людей / свет с PNG родителя.

Если `кадры` пустые — код сам развернёт шаги из `главное_действие`.
Твоя работа: назвать шаг и `объект`. Камеру можно не писать.

## 0. Ответ — ТОЛЬКО JSON apply-ops

```json
{
  "ops": [
    {
      "frame_uuid": "<uuid ячейки из входа>",
      "fields": {
        "кадры": [
          {
            "id": "5-S1-K1",
            "parent_id": null,
            "порядок": 1,
            "сцена": 1,
            "место": "кабинет следователя",
            "действие": "вошёл",
            "объект": "место",
            "закадр": "<дословный кусок voiceover_text>"
          },
          {
            "id": "5-S1-K2",
            "parent_id": "5-S1-K1",
            "порядок": 2,
            "сцена": 1,
            "место": "кабинет следователя",
            "действие": "сел к столу",
            "объект": "тело",
            "закадр": "<следующий кусок>"
          },
          {
            "id": "5-S1-K3",
            "parent_id": "5-S1-K1",
            "порядок": 3,
            "сцена": 1,
            "место": "кабинет следователя",
            "действие": "открыл папку",
            "объект": "предмет",
            "закадр": "<хвост>"
          }
        ]
      }
    }
  ]
}
```

Правила:
1. Один op на каждую ячейку.
2. В `fields` — ТОЛЬКО `кадры`. Запрещены биты, главное_действие, промты.
3. `id` = `{number}-S{сцена}-K{n}`. Первый кадр места: `parent_id: null`.
   Дальше на том же месте: `parent_id` = id первого кадра этой локации.
4. В тексте не используй ASCII `"` — только «ёлочки».

## 1. Как резать

1. Возьми шаги из `главное_действие` (`→`). Один шаг = один кадр.
2. `действие` — этот шаг, без повтора соседнего.
3. `объект` — строго одно из: `место` | `тело` | `двое` | `предмет` | `лицо` | `взгляд`.
   Согласуй с глаголом: вошёл → место, сел → тело, открыл папку → предмет,
   говорит с кем-то → двое, лицо реакции → лицо, смотрит на улику → взгляд.
4. `закадр` — дословный кусок ячейки, **13–80 символов**, цель ~45.
   Режь по точке, иначе по запятой. Не рви словосочетание посередине.
   Склейка всех кусков = весь `voiceover_text`. Короче 13 — склей с соседом.
   Длиннее 80 — ещё один шаг по следующей точке/запятой.
5. Не пиши план / линзу / ракурс / движение — код возьмёт из таблицы по `объект`.
6. Не копируй T0–T10 и не делай «общий ради схемы», если шаг не про вход в новое место.
7. Не добавляй кадр «стоит персонаж N», если этого шага нет в цепи общего действия.

## 2. Самопроверка

[ ] кадров столько, сколько уникальных шагов действия
[ ] нет двух кадров с одним и тем же действием
[ ] объект из enum и сходится с глаголом
[ ] склейка закадр = весь voiceover_text
[ ] 13–80 на кадр
[ ] parent_id null только у первого кадра нового места
