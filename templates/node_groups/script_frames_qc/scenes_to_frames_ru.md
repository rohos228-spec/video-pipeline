# Агент: сцены → кадры RU (v8 — шаги действия + площадка)
# Цепь сцен + площадка → список кадров. Текст НЕ генерирует. Камеру допишет код.

Нода: **excel_gpt** · `outputMode=project_file` · после «Главное действие».
Пишет в **DB** через apply-ops. Единственное поле: `кадры`.

Один кадр = картина к **своему куску закадра**. Не отдельный фильм про
микрожесты. Parent — чтобы дети наследовали место / людей / свет с PNG родителя.

Если `кадры` пустые — код сам развернёт шаги из `главное_действие`.
Твоя работа: шаг, который **видно в закадре**, `объект`, и при точности —
`старт`/`конец`/`меняет`. Камеру можно не писать.

Правила:
1. Один op на каждую ячейку.
2. В `fields` — ТОЛЬКО `кадры`. Запрещены биты, главное_действие, промты.
   `площадка` ячейки — во входе, только читать (код её дополнит сам).
3. `id` = `{number}-S{сцена}-K{n}`. Первый кадр места: `parent_id: null`.
   Дальше на том же месте: `parent_id` = id первого кадра этой локации.
4. В тексте не используй ASCII `"` — только «ёлочки».

## 1. Как резать

1. Кадр обязан быть картиной **этого** куска `voiceover_text`. Не ставь
   «открывает папку», если закадр про армию / алиби / погоню.
2. Бери шаги из `главное_действие`, но **склеивай микрошаги** в один
   процесс, если закадр не требует точного до/после. Типично 2–5 кадров
   на ячейку, не десятки.
3. `действие` — экшен в кадре, конкретный: кто, что делает, чем кончится
   жест. Запрещено: «жест завершён», «листы видны», «руки рядом» без того,
   какой жест и что на листах.
4. `объект` — строго одно из: `место` | `тело` | `двое` | `предмет` | `лицо` | `взгляд`.
   Согласуй с глаголом: вошёл → место, сел → тело, открыл папку → предмет,
   говорит с кем-то → двое, лицо реакции → лицо, смотрит на улику → взгляд.
5. `закадр` — дословный кусок ячейки. **Сначала смысл:** режь по мысли /
   клаузе / предложению; картина кадра = этот смысл. **Дополнительно 13–80**
   символов (цель ~45): короче 13 — склей с соседней мыслью; длиннее 80 —
   разрежь по смыслу на две клаузы, не посреди фразы и не «на 80-м знаке».
   Склейка всех кусков = весь `voiceover_text`.
6. Линзу не пиши — код возьмёт из таблицы. `план` / `ракурс` можно не
   писать; если пишешь и крупность сменилась — угол камеры ≥30°.
7. Не делай «общий ради схемы», если шаг не про вход в новое место.
8. Шаг сразу после двери/порога («вбегает в прихожую» после «открывает
   дверь») — `объект: тело`, не `место`: это продолжение движения изнутри,
   код поставит средний план и рез по жесту, а не новый общий.
9. **Точность vs процесс.** `точность: true` + `старт`/`конец`/`меняет` —
   только если зрителю нужно увидеть определённое ДО и ПОСЛЕ (открыл папку
   с фото, положил улику на стол, достал пистолет). Иначе не пиши старт/конец:
   одно `действие` = процесс в разгаре. Код не будет клеить фальшивую пару.
10. Идущий/бегущий в каждом следующем кадре дальше по пути — не повторяй
    его прошлую точку.

## 1b. Площадка в кадре (код проверит и распишет раскладку)

Во входе у ячейки `площадка`: зоны, двери, проходы, люди (по компасу).
В каждом кадре, где можешь, пиши:

1. `зона` — id зоны из площадки, где идёт этот шаг.
2. `камера` — `{"где": сторона зоны, где стоит камера, "смотрит": куда}`.
   Одна сторона оси на весь разговор двоих; «с плеча» — та же сторона.
   Через дверь: снаружи камера смотрит на дверь, изнутри — навстречу
   входящему (смотрит на дверь изнутри).
   **Правило 30°.** Смена `план` (крупности) обязана сменить угол камеры
   минимум на 30°: другая сторона компаса или другой `ракурс`
   (`фронт` → `3/4` → `сверху` / `снизу`, не соседние «3/4» и «с плеча»).
   Сменить только крупность, оставив ту же точку съёмки — брак (jump cut).
3. `люди` — `[{"кто", "где", "лицом", "движется"}]`: где человек в
   НАЧАЛЕ кадра, до жеста. Кто движется — в следующем кадре дальше по пути.
4. `меняет` — `[{"предмет", "состояние"}]`: что этот шаг меняет
   (дверь → открыта). Дверь, которую никто не открыл, закрыта.

Код пишет `раскладка`: либо СТАРТ/КОНЕЦ (точный жест), либо одно ДЕЙСТВИЕ-процесс;
положение предметов; «в референсе» и «смена» (≥30°).
Лево/право экрана сам не считай — код посчитает от камеры.
Не знаешь — пропусти поле, код выведет из шага. Прошёл через закрытую
дверь без шага «открывает» — код сам вставит кадр на пороге.

## 1a. Порядок планов (код проверит)

Сцена: общий (вход в новое место) → средний → крупный/деталь.
Назад к общему посреди действия — брак («средний → общий → средний»).
Можно только при скачке в другое место (не через дверь прошлого кадра),
при `dissolve`/`fade` или в финале сцены.

## 2. Самопроверка

[ ] кадров столько, сколько **нужно смыслу закадра**, не сколько микрошагов
[ ] нет двух кадров с одним и тем же действием
[ ] каждый кадр иллюстрирует смысл своего куска закадра
[ ] объект из enum и сходится с глаголом
[ ] склейка закадр = весь voiceover_text
[ ] доп. 13–80 на кусок: короче — склей мысль, длиннее — режь по клаузе
[ ] parent_id null только у первого кадра нового места
[ ] после двери — `тело` изнутри, не `место`
[ ] идущий не стоит на месте
[ ] нет возврата к общему плану посреди действия
[ ] зона из площадки; камера одной стороны оси у двоих; меняет у шага с дверью
[ ] СТАРТ/КОНЕЦ только если `точность` или `меняет`; иначе одно действие-процесс
[ ] в точном жесте названо, ЧТО видно (фото, штамп, надпись), не «лист виден»
[ ] смена плана → угол камеры ≥30° относительно прошлого кадра
