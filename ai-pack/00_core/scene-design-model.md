# scene_design — модель сущностей

## Запомни

1. **Ячейка закадра + аудиометки** = временной диапазон текста = **целая сцена**.
   Текст ячейки **разбивается по кадрам сцены**: каждый кадр несёт свой фрагмент;
   **сумма фрагментов кадров сцены = полный текст ячейки** (ничего не теряется
   и не добавляется).
2. **Скелет не делает сцены.** Он размечает каждую VO-ячейку: фокус, смысловые
   части (биты = «было → стало»), предметы (`items_seed`), seed c/loc.
3. **1 ячейка закадра → 1 карточка скелета** (`cells[].кадр = N`). Склейка
   соседних VO запрещена. Внутри пайплайна карточка может жить как мост
   `scenes[]` / `id_scene=scene_NN` для action/camera.
4. **К одной VO-ячейке может относиться много визуальных кадров** (шоты SET) —
   их добавляет camera_expand **после** скелета/action.
5. Главное — границы по озвучке (ячейка закадра), не «модель сгруппировала
   три VO в одну сцену».

## Код

- `camera_expand.subdivide_vo_frames_by_camera` — вставляет шоты и раздаёт
  фрагменты VO по кадрам (`split_text_into_parts`); `collapse_shot_children`
  склеивает фрагменты обратно на родителя перед повторным прогоном.
- Скелет: `prompts/05_excel_gpt/sd_skeleton.md` + `normalize_skeleton_draft`.
- Промпты: `prompts/scene_design/action.md`, `assemble.md`, `camera.md`.
