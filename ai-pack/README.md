# ai-pack — пакет для ИИ

**Видимое место:** корень репозитория `video-pipeline/ai-pack/`.  
**Ярлык на рабочем столе:** `AI-PACK video-pipeline`.

## Что это

Готовый набор настроек и гайдов, чтобы модель могла:

- понимать пайплайн Studio;
- чинить баги по карте кода;
- править промпты по контракту DB/apply-ops;
- не ломать git-ветки и статусы нод.

## Как кинуть в ИИ

1. Открой папку `ai-pack` (или ярлык на рабочем столе).
2. Прикрепи **сначала** `START_HERE.md`.
3. По задаче добавь файлы из `00_core/`, `01_data_prompts/`, …
4. Либо прикрепи всю папку целиком (если клиент умеет).

## Содержимое

| Папка | Содержание |
|-------|------------|
| `START_HERE.md` | главный вход — читай первым |
| `00_core/` | AGENTS, карта, ops/map rules |
| `01_data_prompts/` | контракт промптов, DB v2, ноды, blocks |
| `02_ops/` | bible оператора, mass |
| `03_config/` | `env.example` (без секретов), pyproject |
| `MANIFEST.txt` | git HEAD и список файлов на момент сборки |

## Обновить и проверить правдивость

```text
python scripts/build_ai_pack.py
python scripts/verify_ai_pack.py
```

`verify` сверяет копии с источниками, ссылки START_HERE, отсутствие секретов  
и ключевые факты (DB SoT, media gates, Studio меню).

Оригиналы живут в `docs/`, `AGENTS.md`, `.cursor/rules/`.  
Этот каталог — удобная **выгрузка для чата**, не второй SoT.
