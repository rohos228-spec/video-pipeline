# /vp-resume [тема или путь плана]

Автопилот включён. Восстанови состояние по фактам, а не по памяти.

1. `git worktree list` — активные worktree в `.worktrees/`. Если тема не указана и
   их несколько — возьми с самым свежим коммитом (`git -C <wt> log -1 --format=%ci`).
2. В выбранном worktree найди журнал `.superpowers/sdd/*/progress.md`; первая строка
   называет план. Прочитай план и спеку.
3. Сверь журнал с `git log --oneline <база>..HEAD` и `git status`:
   - задача в журнале отмечена, коммит есть → готова;
   - незакоммиченные правки → это прерванная задача: проверь их тестами, доведи и закоммить
     или откати только их (`git -C <wt> checkout -- <файлы>` — спросит человека хук; при
     сомнении доведи, а не откатывай);
   - журнала нет, но есть план → продолжай с первой задачи без коммита.
4. Продолжи `superpowers:subagent-driven-development` с первой незавершённой задачи и
   далее по `/vp-auto` шаги 6–9.
5. Нет ни журнала, ни плана — есть только спека → начни с шага 5 `/vp-auto`.
   Нет ничего → сообщи, что продолжать нечего, и покажи `git worktree list`.

В отчёте отдельно укажи, с какого места продолжил и почему так решил.
