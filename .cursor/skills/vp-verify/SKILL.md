# /vp-verify [путь worktree или ветка]

Ничего не чини — только проверяй и докладывай.

1. Цель: указанный worktree; иначе — текущий; иначе самый свежий в `.worktrees/`.
   База: `git merge-base HEAD <ветка основного checkout>`.
2. Параллельно запусти субагентов:
   - `vp-verifier` — полный прогон `tests/`, ruff E9/F63/F7/F82 по изменённым файлам,
     сравнение падений с базой;
   - `vp-contract-reviewer` — дифф `база...HEAD` на контракты проекта.
3. Дополнительно сам: `<python> -m ruff check <изменённые .py>` — новые замечания
   относительно базы (старые ~50 по репозиторию не считаются).
4. Итог по-русски:

```
ВЕРДИКТ: ГОТОВО К СЛИЯНИЮ | НЕ ГОТОВО
Ветка / worktree / база:
Тесты: было <N failed> → стало <M failed>; новые: ...
Контракты: OK | нарушения ...
Ручные проверки человеку: ...
Команды слияния (выполняет человек): ...
```
