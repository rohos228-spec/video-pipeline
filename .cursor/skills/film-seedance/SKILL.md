# Шаблон 3: видеопромпты Seedance 2.0

## Нумерация @image — сначала прочитай
Каждому референсу — СВОЙ номер. Два листа персонажей НЕ бывают оба `@image1`
(персонажи сольются).
- Лист персонажа A → `@image1`, B → `@image2`, …
- Сетка раскадровки → следующий свободный номер (`@image3` при двух листах;
  `@image1`, если сетка — единственный референс).

## Длительность: всегда 15 секунд
Seedance 2.0 режет на 15 с. По умолчанию пиши на полные 15 и таймлайн 0:00–0:15.
Меньше — только если человек прямо попросил («6-секундный тизер»).

## Звук: без музыки по умолчанию
Указывай ambient / БЕЗ МУЗЫКИ. Музыку вставляй только по явному запросу.

## Вариант A — текст, опционально листы персонажей
Когда нет раскадровки; комбинируемые промпты кадров.
```text
15 секунд / [N] СКЛЕЕК / [ЖАНР + ТОН] / [ЗВУК]
ПЕРСОНАЖ 1: [внешность, черты, стиль]. [@image1, если лист есть]
ПЕРСОНАЖ 2: [опционально]. [@image2]
ОКРУЖЕНИЕ: [место, время, погода, свет, атмосфера]
ЗВУК / НАСТРОЕНИЕ: [без музыки; ключевые звуки]
ТАЙМЛАЙН (весь 0:00–0:15):
0:00–0:05: [кадр/камера] — [что в кадре и происходит]
0:05–0:10: …
0:10–0:15: …
```
Многокадровая серия без раскадровки: по промпту A на кадр; ПЕРСОНАЖ/ОКРУЖЕНИЕ/ЗВУК
идентичны во всех, меняются только ТАЙМЛАЙН и кадрирование. Аспект указывай в каждом.

## Вариант B — раскадровка-сетка как главный референс
Когда есть сетка 3×3 — предпочтительнее A (меньше дрейф).
> Используй раскадровку-сетку @image1 как основной визуальный референс и ориентир
> движения. 15-секундная кинематографическая последовательность. Панели — как
> последовательные кадры, не единое изображение. Соблюдай порядок панелей, логику
> камеры, стрелки движения, кадрирование. БЕЗ ТЕКСТА НА ЭКРАНЕ, БЕЗ МУЗЫКИ.
> Сюжетная линия: [сжато, не пересказ каждой панели].

## Вариант C — листы персонажей + сетка (макс. точность)
> Персонаж 1: @image1 / Персонаж 2: @image2. Раскадровка-сетка @image3 — референс
> движения и кадрирования. Дальше как в B.
Один лист → убери строку «Персонаж 2», сетка = @image2. Три листа → сетка = @image4.

## Диалоги (в основном вариант A)
- Реплики в кавычках внутри таймлайна, с эмоцией и микрожестом рядом.
- Ответ второго начинай с «She replies:» / «He replies:» — иначе речь наложится.

## Микродрама
- Эмоции вплетай в биты: один бит — один эмоциональный переход («гнев нарастает»,
  «боль сменяется решимостью»).
- Микровыражения конкретные и мелкие: сжатая челюсть, прищур, вздрагивание.
- Эмоция → физическое действие с реальной физикой (удар по столу → сдвинулись стаканы).
- ОДИН тег актёрской игры в конце промпта, через запятые. Таймлайн остаётся
  компактным списком кадров, без абзаца прилагательных в начале.

## Правило выдачи
- Каждый промпт в своём блоке ``` — внутри только промпт.
- Несколько промптов — подписывай над блоком: «### Панель 1 — промпт Seedance».
