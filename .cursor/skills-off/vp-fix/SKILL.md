# /vp-fix <описание бага, лог или падающий тест>

Автопилот включён (`.cursor/rules/00-autonomy.mdc` §2). Короткий цикл без спеки и плана.

1. **Изоляция.** `superpowers:using-git-worktrees` → `.worktrees/fix-<тема>`, ветка
   `vp/fix-<тема>`. Python — `.venv` основного checkout.
2. **Причина.** Субагент `vp-debugger` (или сам по `superpowers:systematic-debugging`):
   симптом → воспроизведение → корневая причина с доказательством.
3. **Тест.** Падающий pytest, воспроизводящий баг (`superpowers:test-driven-development`).
   Убедись, что он падает по нужной причине. Коммит.
4. **Фикс.** Минимальное изменение в месте причины, не в месте симптома. Тест зелёный,
   тесты зоны зелёные (кроме записанных «падали до меня»). Коммит.
5. **Проверка.** Субагент `vp-verifier`; если трогал `app/`/`web/` — `vp-contract-reviewer`.
   Замечания → исправить (до 5 раундов).
6. **Отчёт:** причина (файл:строка) → тест → фикс → ветка/worktree → команды для
   человека (merge/push) → что проверить руками (перезапуск бэкенда, шаг в Studio).

Не воспроизводится без живых сервисов — остановись и опиши, что запустить и какие
логи прислать.
