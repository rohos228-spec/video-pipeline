# Шаблон 1: лист персонажа

Результат: сетка 8 кадров. Верхний ряд — 4 полных роста (спереди, сбоку, 3/4, сзади),
нижний ряд — 4 соответствующих крупных плана лица. Соотношение листа 16:9.

## Два важнейших правила
1. **Есть референсное изображение → НЕ описывай его словами.** Изображение и есть описание.
   Укажи только стиль визуализации (Режим A).
2. **Нейтральное освещение.** Никакого света конкретной сцены (лунный, огонь, неон) —
   лист используется во многих сценах. Только чистый равномерный студийный свет.
3. Всегда включай фразу: «Фон должен быть простым и не отвлекать от дизайна персонажа».

## Режим A — прикреплены референсные изображения
> Создай профессиональный референсный лист для прикреплённого персонажа, используя
> прикреплённые изображения как строгий референс, сходство 1:1, [ОПИСАНИЕ СТИЛЯ].
> Четыре вертикальных столбца = 8 кадров. Верхний ряд: полный рост с головы до ног
> (спереди, сбоку, 3/4, сзади), ступни видны, без кадрирования. Нижний ряд: 4 крупных
> плана лица под каждым ракурсом. Стиль: [БЛОК СТИЛЯ]. Фон простой, не отвлекает.
> Соотношение сторон: 16:9.

## Режим B — только текст, без референса
- Описание через запятую, **30–60 слов** (более 100 — ошибка).
- Только якоря идентичности: возраст, телосложение, лицо, волосы, ключевая одежда, реквизит.
- Запрещено: грязь, кровь, влажные волосы, искры, контровой свет — это детали сцены,
  они уходят в промпты кадров, а не в лист.

## Блок стиля (меняется только эстетика, без света сцены)
- Фотореализм: зеркальная камера, 35-мм плёнка, приглушённая гамма, не 3D-рендер.
- Pixar/3D: стилизованный 3D-рендер, мягкое глобальное освещение, без фотореализма.
- Аниме/2D: сел-шейдинг, чёткие линии, живописные фоны, без 3D.
- Нуар: ч/б, высокий контраст, жёсткая светотень, зерно 35 мм.
- Инфлюенсер/iPhone: естественный дневной свет, фронталка, без цветокора.

## Правило выдачи
- Промпт целиком в блоке ``` — без комментариев внутри.
