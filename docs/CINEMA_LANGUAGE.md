# Киноязык: планы, ракурсы, движения, монтаж — сборка перечислений

Суть простым языком. Один шот (кадр) собирается по формуле:

**ШОТ = ПЛАН (крупность) + РАКУРС + ДВИЖЕНИЕ КАМЕРЫ + ДВИЖЕНИЕ В КАДРЕ + ДЛИТЕЛЬНОСТЬ + ЗВУК**

Иерархия всего:

```
бит (было→стало) → шот → монтажная фраза → сцена → сиквенция (2–7 сцен) → акт → фильм
```

---

## 1. Планы (крупность, шкала Кулешова)

Эталон — фигура человека.

| # | План | Что в кадре | Смысл / функция |
|---|------|-------------|-----------------|
| 1 | Деталь (сверхкрупный) | глаз, рука, предмет | акцент, улика, ключ к смыслу |
| 2 | Крупный | лицо по плечи | эмоция, мысль, интимность, контакт со зрителем |
| 3 | 1-й средний (по пояс) | туловище по локти | жест + эмоция, основной план диалога |
| 4 | 2-й средний (по колено, «ковбойский») | фигура по колено | действие, готовность, напряжение тела |
| 5 | Общий | человек в полный рост | действие в пространстве, установка места |
| 6 | Дальний | фигура ≤ 1/7 кадра | среда важнее человека, масштаб, одиночество |
| 7 | Экстремально дальний | человек едва различим | «взгляд Бога», экспозиция мира |

**Закон:** чем крупнее план → тем сильнее эмоция и меньше контекст; чем дальше → тем больше контекст и меньше эмоция. Крупный план читается быстрее — ему нужно меньше экранного времени, чем общему.

## 2. Ракурсы (точка съёмки)

| Ракурс | Смысл |
|--------|-------|
| Нейтральный (уровень глаз) | объективность, равенство, «как в жизни» |
| Верхний (сверху вниз) | слабость, уязвимость, жертва, подчинение |
| Нижний (снизу вверх) | сила, власть, угроза, героизм; потолок «давит» |
| Птичий полёт (строго сверху) | судьба, схема события, незначительность человека |
| Голландский (завален горизонт) | тревога, безумие, дезориентация, «что-то не так» |
| Над плечом (OTS) | диалог, чужая точка зрения, вовлечение в разговор |
| POV (субъективный) | глаза героя, максимальная идентификация |
| Острый / нейтральный | сильное / слабое смещение точки — степень акцента |

**Закон:** ракурс управляет социальным весом: низ = доминирование, верх = подчинение.

## 3. Движение камеры

Два класса: **статика** (камера на месте: pan/tilt/roll/zoom) и **динамика** (камера едет: dolly/tracking/crane/steadicam).

| Движение | Как делается | Смысл |
|----------|--------------|-------|
| Панорама (pan) | поворот по горизонтали с места | обзор пространства, слежка, связь двух точек |
| Наклон (tilt) | поворот по вертикали с места | вверх — величие/угроза; вниз — слабость/падение |
| Ролл (roll) | вращение вокруг оси объектива | дезориентация, кризис |
| Наезд (dolly in) | камера едет к объекту | нарастание напряжения, погружение в мысль героя |
| Отъезд (dolly out) | камера едет от объекта | отчуждение, раскрытие контекста, типичный финал сцены |
| Зум (zoom in/out) | фокусное расстояние, камера стоит | резкий акцент, «дешёвое» напряжение, ретро-стиль |
| Контр-зум (dolly-zoom) | наезд + зум навстречу | шок, головокружение, «мир схлопнулся» («Вертиго») |
| Тревелинг (tracking) | езда вдоль/за объектом (рельсы, тележка) | сопровождение, путешествие, преследование |
| Краб-шот | плавный сдвиг вбок без поворота | наблюдение, обход, скрытое присутствие |
| Кран / лифт | перемещение по вертикали | подъём = взлёт, масштаб, свобода; спуск = падение, погружение |
| Арка (arc) | обход вокруг объекта | значимость момента, смена фона без склейки |
| Стедикам / гимбал | плавное следование за героем | «идём с героем», присутствие |
| Ручная камера | тряска, с плеча | документальность, хаос, тревога |
| Дрон | воздушные траектории | масштаб, свобода, экспозиция |

**Закон:** движение К объекту = нагнетание; ОТ объекта = разрядка. Мотивированное движение (за действием) незаметно; немотивированное — само становится смыслом.

## 4. Движение в кадре (мизансцена)

| Движение | Смысл |
|----------|-------|
| Вход в кадр | начало фазы действия; склейка «на входе» |
| Выход из кадра | конец фазы; склейка «на выходе» экономит время |
| Слева направо | лёгкость, развитие, «вперёд» |
| Справа налево | сопротивление, возврат, трудность |
| На камеру | напор, угроза |
| От камеры | уход, потеря, отчуждение |
| По диагонали | максимум динамики |
| Вверх / вниз | рост власти / падение |

**Жёсткие правила склейки:**
- **Правило 180°** — не пересекать ось действия, иначе герои «меняются местами» на экране.
- **Правило 30°** — между двумя планами одного объекта ракурс менять минимум на 30°, иначе «прыжок».
- **Правило Кулешова** — комфортный стык «через один план» (общий↔1-й средний, 2-й средний↔крупный). Исключения: крупный↔деталь и общий↔дальний стыкуются напрямую. При укрупнении — шаг в сторону (смена ракурса и фона).

## 5. Комбинации кадров в сцене (монтажные фразы)

Базовая схема эпизода (от Гриффита): **общий установочный → укрупнение на главный объект → развитие → возврат на общий** (ре-эстаблишинг).

| # | Фраза | Последовательность | Эффект |
|---|-------|--------------------|--------|
| 1 | Наступательная (сужение) | дальний → общий → средний → крупный → деталь | втягивание, нарастание, фокус на сути |
| 2 | Отступательная (расширение) | деталь → крупный → средний → общий → дальний | раскрытие контекста, разрядка, выход из сцены |
| 3 | Кольцевая | общий → … → крупный → … → общий | завершённость, «поставили точку» |
| 4 | Маятниковая (диалог) | shot/reverse shot: план А ↔ план Б, укрупнение к кульминации реплики | ритм перебивки, рост конфликта |
| 5 | Мастер-шот + врезки | общий всей сцены + cut-in (деталь внутри) + cut-away (реакция/предмет сбоку) | страховка монтажа, акценты без пересъёмки |
| 6 | Параллельная (кросс-каттинг) | линия А ↔ линия Б, чередование учащается к финалу | «тем временем…», саспенс, сближение линий |
| 7 | Контрастная | стык крайностей: дальний ↔ деталь, шум ↔ тишина | шок, монтаж аттракционов (Эйзенштейн) |
| 8 | Ассоциативная | действие + образ-сравнение | метафора, смысл рождается в стыке |
| 9 | Нарезка (montage) | серия коротких кадров одного процесса | сжатие времени (тренировка, дорога) |
| 10 | Match cut | склейка по форме/движению/взгляду | плавный переход между сценами/эпохами |
| 11 | Jump cut | скачок внутри одного плана | энергия, нерв, блогерский ритм |
| 12 | Smash cut | резкий обрыв на контрасте (крик → тишина) | комический или шоковый эффект |

## 6. Последовательность сцен

Сцена = единство места + времени + действия. Сцена работает, если на выходе **что-то изменилось** (заряд сцены: +/−).

| # | Схема связи сцен | Как работает |
|---|------------------|--------------|
| 1 | Линейная | A → B → C по причинно-следственной цепи |
| 2 | Параллельная | чередование 2+ линий, сходятся в кульминации |
| 3 | Инверсионная | флешбек / флешфорвард, начало с середины (in medias res) |
| 4 | Эллипсис | пропуск времени (затемнение, нарезка, диалоговый мост) |
| 5 | Звуковой мост | J-cut: звук новой сцены до картинки; L-cut: звук старой поверх новой |
| 6 | Контрастный стык | богатство↔нищета, смех↔трагедия |
| 7 | Смысловой мост | предмет/форма/движение связывает две сцены (match cut на уровне сцен) |
| 8 | Крючок | сцена обрывается на вопросе → ответ в следующей |

**Каркас (трёхактная структура):**

```
Акт I  (завязка, ~25%):      экспозиция → побуждающее событие → ППП (точка невозврата)
Акт II (конфронтация, ~50%): перипетии → ЦПП (перелом, ложная победа/поражение) → рост ставок → ФПП (кризис, «всё рушится»)
Акт III (развязка, ~25%):    кульминация → разрешение
```

Бит = минимальное событие «было → стало». Биты складываются в сцены, сцены — в сиквенции (мини-истории со своим поворотом), сиквенции — в акты.

## 7. Взаимосвязи (сводная матрица)

| Связь | Правило |
|-------|---------|
| План ↔ эмоция | крупность = дистанция до чувства: ближе = сильнее |
| Ракурс ↔ власть | низ = сила, верх = слабость, завал = тревога |
| Движение камеры ↔ энергия | к объекту = нагнетание, от объекта = разрядка |
| План ↔ длительность | чем крупнее план, тем короче он читается |
| Фраза ↔ арка сцены | вход — наступательная, выход — отступательная, диалог — маятниковая |
| Сцена ↔ бит | нет изменения «было→стало» — сцена лишняя |
| Сиквенция ↔ акт | каждая сиквенция заканчивается мини-поворотом, акт — крупным |

**Жанр ↔ типовой набор:**

| Жанр | Планы | Движение | Ракурсы |
|------|-------|----------|---------|
| Триллер | средние + крупные | медленные наезды, стедикам | нейтральные, изредка голландский |
| Экшен | общие + 2-й средний | тревелинг, ручная камера, резкие повороты | низкие, острые |
| Драма | 1-й средний + крупный | медленные панорамы, кран | нейтральные, верхние для слабости |
| Хоррор | детали + общие | краб-шот, медленный наезд | голландский, верхний, POV |
| Комедия | общие + средние | статика, минимум движения | нейтральные (играют тела, не камера) |

**Алгоритм сборки сцены:**
1. Определи бит сцены (что изменится: было → стало).
2. Выбери фразу (обычно: общий → развитие → крупный акцент → выход).
3. Разложи фразу в шоты: каждому шоту назначь план + ракурс + движение по таблицам выше.
4. Проверь стыки: 180°, 30°, «через один план».
5. Свяжи с соседними сценами: крючок, звуковой или смысловой мост.
