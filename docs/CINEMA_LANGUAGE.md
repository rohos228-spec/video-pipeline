# Киноязык — сборка перечислений

Как устроено: разделы 1–5 — детали (планы, ракурсы, движение камеры, движение в кадре, смыслы).
Раздел 6 — комбинации кадров в сцене. Раздел 7 — последовательность сцен. Раздел 8 — карта всех взаимосвязей.

Формула кадра: **КАДР = ПЛАН + РАКУРС + ДВИЖЕНИЕ КАМЕРЫ + ДВИЖЕНИЕ В КАДРЕ + ДЛИНА + ЗВУК**

Лестница сборки: **бит → кадр → фраза → сцена → сиквенция → акт → фильм**

---

## 1. ПЛАНЫ (крупность — сколько человека в кадре)

По шкале Кулешова, от близкого к дальнему:

- **Деталь** — глаз, рука, предмет → акцент, улика, ключ смысла
- **Крупный** — лицо по плечи → эмоция, мысль, интимность
- **Средний крупный** — по грудь → разговор «с глазу на глаз»
- **1-й средний** — по пояс → жест + эмоция, основной план диалога
- **2-й средний** — по колено («ковбойский») → готовность к действию
- **Общий** — человек в полный рост → действие в пространстве
- **Дальний** — человек маленький (≤1/7 кадра) → среда важнее человека
- **Сверхдальний** — человек-точка → масштаб мира, «взгляд Бога»

Функциональные планы (роль кадра в сцене):

- **Установочный** — первый кадр сцены, показывает где и когда
- **Мастер-шот** — вся сцена одним общим планом, страховка для монтажа
- **Двойной** — два героя вместе → отношения
- **Над плечом (OTS)** — через плечо одного на другого → вовлечение в диалог
- **POV** — камера = глаза героя → «я — герой»
- **Врезка (insert)** — деталь из основного кадра (письмо, экран) → «смотри сюда»
- **Перебивка (cutaway)** — то, чего нет в кадре (часы, собака) → комментарий, маскировка склейки
- **Реакция** — лицо слушающего → отклик важнее реплики

Законы планов:

- Ближе = сильнее эмоция, меньше контекст. Дальше = наоборот.
- Крупный план читается быстро — ему хватает 1–2 секунд. Общему нужно больше.
- Деталь без общего плана = загадка. Общий без детали = безразличие.

---

## 2. РАКУРСЫ (откуда смотрит камера)

По высоте:

- **Птичий (строго сверху)** → судьба, схема события, человек-муравей
- **Верхний** → слабость, жертва, подчинение
- **Уровень глаз** → равенство, объективность
- **Уровень пояса** → лёгкое усиление героя
- **Нижний** → сила, власть, угроза
- **С земли** → монументальность, среда давит

По углу:

- **Фронтальный (анфас)** → прямой контакт, откровенность
- **3/4** → естественность, самый рабочий ракурс
- **Профиль** → отстранённость, герой «в себе»
- **Со спины** → тайна, уход
- **Голландский (завален горизонт)** → тревога, безумие, «что-то не так»

Законы ракурсов:

- Низ = доминирование. Верх = подчинение. Завал = тревога.
- Голландский угол — специя: только дозированно.
- Между склейками ракурс менять минимум на 30° (иначе картинка «прыгает»).

---

## 3. ДВИЖЕНИЕ КАМЕРЫ

Камера стоит (крутится на месте):

- **Панорама (влево/вправо)** → обзор, слежка, связь двух точек
- **Наклон (вверх/вниз)** → вверх = величие, вниз = слабость
- **Ролл (вращение)** → дезориентация
- **Зум (приближение без езды)** → резкий акцент, нерв, ретро

Камера едет:

- **Наезд (к объекту)** → нагнетание, погружение в мысль
- **Отъезд (от объекта)** → разрядка, отчуждение, финал сцены
- **Тревелинг (вдоль/за объектом)** → сопровождение, погоня
- **Краб (вбок)** → наблюдение, скрытое присутствие
- **Подводка (навстречу идущему)** → встреча, сближение
- **Проводка (вслед уходящему)** → потеря, «герой уходит»
- **Кран вверх** → взлёт, масштаб, свобода
- **Кран вниз** → падение, погружение
- **Арка (обход по дуге)** → значимость момента
- **Облёт 360°** → кульминация чувства, «время остановилось»
- **Стедикам/гимбал** → «идём с героем»
- **Ручная камера (тряска)** → хаос, документальность, паника
- **Дрон** → масштаб, свобода

Трюки:

- **Контр-зум (ездa + зум навстречу)** → шок, «мир схлопнулся»
- **Whip pan (резкий рывок со смазом)** → энергичный переход
- **Скрытая склейка (через тёмный объект)** → эффект одного дубля

Законы движения:

- К объекту = нагнетание. От объекта = разрядка.
- Движение за действием — незаметно. Движение без причины — само становится смыслом.
- Медленное движение = драма. Резкое = паника.
- Движение начинается и кончается в статике (точки покоя).

---

## 4. ДВИЖЕНИЯ В КАДРЕ (мизансцена)

- **Вход в кадр** → начало действия
- **Выход из кадра** → конец действия (склейка на выходе экономит время)
- **Слева направо** → легко, «вперёд»
- **Справа налево** → трудно, «назад»
- **На камеру** → угроза, напор
- **От камеры** → уход, потеря
- **По диагонали** → максимум динамики
- **Вверх** → рост власти
- **Вниз** → падение
- **По кругу** → тупик, цикл

Композиция (где стоит объект в кадре):

- **Трети** (объект на линиях сетки 3×3) → гармония
- **Центр, симметрия** → мощь, ритуал, одержимость
- **Ведущие линии** (дорога, стены) → ведут взгляд к объекту
- **Рамка в рамке** (дверь, окно) → ловушка, изоляция
- **Воздух перед лицом** → куда смотрит/идёт — там запас кадра
- **Нет воздуха над головой** → давление, тревога
- **Пустой кадр вокруг** → одиночество
- **Забитый кадр** → хаос

---

## 5. СМЫСЛЫ (что хочешь → что ставишь)

Прямой справочник «задача → решение»:

- Хочу **эмоцию** → крупный план
- Хочу **контекст** → общий или дальний
- Хочу **силу героя** → нижний ракурс + центр кадра
- Хочу **слабость** → верхний ракурс + мало воздуха над головой
- Хочу **тревогу** → голландский угол + медленный наезд + тишина
- Хочу **напряжение** → медленный наезд + длинный кадр
- Хочу **разрядку** → отъезд + общий план
- Хочу **хаос** → ручная камера + короткие кадры
- Хочу **спокойствие** → статика + длинный кадр
- Хочу **одиночество** → дальний план + пустой кадр
- Хочу **шок** → контрастный стык (дальний↔деталь) или smash cut
- Хочу **интимность** → крупный + уровень глаз + статика
- Хочу **ностальгию** → наплыв + медленный отъезд
- Хочу **торжество** → кран вверх + дальний план
- Хочу **панику** → нарастающая нарезка (кадры всё короче)
- Хочу **саспенс** → зритель знает угрозу, герой нет + перебивки на угрозу

Обратный справочник «решение → эффект»:

- Крупность ↑ → эмоция ↑, контекст ↓
- Ракурс ниже → персонаж сильнее
- Камера к объекту → нарастание
- Камера от объекта → разрядка
- Кадр короче → энергия ↑
- Кадр длиннее → напряжение/созерцание ↑
- Тишина перед звуком → удар громче

## 6. КОМБИНАЦИИ КАДРОВ В СЦЕНЕ (главный раздел)

Обозначения: Дт=деталь, К=крупный, С=средний, О=общий, Д=дальний.

### 6.1. По направлению крупности

1. **Наступательная**: Д → О → С → К → Дт — втягивание, нарастание
2. **Отступательная**: Дт → К → С → О → Д — раскрытие контекста, выход из сцены
3. **Кольцевая**: О → С → К → С → О — завершённость, «точка»
4. **Волна**: О → С → О → К → О — спокойное развитие, «прибой-отлив»
5. **Контрастная**: Д ↔ Дт — шок, стык крайностей

### 6.2. По драматургии

6. **Маятник (диалог)**: план А ↔ план Б, к кульминации реплики укрупнить — ритм перебивки
7. **Мастер + врезки**: общий всей сцены + детали (cut-in) + перебивки (cutaway) — страховка монтажа
8. **Действие → реакция**: событие → лицо → событие — эмоция важнее события
9. **Параллель (кросс-каттинг)**: линия А ↔ линия Б, чередование учащается — «тем временем», саспенс
10. **Метафора**: действие + образ-сравнение — смысл рождается в стыке
11. **Нарезка**: много коротких кадров одного процесса — сжатие времени (тренировка, дорога)
12. **Эффект Кулешова**: одно лицо + разные предметы = разные эмоции — смысл делает соседний кадр
13. **Нарастающая**: кадры всё короче к концу — ускорение, кульминация
14. **Замедляющая**: кадры всё длиннее — осмысление, «после качки»

### 6.3. Особые стыки

15. **Match cut** — склейка по форме/движению (костёр → солнце) — плавный прыжок между мирами
16. **Jump cut** — скачок внутри одного плана — нерв, блогерский ритм
17. **Smash cut** — резкий обрыв на контрасте (крик → тишина) — шок или смех
18. **J-cut** — звук новой сцены до картинки — мягкий вход
19. **L-cut** — звук старой сцены над новой картинкой — эхо, связь

### 6.4. Правила стыков (техника безопасности)

- **180°** — не перепрыгивать линию между героями, иначе они поменяются местами
- **30°** — соседние планы одного объекта снимать с разницы минимум 30°
- **Через один план** (Кулешов) — комфортные стыки: О↔1С, 2С↔К; исключения: К↔Дт, О↔Д
- **По движению** — резать в середине жеста, стык невидим
- **По взгляду** — герой смотрит за кадр → следующий кадр показывает, на что
- **Шаг в сторону** — при укрупнении подойти и сместиться: меняется фон, склейка гладче

### 6.5. Готовые разбивки сцен

**Диалог двух героев** — 7 камер:

1. Мастер (оба, вся сцена)
2. OTS на А
3. OTS на Б
4. Чистый план А
5. Чистый план Б
6. Врезки (руки, предметы, экран)
7. Перебивки (окно, часы)
Монтаж: мастер → маятник OTS → укрупнение на пике → выход на общий

**Экшен**:

- Общий план на каждый новый шаг (география читается всегда)
- Крупные — только на ударах и лицах
- Резать по движению, не по паузе
- Кадры короче к концу сцены
- Один длинный дубль среди нарезки — передышка

**Саспенс (Хичкок)**:

1. Зритель знает об угрозе, герой — нет
2. Перебивки на угрозу между бытовыми планами
3. Медленный наезд = приближение развязки
4. Растянуть время: 10 секунд жизни → минута экрана
5. Разрядка — обнаружение, а не взрыв
(сюрприз = 15 секунд шока; саспенс = 15 минут напряжения)

## 7. ПОСЛЕДОВАТЕЛЬНОСТЬ СЦЕН

Сцена = одно место + одно время + одно действие. Сцена живая, если на выходе что-то изменилось (было → стало).

### 7.1. Типы сцен

- **Экспозиционная** — вводит мир и героя
- **Побуждающая** — событие-толчок
- **Развивающая** — попытка → препятствие → результат
- **Поворотная** — меняет направление истории
- **Кульминационная** — главное столкновение
- **Разрешающая** — последствия, новая жизнь
- **Переходная** — связка (самая слабая, резать первой)

### 7.2. Схемы связи сцен

1. **Линейная** — A → B → C по причине-следствию
2. **Параллельная** — две линии чередуются, сходятся в кульминации
3. **Инверсионная** — флешбек/флешфорвард, начало с середины
4. **Рамочная** — история внутри истории, конец = начало
5. **Эллипсис** — пропуск времени (затемнение, нарезка)
6. **Звуковой мост** — J/L-cut между сценами
7. **Контрастный стык** — богатство↔нищета, шум↔тишина
8. **Смысловой мост** — предмет/фраза связывает сцены
9. **Крючок** — сцена обрывается на вопросе, ответ в следующей
10. **Эхо** — сцена повторяет раннюю с изменением — виден рост героя

### 7.3. Каркасы (из чего собирается фильм)

**Три акта:**

- Акт 1 (25%): экспозиция → толчок → точка невозврата (ППП)
- Акт 2 (50%): препятствия → перелом посередине (ЦПП) → кризис «всё рушится» (ФПП)
- Акт 3 (25%): кульминация → развязка

**15 битов (Save the Cat):**

1. Открывающий образ — герой «до»
2. Тема вслух
3. Установка мира
4. Катализатор — старая жизнь опрокинута
5. Дебаты — «а надо ли?»
6. Переход в акт 2 — герой сам решает
7. Линия Б — второй сюжет (отношения)
8. Развлечения — «сцены из трейлера»
9. Середина — ложная победа/поражение
10. Враги наступают
11. Всё потеряно — дно
12. Тёмная ночь души — герой находит ответ
13. Переход в акт 3 — линии А+Б сливаются
14. Финал — герой применяет усвоенное
15. Финальный образ — зеркало первого, доказательство изменения

**Путь героя (12 стадий):** обычный мир → зов → отказ → наставник → порог → тесты/союзники/враги → приближение → смертельное испытание → награда → обратная дорога → воскрешение → возвращение

**8 сиквенций:** фильм = 8 мини-фильмов по 10–15 минут, у каждой своя цель и свой поворот в конце

### 7.4. Законы последовательности

- Сцена без изменения = лишняя сцена
- Входить в сцену поздно, выходить рано
- Каждая сцена отвечает на один вопрос зрителя и задаёт следующий
- Каждая сиквенция кончается мини-поворотом, акт — крупным

## 8. КАРТА ВСЕХ ВЗАИМОСВЯЗЕЙ

### 8.1. Общая схема

```
СМЫСЛ (что хочу сказать)
   ↓ выбирает
ПЛАН + РАКУРС + ДВИЖЕНИЕ КАМЕРЫ + ДВИЖЕНИЕ В КАДРЕ
   ↓ собираются в
ФРАЗА (комбинация кадров)
   ↓ фразы собираются в
СЦЕНА (бит: было → стало)
   ↓ сцены связываются в
СИКВЕНЦИЯ → АКТ → ФИЛЬМ
```

### 8.2. Пары связей

- **План ↔ смысл**: крупность = дистанция до эмоции (ближе = сильнее)
- **Ракурс ↔ власть**: низ = сила, верх = слабость, завал = тревога
- **Движение камеры ↔ энергия**: к объекту = нагнетание, от = разрядка
- **Движение в кадре ↔ направление сюжета**: вправо = вперёд, влево = назад
- **Композиция ↔ внимание**: трети = гармония, центр = мощь, рамка = ловушка
- **План ↔ длина кадра**: крупный читается быстро, общий медленно
- **Длина кадра ↔ ритм**: короткий = агрессия, длинный = созерцание
- **Фраза ↔ роль в сцене**: вход = наступательная, выход = отступательная, диалог = маятник
- **Переход ↔ смысл**: склейка = «и», наплыв = «потом», затемнение = «конец главы»
- **Сцена ↔ бит**: нет «было→стало» — сцена мертва
- **Сиквенция ↔ акт**: сиквенция = мини-поворот, акт = крупный поворот
- **Звук ↔ картинка**: контрапункт (нежное на жестоком) сильнее синхрона

### 8.3. Жанр ↔ набор приёмов

- **Триллер**: средние+крупные, медленные наезды, наступательная фраза, параллель
- **Экшен**: общие+2-й средний, тревелинг+ручная, контрастная фраза, нарезка
- **Драма**: 1-й средний+крупный, панорамы+кран, маятник, реакция
- **Хоррор**: детали+общие, краб+медленный наезд, голландский, smash cut
- **Комедия**: общие+средние, статика, мастер+врезки, smash cut
- **Мелодрама**: крупный, стедикам+арка, волна, наплывы
- **Вертикаль 9:16 (Shorts/Reels)**: крупный+MCU база, хук в 1-ю секунду, кадры 1–3 сек, jump cut — норма, нижняя треть кадра занята интерфейсом

### 8.4. Эмоция ↔ рецепт кадра

- **Тревога** = крупный + голландский + медленный наезд + тишина
- **Одиночество** = дальний + пустой кадр + статика + длинно
- **Мощь** = нижний + центр + tilt вверх
- **Паника** = ручная + короткие кадры + нарастающая нарезка
- **Интимность** = крупный + уровень глаз + статика
- **Ностальгия** = наплыв + медленный отъезд
- **Шок** = smash cut или контр-зум + резкий звук
- **Торжество** = кран вверх + дальний

## 9. АЛГОРИТМ СБОРКИ СЦЕНЫ (7 шагов)

1. **Бит** — что изменится: было → стало. Нет изменения — сцена не нужна.
2. **Фраза** — выбрать схему из раздела 6 (обычно: общий → развитие → крупный акцент → выход).
3. **Кадры** — каждому назначить: план + ракурс + движение камеры + движение в кадре + длину.
4. **Стыки** — проверить: 180°, 30°, «через один план», рез по движению.
5. **Переходы** — расставить знаки препинания: склейка / наплыв / затемнение.
6. **Связи** — крючок на выходе, звуковой или смысловой мост на входе.
7. **Ритм** — кадры короче к кульминации сцены, длинный кадр после пика.

## 10. ТИПИЧНЫЕ ОШИБКИ

- Склейка соседних крупностей без смены ракурса → лечится правилом 30°
- Пересечение оси 180° → камера всегда по одну сторону линии
- Сцена без изменения → вырезать или добавить бит
- Установочный план в каждой сцене → входить сразу в действие
- Движение камеры без причины → мотивировать действием или статика
- Все кадры одинаковой длины → ритм-волна: короткое ↔ длинное
- Всё снято одним средним планом → обязательный минимум: общий + крупный + деталь
- Голландский угол «для красоты» → только для тревоги
- Музыка вместо эмоции → сцена должна работать без звука
- Деталь, которая не стреляет → показал ружьё — выстрели (Чехов)
