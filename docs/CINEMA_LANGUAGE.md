# Киноязык — база знаний для LLM + алгоритм раскадровки

Назначение файла: LLM читает его целиком и дальше умеет (1) оперировать всеми типами данных по их ID, (2) соотносить типы друг с другом по матрицам, (3) идти по цепочке анализа от смысла к кадрам, (4) выдавать раскадровку в шаблоне из раздела 8.

Порядок чтения = порядок работы:

```
РАЗДЕЛ 1: словари сущностей (П, Р, М, Д, К, Э, Т) — «алфавит»
РАЗДЕЛ 2: матрицы связей — «грамматика», что с чем сочетается
РАЗДЕЛ 3: каталог комбинаций кадров (Ф) — «готовые фразы»
РАЗДЕЛ 4: правила валидации — «техника безопасности»
РАЗДЕЛ 5: последовательность сцен — «синтаксис» уровнем выше
РАЗДЕЛ 6: цепочка анализа — пошаговый алгоритм
РАЗДЕЛ 7: чек-лист самопроверки
РАЗДЕЛ 8: шаблон раскадровки + пример — ВЫХОД
```

## 1. СЛОВАРИ СУЩНОСТЕЙ (типы данных)

Каждая сущность имеет ID. Дальше везде используются только ID.

### 1.1. Планы — код `П` (крупность, сколько человека в кадре)

- `П1` **Деталь** — глаз, рука, предмет → акцент, улика
- `П2` **Крупный** — лицо по плечи → эмоция, мысль
- `П3` **Средний крупный** — по грудь → разговор с глазу на глаз
- `П4` **1-й средний** — по пояс → жест + эмоция, база диалога
- `П5` **2-й средний** — по колено → готовность к действию
- `П6` **Общий** — в полный рост → действие в пространстве
- `П7` **Дальний** — человек ≤1/7 кадра → среда важнее человека
- `П8` **Сверхдальний** — человек-точка → масштаб мира

Функциональные роли кадра (надбавка к плану, код `р`):

- `р1` установочный, `р2` мастер-шот, `р3` двойной, `р4` над плечом (OTS), `р5` POV, `р6` врезка (insert), `р7` перебивка (cutaway), `р8` реакция

### 1.2. Ракурсы — код `Р` (откуда смотрит камера)

По высоте:

- `Р1` **Птичий** (строго сверху) → судьба, схема события
- `Р2` **Верхний** → слабость, жертва
- `Р3` **Уровень глаз** → равенство, объективность
- `Р4` **Уровень пояса** → лёгкое усиление
- `Р5` **Нижний** → сила, власть, угроза
- `Р6` **С земли** → монументальность, среда давит

По углу:

- `Р7` **Фронтальный** → прямой контакт
- `Р8` **3/4** → естественность (рабочий по умолчанию)
- `Р9` **Профиль** → отстранённость
- `Р10` **Со спины** → тайна, уход
- `Р11` **Голландский** (завален горизонт) → тревога, безумие
- `Р12` **OTS** (через плечо) → вовлечение в диалог
- `Р13` **POV** (глаза героя) → идентификация

### 1.3. Движение камеры — код `М`

Камера стоит:

- `М1` **Статика** → объективность, спокойствие
- `М2` **Панорама** (поворот ↔) → обзор, слежка
- `М3` **Наклон** (поворот ↕) → вверх=величие, вниз=слабость
- `М4` **Ролл** (вращение) → дезориентация
- `М5` **Зум** (без езды) → резкий акцент, нерв

Камера едет:

- `М6` **Наезд** → нагнетание, погружение в мысль
- `М7` **Отъезд** → разрядка, отчуждение, финал сцены
- `М8` **Тревелинг** (вдоль/за) → сопровождение, погоня
- `М9` **Краб** (вбок) → наблюдение, скрытое присутствие
- `М10` **Подводка** (навстречу) → встреча
- `М11` **Проводка** (вслед) → уход, потеря
- `М12` **Кран вверх** → взлёт, торжество
- `М13` **Кран вниз** → падение, погружение
- `М14` **Арка** (обход по дуге) → значимость момента
- `М15` **Облёт 360°** → кульминация чувства
- `М16` **Стедикам** (следование) → «идём с героем»
- `М17` **Ручная** (тряска) → хаос, документальность
- `М18` **Дрон** → масштаб, свобода

Трюки:

- `М19` **Контр-зум** → шок, «мир схлопнулся»
- `М20` **Whip pan** (рывок со смазом) → энергичный переход

### 1.4. Движение в кадре — код `Д` (мизансцена)

- `Д1` **Вход в кадр** → начало действия
- `Д2` **Выход из кадра** → конец действия
- `Д3` **Слева направо** → легко, «вперёд»
- `Д4` **Справа налево** → трудно, «назад»
- `Д5` **На камеру** → угроза
- `Д6` **От камеры** → потеря
- `Д7` **По диагонали** → максимум динамики
- `Д8` **Вверх** → рост власти
- `Д9` **Вниз** → падение
- `Д10` **По кругу** → тупик, цикл
- `Д11` **Статика в кадре** → наблюдение

### 1.5. Композиция — код `К`

- `К1` **Трети** → гармония (по умолчанию)
- `К2` **Центр/симметрия** → мощь, ритуал
- `К3` **Ведущие линии** → взгляд ведут к объекту
- `К4` **Рамка в рамке** (дверь, окно) → ловушка, изоляция
- `К5` **Воздух по взгляду/движению** → запас куда смотрят/идут
- `К6` **Мало воздуха над головой** → давление
- `К7` **Пустота вокруг** → одиночество
- `К8` **Забитый кадр** → хаос

### 1.6. Эмоции/смыслы — код `Э` (цель кадра или сцены)

- `Э1` Интимность, эмоция
- `Э2` Контекст, экспозиция
- `Э3` Сила, доминирование
- `Э4` Слабость, жертва
- `Э5` Тревога
- `Э6` Напряжение, нагнетание
- `Э7` Разрядка, облегчение
- `Э8` Хаос, паника
- `Э9` Спокойствие
- `Э10` Одиночество
- `Э11` Шок
- `Э12` Ностальгия, лирика
- `Э13` Торжество
- `Э14` Саспенс (ожидание угрозы)
- `Э15` Комичность
- `Э16` Тайна, загадка

### 1.7. Переходы — код `Т` (знаки препинания)

- `Т1` **Склейка** — «и» (70–80% всех стыков)
- `Т2` **Наплыв** — «потом / вспомнил»
- `Т3` **Затемнение** — «конец главы»
- `Т4` **Вытеснение** — стилизация, ретро
- `Т5` **J-cut** — звук новой сцены до картинки
- `Т6` **L-cut** — звук старой поверх новой
- `Т7` **Match cut** — склейка по форме/движению
- `Т8` **Smash cut** — резкий обрыв на контрасте
- `Т9` **Jump cut** — скачок внутри плана
- `Т10` **Скрытая склейка** — через смаз/темноту

### 2.4. План ↔ Движение камеры (совместимость)

Хорошие пары:

- `П1` деталь + `М6` наезд / `М1` статика (деталь не тревелить — потеряется)
- `П2` крупный + `М6` наезд / `М1` / `М16`
- `П4`–`П5` средние + `М8` тревелинг / `М10` / `М11` / `М16`
- `П6` общий + `М8` / `М12` / `М14` / `М16`
- `П7`–`П8` дальние + `М12` кран / `М18` дрон / `М2` панорама

Плохие пары (не ставить):

- `П1` + `М8`/`М18` — деталь не читается в езде и издалека
- `П8` + `М6` — наезд на сверхдальнем бессмысленно долгий

### 2.5. План ↔ Длительность кадра

- `П1`–`П2`: 0.5–2 сек (читается мгновенно)

- `П7`–`П8`: 5–10 сек
- Вертикаль 9:16 (Shorts/Reels): любой кадр 1–3 сек, хук — первая секунда

### 2.6. Жанр → набор (Э, П, Р, М, Ф)

- **Триллер**: `П2 П3 П4` + `Р3 Р11` + `М6 М16` + фразы `Ф1 Ф11`
- **Экшен**: `П5 П6` + `Р5 Р8` + `М8 М17 М20` + `Ф5 Ф15`
- **Драма**: `П2 П4` + `Р3 Р2` + `М2 М12` + `Ф8 Ф10`
- **Хоррор**: `П1 П6` + `Р11 Р2 Р13` + `М9 М6` + `Ф2 Ф19`
- **Комедия**: `П5 П6` + `Р3 Р7` + `М1` + `Ф9 Ф20`
- **Мелодрама**: `П2 П3` + `Р3 Р8` + `М14 М16` + `Ф4 Ф21`
- **Вертикаль 9:16**: `П1 П2 П3` + `Р3 Р7` + `М1 М6` + `Ф26 Ф27`

## 3. КАТАЛОГ КОМБИНАЦИЙ КАДРОВ — код `Ф` (монтажные фразы)

Формат: `Ф-код` название — формула из П-кодов — эффект — когда ставить.

### 3.1. По направлению крупности

- `Ф1` **Наступательная** — `П7→П6→П4→П2→П1` — втягивание, нарастание — вход в сцену, приближение к сути
- `Ф2` **Отступательная** — `П1→П2→П4→П6→П7` — раскрытие контекста, разрядка — выход из сцены, reveal
- `Ф3` **Кольцевая** — `П6→П4→П2→П4→П6` — завершённость — сцена-диалог целиком
- `Ф4` **Волна** — `П6→П4→П6→П2→П6` — спокойное дыхание — лирика, созерцание
- `Ф5` **Контрастная** — `П7↔П1` — шок от скачка — акцент-вспышка, эйзенштейновский стык
- `Ф6` **Ступенчатая** — `П6→П4→П3→П2` (по одному шагу шкалы) — максимально гладко — драма, интервью
- `Ф7` **Зигзаг** — `П2→П6→П2→П6` — качели эмоция↔контекст — герой на фоне события

### 3.2. По драматургии

- `Ф8` **Маятник (диалог)** — `П4(А)↔П4(Б)`, на пике `П2(А)↔П2(Б)` — ритм перебивки — любой разговор
- `Ф9` **Мастер + врезки** — `П6(р2)` + `П1(р6)` + `р7` — страховка, акценты — сцены с предметами/документами
- `Ф10` **Действие → реакция** — событие `П4` → лицо `П2(р8)` → событие — эмоция важнее события — новости, признания
- `Ф11` **Параллель (кросс-каттинг)** — линия А ↔ линия Б, учащаясь — «тем временем», саспенс — погони, гонка со временем
- `Ф12` **Метафора** — действие + образ-сравнение — смысл в стыке — авторский акцент
- `Ф13` **Нарезка** — 6–12 коротких кадров процесса — сжатие времени — тренировка, дорога, сборы
- `Ф14` **Эффект Кулешова** — `П2` лицо + `П1` предмет А / то же лицо + предмет Б — смысл делает соседний кадр — экономия актёрской игры
- `Ф15` **Нарастающая** — кадры 4с→3с→2с→1с→0.5с — ускорение к пику — кульминация сцены
- `Ф16` **Замедляющая** — кадры 1с→2с→4с→8с — остановка после пика — «после взрыва», осмысление

### 3.3. Ситуативные схемы (готовые рецепты сцен)

- `Ф17` **Reveal** — `П1` деталь → `М7` отъезд → `П6` контекст — «о, так вот что это было» — открытие сцены, твист
- `Ф18` **Погоня** — `Ф11` параллель + `М8` тревелинг обеих линий + `Д3` у одного, `Д4` у другого — скорость и геометрия — экшен
- `Ф19` **Саспенс (Хичкок)** — зритель знает угрозу, герой нет: `П6` быт ↔ `П1(р7)` угроза, `М6` на героя — растянутое ожидание — триллер/хоррор
- `Ф20` **Комедийная** — `П6(р2)` статика + игра телами + `Т8` smash cut на панчлайне — не мешать актёрам — комедия
- `Ф21` **Романтическая** — `П3` двойной + `М14` арка + `П2` по очереди — кружение, близость — мелодрама
- `Ф22` **Хоррор-выход** — `М9` краб за героем + `П1` деталь + пауза + `Т8` — скрытое присутствие → скример
- `Ф23` **Сон/воспоминание** — `Т2` наплыв вход + `Р13` POV + `Т2` выход — отделить от реальности — флешбеки
- `Ф24` **Путешествие** — `П7`+`М8` слева направо `Д3` × 3–4 локации — движение сюжета — переезды, походы
- `Ф25` **Вход в новое место** — `П7(р1)` установочный → `П1`×2–3 детали места → `П6` герой в нём — география за 4 кадра — любая смена локации
- `Ф26` **Хук-вертикаль** — `П1`/`П2` с движением в 1-ю секунду → `Т9` jump cuts по 1–3 сек — удержание в фиде — Shorts/Reels/TikTok
- `Ф27` **Инфо-подача** — `П3` говорящий + `П1(р6)` врезки фактов — сухое, но быстро — объяснения, новости
- `Ф28` **Один дубль** — `М16` стедикам через всю сцену, `Т10` скрытые склейки — эффект присутствия — гордость режиссёра
- `Ф29` **Уход героя** — `М11` проводка + `П6→П7` + `М7` отъезд — потеря, финал — концовки сцен и фильма
- `Ф30` **Бой/танец** — `П6` статика на связки + `П2` на ударах + `Ф15` ускорение — читаемость + энергия — экшен, музномер

### 3.4. Особые стыки (внутри любой фразы)

- `Т7` match cut — по форме/движению/взгляду — прыжок между мирами/эпохами
- `Т8` smash cut — крик → тишина — шок или смех
- `Т9` jump cut — скачок в плане — нерв, блог-ритм
- `Т5`/`Т6` J/L-cut — звук раньше/позже картинки — мягкая сшивка
- `Т10` скрытая — через смаз/стену — «один дубль»

## 4. ПРАВИЛА ВАЛИДАЦИИ (проверять каждую цепочку кадров)

- `В1` **180°** — камера всегда по одну сторону линии между героями; нарушение = герои меняются местами
- `В2` **30°** — соседние кадры одного объекта: разница ракурса ≥ 30°
- `В3` **Через один план** (Кулешов) — комфортные стыки: `П6↔П4`, `П5↔П2`; прямые исключения: `П2↔П1`, `П6↔П7`
- `В4` **Рез по движению** — стык в середине жеста, не в паузе
- `В5` **Рез по взгляду** — смотрит за кадр → следующий кадр = на что смотрит
- `В6` **Шаг в сторону** — при укрупнении сместить камеру: меняется фон, стык гладче
- `В7` **Движение с точками покоя** — `М`-кадр начинается и кончается в статике
- `В8` **Направление экрана** — у преследователя и жертвы в `Ф11`/`Ф18` направления `Д` должны совпадать (оба `Д3`) или встречаться (`Д3` vs `Д4`) — по смыслу
- `В9` **Длина по плану** — длительность из матрицы 2.5
- `В10` **Ружьё Чехова** — каждая `П1` деталь должна «выстрелить» позже

## 5. ПОСЛЕДОВАТЕЛЬНОСТЬ СЦЕН

Сцена = место + время + действие. Живая сцена: на выходе изменилось «было → стало» (бит).

### 5.1. Типы сцен — код `С`

- `С1` экспозиционная, `С2` побуждающая, `С3` развивающая, `С4` поворотная, `С5` кульминационная, `С6` разрешающая, `С7` переходная (резать первой)

### 5.2. Схемы связи сцен — код `Л`

- `Л1` линейная (причина→следствие)
- `Л2` параллельная (линии сходятся в кульминации)
- `Л3` инверсионная (флешбек/флешфорвард, in medias res)
- `Л4` рамочная (конец = начало)
- `Л5` эллипсис (пропуск времени)
- `Л6` звуковой мост (`Т5`/`Т6` между сценами)
- `Л7` контрастный стык (богатство↔нищета)
- `Л8` смысловой мост (предмет/фраза связывает)
- `Л9` крючок (обрыв на вопросе → ответ в следующей)
- `Л10` эхо (повтор ранней сцены с изменением)

### 5.3. Каркасы — код `Х`

- `Х1` **Три акта**: экспозиция→толчок→ППП (25%) | препятствия→ЦПП→кризис ФПП (50%) | кульминация→развязка (25%)
- `Х2` **15 битов (Save the Cat)**: образ → тема → установка → катализатор → дебаты → вход в акт 2 → линия Б → развлечения → середина → враги наступают → всё потеряно → тёмная ночь → вход в акт 3 → финал → финальный образ
- `Х3` **Путь героя (12)**: обычный мир → зов → отказ → наставник → порог → тесты → приближение → испытание → награда → обратный путь → воскрешение → возвращение
- `Х4` **8 сиквенций**: фильм = 8 мини-фильмов, у каждой своя цель + поворот

### 5.4. Законы

- Сцена без бита = лишняя
- Входить поздно, выходить рано
- Каждая сцена отвечает на один вопрос зрителя и задаёт следующий
- Сиквенция кончается мини-поворотом, акт — крупным

## 6. ЦЕПОЧКА АНАЛИЗА (порядок работы LLM)

Вход: текст сцены / закадровый текст / идея. Идти строго по шагам, ничего не пропуская.

**ШАГ 1. Бит.** Сформулируй «было → стало». Нет изменения — стоп, сцена мертва (`5.4`).

**ШАГ 2. Эмоция.** Выбери 1–2 кода `Э` (цель сцены) и тип сцены `С`.

**ШАГ 3. Фраза.** По `Э` и `С` выбери `Ф` из каталога (раздел 3). По умолчанию: вход `Ф1`, диалог `Ф8`, выход `Ф2`/`Ф29`.

**ШАГ 4. Разворот в кадры.** Каждому кадру фразы назначь коды:
`П` (из матрицы 2.1) + `Р` (2.2) + `М` (2.3, проверить совместимость 2.4) + `Д` + `К` + длительность (2.5).

**ШАГ 5. Валидация.** Прогнать цепочку по правилам `В1`–`В10`. Нарушение → поменять кадр, не правило.

**ШАГ 6. Переходы и ритм.** Расставить `Т` между кадрами; проверить волну длительностей (к пику — короче, после пика — длинный).

**ШАГ 7. Связи сцен.** Выбрать `Л` к предыдущей и следующей сцене; на выходе — `Л9` крючок по умолчанию.

**ШАГ 8. Выход.** Выписать раскадровку строго по шаблону раздела 8.

## 8. ВЫХОД: ШАБЛОН РАСКАДРОВКИ

### 8.1. Формат (каждый кадр — одна строка)

```
КАДР <№> | П<n> <название> | Р<n> <ракурс> | М<n> <камера> | Д<n> <в кадре> | К<n> <композиция> | <сек> сек | звук: <что слышно> | переход: Т<n>
   содержание: <что видим, 1 фраза>
```

### 8.2. Пример раскадровки (сцена «герой находит письмо», бит: спокойствие → тревога; Э6; С3; фраза Ф1)

```
КАДР 1 | П7 дальний | Р3 уровень глаз | М1 статика | Д1 вход | К1 трети | 4 сек | звук: улица, дождь | переход: Т1
   содержание: подъезд, герой входит в кадр слева
КАДР 2 | П6 общий | Р8 3/4 | М16 стедикам | Д3 вперёд | К5 воздух по ходу | 3 сек | звук: шаги по лестнице | переход: Т1
   содержание: герой поднимается по лестнице, камера следует
КАДР 3 | П4 1-й средний | Р8 3/4 | М1 статика | Д11 статика | К1 трети | 2 сек | звук: скрип двери | переход: Т1
   содержание: герой открывает дверь квартиры
КАДР 4 | П2 крупный | Р3 уровень глаз | М6 наезд медленный | Д11 статика | К2 центр | 3 сек | звук: тишина | переход: Т1
   содержание: лицо героя — замечает что-то за кадром
КАДР 5 | П1 деталь | Р3 уровень глаз | М6 наезд | Д11 статика | К2 центр | 2 сек | звук: удар сердца | переход: Т5 (J-cut: шёпот начинается)

   содержание: глаза героя — страх; выход-крючок Л9
```
