# Киноязык: планы, ракурсы, движения, монтаж — полная сборка перечислений

Суть простым языком. Один шот (кадр) собирается по формуле:

**ШОТ = ПЛАН (крупность) + РАКУРС + КОМПОЗИЦИЯ + ДВИЖЕНИЕ КАМЕРЫ + ДВИЖЕНИЕ В КАДРЕ + ДЛИТЕЛЬНОСТЬ + ЗВУК**

Иерархия всего:

```
бит (было→стало) → шот → монтажная фраза → сцена → сиквенция (2–7 сцен) → акт → фильм
```

Каждый уровень отвечает на свой вопрос:
- шот — «что я вижу сейчас?»
- фраза — «что происходит в этом куске?»
- сцена — «что изменилось?»
- сиквенция — «какой мини-поворот случился?»
- акт — «в каких новых обстоятельствах теперь действие?»
- фильм — «как изменился герой?»

## 1. Планы (крупность)

### 1.1. Шкала Кулешова (эталон — фигура человека)

| # | План | Что в кадре | Смысл / функция |
|---|------|-------------|-----------------|
| 1 | Деталь (сверхкрупный, ECU) | глаз, губы, рука, предмет | акцент, улика, ключ к смыслу, максимум напряжения |
| 2 | Крупный (CU) | лицо по плечи | эмоция, мысль, интимность, прямой контакт со зрителем |
| 3 | Средний крупный (MCU) | по грудь | эмоция + начало жеста, «разговорный» план |
| 4 | 1-й средний (по пояс, MS) | туловище по локти | жест + эмоция, основной план диалога |
| 5 | 2-й средний (по колено, «ковбойский») | фигура по колено | действие, готовность, напряжение тела (на бедре — кобура) |
| 6 | Средний дальний (MLS) | в полный рост без запаса воздуха | действие целиком, но человек ещё главный |
| 7 | Общий (WS) | человек в рост + среда вокруг | действие в пространстве, установка места |
| 8 | Дальний (LS/EWS) | фигура ≤ 1/7 кадра | среда важнее человека, масштаб, одиночество |
| 9 | Экстремально дальний | человек едва различим | «взгляд Бога», экспозиция мира, эпичность |

**Законы крупности:**
- Чем крупнее план → тем сильнее эмоция и меньше контекст.
- Чем дальше план → тем больше контекст и меньше эмоция.
- Крупный план читается быстрее: ему нужно меньше экранного времени, чем общему.
- Деталь без общего плана = загадка; общий без детали = безразличие.
- Резкий скачок крупности (дальний → деталь) = шок; плавный ход = втягивание.

### 1.2. Функциональные типы кадров (роль шота в сцене)

| Тип | Что это | Зачем |
|-----|---------|-------|
| Установочный (establishing) | дальний/общий план локации в начале сцены | где и когда происходит действие, тон сцены |
| Мастер-шот (master) | общий план всей сцены целиком, от начала до конца | страховка монтажа, география действия |
| Двойной (two-shot) | два персонажа в одном кадре | отношения, химия, диалог без разрыва |
| Групповой | 3+ персонажа | иерархия группы, кто где стоит |
| Над плечом (OTS) | камера за плечом одного героя на другого | вовлечение в диалог, чужая точка зрения |
| POV (субъективный) | камера = глаза героя | максимальная идентификация, «я — герой» |
| Врезка (insert / cut-in) | крупный план детали из основного кадра (письмо, рука, экран) | акцент на важном, что зритель мог пропустить |
| Перебивка (cutaway) | кадр того, чего НЕТ в основном плане (собака, часы, толпа) | смысловой комментарий, маскировка склейки, ритм |
| Реакционный (reaction shot) | лицо слушающего, а не говорящего | эмоциональный отклик — часто важнее реплики |
| План-ответ (reverse) | обратный ракурс в диалоге | равноправие сторон, ритм перебивки |
| План-атмосфера | деталь среды без людей (дождь по стеклу) | настроение, пауза, переход |
| План-экшн | кадр, построенный вокруг движения | трюк, драка, погоня — читаемость важнее красоты |

## 2. Ракурсы (точка съёмки)

### 2.1. По вертикали (высота камеры)

| Ракурс | Смысл |
|--------|-------|
| Птичий полёт (строго сверху) | судьба, схема события, незначительность человека, «взгляд Бога» |
| Верхний (сверху вниз) | слабость, уязвимость, жертва, подчинение |
| Уровень глаз (нейтральный) | объективность, равенство, «как в жизни» |
| Уровень пояса | лёгкое усиление героя без гротеска |
| Уровень колен / земли | монументальность, давление среды (потолок «давит») |
| Нижний (снизу вверх) | сила, власть, угроза, героизм |

### 2.2. По горизонтали (угол к объекту)

| Ракурс | Смысл |
|--------|-------|
| Фронтальный (анфас) | прямой контакт, откровенность, театральность |
| 3/4 (классический) | объём + естественность, самый рабочий ракурс |
| Профиль | отстранённость, мысль, «герой в себе» |
| Со спины | тайна, уход, зритель «догоняет» героя |
| Голландский (завален горизонт) | тревога, безумие, дезориентация, «что-то не так» |

### 2.3. По степени смещения

- **Нейтральный ракурс** — небольшое смещение от привычной точки: незаметен, «невидимая» съёмка.
- **Острый ракурс** — сильное смещение (сверху/снизу/сбоку): сам становится смыслом, акцент.

**Законы ракурса:**
- Ракурс управляет социальным весом: низ = доминирование, верх = подчинение.
- Смена ракурса без смены крупности освежает склейку (правило 30°).
- Голландский угол — специя: работает только дозированно.

## 3. Композиция кадра

| Приём | Как работает | Эффект |
|-------|--------------|--------|
| Правило третей | кадр делится сеткой 3×3, объекты — на линиях и пересечениях | гармония, «правильная» картинка |
| Золотое сечение | пропорция 1:1,618 вместо ровных третей | более тонкая, «природная» гармония |
| Центр / симметрия | объект строго по центру, зеркальный кадр | мощь, ритуальность, одержимость (Уэс Андерсон, Кубрик) |
| Ведущие линии | дороги, стены, тени ведут взгляд к объекту | управление вниманием |
| Глубина (3 плана) | передний + средний + задний план | объём, «окно в мир» вместо открытки |
| Рамка в рамке | дверь, окно, зеркало вокруг героя | ловушка, наблюдение, изоляция |
| Воздух по взгляду | свободное место перед лицом/движением | куда смотрит/идёт — там запас кадра |
| Воздух над головой (headroom) | чем меньше — тем тревожнее | нет воздуха = давление, клаустрофобия |
| Диагонали | наклонные линии в кадре | динамика, нестабильность |
| Заполненность | пустой кадр vs забитый кадр | одиночество vs хаос/давление |

**Закон:** композиция — это маршрут для глаза зрителя: яркое пятно → лицо → контрастные линии → всё остальное.

## 4. Движение камеры

### 4.1. Статика (камера на месте, меняется ориентация)

| Движение | Как делается | Смысл |
|----------|--------------|-------|
| Панорама (pan) | поворот по горизонтали | обзор пространства, слежка, связь двух точек, «тем временем рядом…» |
| Наклон (tilt) | поворот по вертикали | вверх — величие/угроза; вниз — слабость/падение |
| Ролл (roll) | вращение вокруг оси объектива | дезориентация, кризис, «мир перевернулся» |
| Зум (zoom in/out) | меняется фокусное, камера стоит | резкий акцент, нерв, ретро-стиль 70-х; перспектива НЕ меняется |
| Панорама обзора | медленный pan по пространству | зритель осматривается вместе с героем, саспенс |
| Панорама-следование | pan за движущимся объектом | сопровождение без езды |

### 4.2. Динамика (камера перемещается в пространстве)

| Движение | Как делается | Смысл |
|----------|--------------|-------|
| Наезд (dolly in / push-in) | камера едет к объекту | нарастание напряжения, погружение в мысль героя |
| Отъезд (dolly out / pull-out) | камера едет от объекта | отчуждение, раскрытие контекста, типичный финал сцены |
| Тревелинг (tracking) | езда вдоль/за объектом (рельсы, тележка) | сопровождение, путешествие, преследование |
| Краб-шот | плавный сдвиг вбок без поворота | наблюдение, обход, скрытое присутствие |
| Подводка | тревелинг навстречу идущему герою | встреча, сближение |
| Проводка | тревелинг вслед уходящему | потеря, финал, «герой уходит» |
| Кран / лифт | перемещение по вертикали | подъём = взлёт, масштаб, свобода; спуск = падение, погружение |
| Арка (arc) | обход вокруг объекта по дуге | значимость момента, смена фона без склейки |
| Облёт (orbit, 360°) | полный круг вокруг объекта | кульминация чувства, «время остановилось» |
| Стедикам / гимбал | плавное следование за героем | «идём с героем», присутствие, длинные дубли |
| Ручная камера | тряска, с плеча | документальность, хаос, тревога, паника |
| Дрон | воздушные траектории | масштаб, свобода, экспозиция, «взгляд Бога» в движении |
| Вертолётный пролёт | дрон/кран через пространство сцены | эпичность, переход между мирами |

### 4.3. Комбинированные и трюковые

| Движение | Как делается | Смысл |
|----------|--------------|-------|
| Контр-зум (dolly-zoom) | наезд + зум навстречу друг другу | шок, головокружение, «мир схлопнулся» («Вертиго») |
| Наезд + панорама | езда с поворотом | сложное раскрытие пространства |
| Кран + арка | подъём с обходом | торжественный выход из сцены |
| Whip pan (свист-панорама) | резкий pan со смазом | энергичный переход, комедия, экшен |
| Скрытая склейка (invisible cut) | движение через тёмный объект/стену | «один дубль» на самом деле склеен |

**Законы движения:**
- Движение К объекту = нагнетание; ОТ объекта = разрядка.
- Мотивированное движение (за действием) незаметно; немотивированное — само становится смыслом.
- Скорость движения = скорость эмоции: медленный наезд — драма, резкий — паника.
- Движение должно начинаться и заканчиваться в статике (точки покоя), иначе кадр «плывёт».

## 5. Движение в кадре (мизансцена)

| Движение | Смысл |
|----------|-------|
| Вход в кадр | начало фазы действия; склейка «на входе» |
| Выход из кадра | конец фазы; склейка «на выходе» экономит время |
| Слева направо | лёгкость, развитие, «вперёд» (для читающих слева направо культур) |
| Справа налево | сопротивление, возврат, трудность |
| На камеру | напор, угроза, вторжение |
| От камеры | уход, потеря, отчуждение |
| По диагонали | максимум динамики |
| Вверх / вниз | рост власти / падение |
| По кругу | тупик, навязчивость, цикл |
| Камера стоит — люди движутся | объективный взгляд, наблюдение |
| Камера движется — люди стоят | субъективный взгляд, осмотр |

**Жёсткие правила склейки:**
- **Правило 180°** — не пересекать ось действия (воображаемую линию между героями), иначе они «меняются местами» на экране.
- **Правило 30°** — между двумя планами одного объекта ракурс менять минимум на 30°, иначе «прыжок» изображения.
- **Правило Кулешова** — комфортный стык «через один план» (общий↔1-й средний, 2-й средний↔крупный). Исключения: крупный↔деталь и общий↔дальний стыкуются напрямую. При укрупнении — шаг в сторону (смена ракурса и фона).
- **Склейка по движению** — резать в середине жеста, а не в паузе: стык становится невидимым.
- **Склейка по взгляду** — герой смотрит за кадр → следующий кадр показывает, на что.

## 6. Смыслы: сводные законы «выбор → эффект»

| Выбор | Эффект |
|-------|--------|
| Крупность ↑ (ближе) | эмоция ↑, контекст ↓ |
| Крупность ↓ (дальше) | контекст ↑, эмоция ↓ |
| Ракурс ниже | персонаж сильнее |
| Ракурс выше | персонаж слабее |
| Горизонт завален | тревога, безумие |
| Камера едет к объекту | нарастание, втягивание |
| Камера едет от объекта | разрядка, отчуждение |
| Камера стоит | объективность, спокойствие |
| Камера в руках | хаос, документальность |
| Длинный кадр | напряжение, созерцание, реальность |
| Короткий кадр | энергия, ритм, агрессия |
| Движение слева направо | развитие |
| Движение справа налево | сопротивление |
| Пустой кадр вокруг героя | одиночество |
| Забитый кадр | давление, хаос |
| Свет сверху | обыденность |
| Свет снизу | жуть, неестественность |
| Тишина перед звуком | усиление удара/крика |

## 7. Комбинации кадров в сцене (монтажные фразы)

Базовая схема эпизода (от Гриффита): **общий установочный → укрупнение на главный объект → развитие → возврат на общий** (ре-эстаблишинг).

### 7.1. Фразы по направлению крупности

| # | Фраза | Последовательность | Эффект |
|---|-------|--------------------|--------|
| 1 | Наступательная (сужение) | дальний → общий → средний → крупный → деталь | втягивание, нарастание, фокус на сути |
| 2 | Отступательная (расширение) | деталь → крупный → средний → общий → дальний | раскрытие контекста, разрядка, выход из сцены |
| 3 | Кольцевая | общий → … → крупный → … → общий | завершённость, «поставили точку» |
| 4 | Волнообразная | общий → средний → общий → крупный → общий | ритм «прибой-отлив», спокойное развитие |
| 5 | Контрастная | стык крайностей: дальний ↔ деталь | шок, монтаж аттракционов (Эйзенштейн) |

### 7.2. Фразы по драматургии

| # | Фраза | Последовательность | Эффект |
|---|-------|--------------------|--------|
| 6 | Маятниковая (диалог) | shot/reverse shot: план А ↔ план Б, укрупнение к кульминации реплики | ритм перебивки, рост конфликта |
| 7 | Мастер-шот + врезки | общий всей сцены + cut-in (деталь внутри) + cut-away (сбоку) | страховка монтажа, акценты без пересъёмки |
| 8 | Реакционная | действие → реакция → действие | эмоция важнее события; зритель живёт откликом |
| 9 | Параллельная (кросс-каттинг) | линия А ↔ линия Б, чередование учащается к финалу | «тем временем…», саспенс, сближение линий |
| 10 | Ассоциативная | действие + образ-сравнение (бойня ↔ скотобойня) | метафора, смысл рождается в стыке |
| 11 | Нарезка (montage) | серия коротких кадров одного процесса | сжатие времени (тренировка, дорога, смена сезонов) |
| 12 | Эффект Кулешова | лицо + предмет А / лицо + предмет Б | одно и то же лицо читается по-разному от соседнего кадра |
| 13 | Нарастающая нарезка | кадры всё короче к концу фразы | ускорение, паника, кульминация |
| 14 | Замедляющая | кадры всё длиннее | торможение, осмысление, после-качка |

### 7.3. Особые стыки внутри фразы

| # | Приём | Как работает |
|---|-------|--------------|
| 15 | Match cut | склейка по форме/движению/взгляду (костёр → солнце) — плавный переход миров |
| 16 | Jump cut | скачок внутри одного плана — энергия, нерв, блогерский ритм |
| 17 | Smash cut | резкий обрыв на контрасте (крик → тишина) — шок или комедия |
| 18 | Склейка по звуку | звук начинается до/после картинки (см. переходы J/L-cut) |

## 8. Переходы (чем соединять кадры и сцены)

| Переход | Как выглядит | Смысл / когда |
|---------|--------------|---------------|
| Прямая склейка (cut) | мгновенная замена кадра | 70–80% всех стыков; динамика, «невидимый» монтаж |
| Наплыв (dissolve) | кадр растворяется в следующем | смена времени, воспоминание, лирика; осторожно — быстро старомодно |
| Затемнение (fade out/in) | уход в чёрный/белый и обратно | конец главы, пауза, сон, смерть; сильный знак препинания |
| Вытеснение (wipe, шторка) | кадр сдвигает предыдущий | стилизация, ретро, комедия, комикс |
| J-cut | звук новой сцены звучит ДО картинки | мягкий вход, интрига («что это за голос?») |
| L-cut | звук старой сцены продолжается НАД новой картинкой | связь сцен, эхо, продолжение мысли |
| Match cut | общая форма/движение между кадрами | элегантный скачок через время/пространство |
| Скрытая склейка | рез в момент смаза/темноты/прохода объекта | эффект «одного дубля» |
| Световой переход | вспышка/блик между кадрами | клиповая энергия |
| Whip pan | резкая панорама со смазом как переход | экшен, комедия, динамичная смена точки |

**Закон:** переход — это знак препинания. Склейка = запятая, наплыв = многоточие, затемнение = точка, smash cut = восклицательный знак.

## 9. Последовательность сцен

Сцена = единство места + времени + действия. Сцена работает, если на выходе **что-то изменилось** (заряд сцены: +/−).

### 9.1. Типы сцен по функции

| Тип | Задача |
|-----|--------|
| Экспозиционная | ввести мир, героя, правила |
| Побуждающая | событие-толчок, ломающее привычную жизнь |
| Развивающая | перипетия: попытка → препятствие → результат |
| Поворотная | информация/событие меняет направление истории |
| Кульминационная | главное столкновение, ставки на максимуме |
| Разрешающая | последствия, новая норма жизни |
| Переходная | связка локаций/времени (самая слабая — сокращать) |

### 9.2. Схемы связи сцен

| # | Схема | Как работает |
|---|-------|--------------|
| 1 | Линейная | A → B → C по причинно-следственной цепи |
| 2 | Параллельная | чередование 2+ линий, сходятся в кульминации |
| 3 | Инверсионная | флешбек / флешфорвард, начало с середины (in medias res) |
| 4 | Рамочная | история внутри истории: начали и кончили одной точкой |
| 5 | Эллипсис | пропуск времени (затемнение, нарезка, диалоговый мост) |
| 6 | Звуковой мост | J-cut / L-cut между сценами |
| 7 | Контрастный стык | богатство↔нищета, смех↔трагедия, шум↔тишина |
| 8 | Смысловой мост | предмет/форма/фраза связывает две сцены (match cut на уровне сцен) |
| 9 | Крючок | сцена обрывается на вопросе → ответ в следующей |
| 10 | Эхо | сцена повторяет предыдущую с изменением — показывает рост героя |

### 9.3. Каркасы (структуры фильма)

**Трёхактная:**

```
Акт I  (завязка, ~25%):      экспозиция → побуждающее событие → ППП (точка невозврата)
Акт II (конфронтация, ~50%): перипетии → ЦПП (перелом, ложная победа/поражение) → рост ставок → ФПП (кризис, «всё рушится»)
Акт III (развязка, ~25%):    кульминация → разрешение
```

**Save the Cat — 15 битов (Блейк Снайдер):**

| # | Бит | % фильма | Задача |
|---|-----|----------|--------|
| 1 | Открывающий образ | 1% | тон и герой «до» |
| 2 | Формулировка темы | 5% | кто-то вслух говорит, о чём фильм |
| 3 | Завязка-установка | 1–10% | мир героя и чего в нём не хватает |
| 4 | Катализатор | 12% | событие, опрокинувшее старую жизнь |
| 5 | Дебаты | 12–25% | герой сопротивляется: «а надо ли?» |
| 6 | Переход в акт 2 | 25% | герой сам принимает решение и входит в новый мир |
| 7 | Линия Б | 30% | второй сюжет (обычно отношения), несущий тему |
| 8 | Развлечения | 30–55% | «обещание жанра»: сцены из трейлера |
| 9 | Середина | 55% | ложная победа или ложное поражение, ставки ↑ |
| 10 | Враги наступают | 55–75% | давление снаружи и внутри растёт |
| 11 | Всё потеряно | 75% | дно, «запах смерти» |
| 12 | Тёмная ночь души | 75–85% | герой переживает потерю и находит ответ |
| 13 | Переход в акт 3 | 85% | линии А и Б сливаются в решение |
| 14 | Финал | 85–100% | герой применяет усвоенное и побеждает |
| 15 | Финальный образ | 100% | зеркало открывающего — доказательство изменения |

**Сиквенционная (8 сиквенций):** фильм делится на 8 мини-фильмов по 10–15 минут; каждая сиквенция = своя цель героя + свой поворот в конце; 2 сиквенции на акт I, 4 на акт II, 2 на акт III.

**Законы последовательности:**
- Бит = минимальное событие «было → стало». Биты → сцены → сиквенции → акты.
- Каждая сиквенция заканчивается мини-поворотом, акт — крупным.
- Порядок сцен = порядок вопросов зрителя: каждая сцена отвечает на один вопрос и задаёт следующий.
- Сцены входят поздно, выходят рано (in late, out early).

## 10. Взаимосвязи (сводные матрицы)

### 10.1. Главная матрица

| Связь | Правило |
|-------|---------|
| План ↔ эмоция | крупность = дистанция до чувства: ближе = сильнее |
| Ракурс ↔ власть | низ = сила, верх = слабость, завал = тревога |
| Композиция ↔ внимание | трети = гармония, центр = мощь, рамка = ловушка |
| Движение камеры ↔ энергия | к объекту = нагнетание, от объекта = разрядка |
| План ↔ длительность | чем крупнее план, тем короче он читается |
| Длительность ↔ ритм | короткие кадры = агрессия, длинные = созерцание |
| Фраза ↔ арка сцены | вход — наступательная, выход — отступательная, диалог — маятниковая |
| Переход ↔ смысл | склейка = «и», наплыв = «потом/вспомнил», затемнение = «конец главы» |
| Сцена ↔ бит | нет изменения «было→стало» — сцена лишняя |
| Сиквенция ↔ акт | каждая сиквенция — мини-поворот, акт — крупный поворот |
| Звук ↔ картинка | контрапункт (тишина на ужасе) сильнее синхрона |

### 10.2. Жанр ↔ типовой набор

| Жанр | Планы | Движение | Ракурсы | Фразы |
|------|-------|----------|---------|-------|
| Триллер | средние + крупные | медленные наезды, стедикам | нейтральные, изредка голландский | наступательная, параллельная |
| Экшен | общие + 2-й средний | тревелинг, ручная камера, whip pan | низкие, острые | контрастная, нарастающая нарезка |
| Драма | 1-й средний + крупный | медленные панорамы, кран | нейтральные, верхние для слабости | маятниковая, реакционная |
| Хоррор | детали + общие | краб-шот, медленный наезд | голландский, верхний, POV | отступательная (из детали), smash cut |
| Комедия | общие + средние | статика, минимум движения | нейтральные (играют тела, не камера) | мастер-шот + врезки, smash cut |
| Мелодрама | крупный + MCU | плавный стедикам, арка | уровень глаз, мягкие | волнообразная, наплывы |
| Документальный | любые | ручная камера | как получилось | нарезка, L/J-cut интервью |

### 10.3. Эмоция ↔ рецепт шота

| Нужно вызвать | Рецепт |
|---------------|--------|
| Тревога | крупный + голландский + медленный наезд + тишина |
| Одиночество | дальний + пустой кадр + статика + длинная длительность |
| Мощь героя | нижний ракурс + центр кадра + медленный tilt вверх |
| Паника | ручная камера + короткие кадры + нарастающая нарезка |
| Интимность | крупный + уровень глаз + статика + мягкий свет |
| Ностальгия | наплыв + тёплый свет + медленный отъезд |
| Шок | smash cut или контр-зум + резкий звук |
| Торжество | кран вверх + общий/дальний + широкий обзор |

## 11. Алгоритм сборки сцены (пошагово)

1. **Бит сцены** — что изменится: было → стало. Нет изменения — сцена не нужна.
2. **Фраза** — выбрать схему (обычно: общий → развитие → крупный акцент → выход).
3. **Шоты** — каждому назначить по формуле: план + ракурс + композиция + движение камеры + движение в кадре + длительность.
4. **Проверка стыков** — 180°, 30°, «через один план», склейка по движению.
5. **Переходы** — выбрать знаки препинания между фразами (склейка/наплыв/затемнение).
6. **Связь с соседями** — крючок на выходе, звуковой или смысловой мост на входе.
7. **Ритм** — разложить длительности: ускорение к кульминации сцены, пауза после.
