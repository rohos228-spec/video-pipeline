# W40 фаза 4: вопросы владельцу (C-4, C-12, C-11, N-16, N-17, C-14)

Сделано безопасными значениями по умолчанию; ниже то, что выбирает владелец.

1. Значение единого потолка `RESTART_CHAIN_MAX_PER_NODE` (сейчас 60 платных перезапусков одного узла на проект, 0 = выкл.). Считаются перегенерации по проверкам, повторы после ошибки, авто-ревью и ручные решения. Заказчик денежного лимита не хочет, поэтому число подбирается под «не зациклилось», а не под бюджет. Нужен ли отдельный, меньший потолок для ручных регенов человека (сейчас они в общем счёте)?
2. Что делать на потолке: сейчас пауза проекта и инцидент «нужен человек». Снимает человек кнопкой «продолжить/возобновить» (счётчики начинаются заново). Достаточно ли этого или нужен отдельный экран решения?

Нужно ли автоматически снимать резерв, когда воркер проекта стал idle (требует опроса состояния проекта), или оставить ручное снятие через отметку незакрытых резервов (C-9)?
4. C-14: `hitl.approve` через слой действий больше не запускает следующий шаг. Нужна ли альтернатива «одобрить и запустить следующий» одним планом с оценкой цены следующего шага в превью (требует оценки по статусу проекта после одобрения)?
5. Telegram: ручной 🔁 на hero-карточке (`app/telegram/bot.py`, ветка `excel_id`) ставит `generating_hero` напрямую, в общий потолок не входит. Подключать ли?
