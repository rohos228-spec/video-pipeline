# Правила планов и ракурсов для группы `script_frames_qc`

Документ для промтов и кода. Имена планов — только канон системы.  
Не использовать в поле `план` слова «по колена» и «поясной» — они только в пояснениях ниже.

Канон поля `план`:
`ДАЛЬНИЙ` | `ОБЩИЙ` | `СРЕДНИЙ` | `СРЕДНЕ-КРУПНЫЙ` | `КРУПНЫЙ` | `ДЕТАЛЬ`

Связь с бытовыми именами (только для понимания):
1 Дальний = ДАЛЬНИЙ  
2 Общий = ОБЩИЙ  
3 По колена = СРЕДНИЙ  
4 Поясной = СРЕДНЕ-КРУПНЫЙ  
5 Крупный = КРУПНЫЙ  
6 Деталь = ДЕТАЛЬ

Нода «сцены → кадры» и QC: если пишете план — только из канона.  
Код после ноды: сверяет план с правилами ниже; запрещённые склейки чинит; не подменяет смысл кадра.

---

## 1. Что означает каждый план

### ДАЛЬНИЙ
Показать место целиком, масштаб, где мы. Люди мелкие или часть среды.  
Типично: улица кварталом, зал целиком, вокзал, двор, кабинет с дверью и всей комнатой сразу.

### ОБЩИЙ
Человек (или группа) целиком + действие в пространстве. Видны ноги, пол, как стоят относительно мебели.  
Типично: вошёл в комнату, подошёл к столу, идет по коридору, двое стоят друг напротив друга во весь рост.

### СРЕДНИЙ (быт: по колена)
Жест и поза. Человек примерно по колено / по бедро: видно корпус и руки, меньше «весь пол».  
Типично: достаёт папку, открывает дверь рукой, показывает на доску, садится, передаёт предмет.

### СРЕДНЕ-КРУПНЫЙ (быт: поясной)
Диалог, руки, верх тела. Лицо читается, но ещё видны плечи и жесты рук.  
Типично: разговор за столом, кивок, передача бумаги из рук в руки, реакция без полного крупного лица.

### КРУПНЫЙ
Эмоция лица. Глаза, рот, мимика — главное. Фон вторичен.  
Типично: услышал обвинение, понял улику, испуг, торжество, стыд.

### ДЕТАЛЬ
Предмет или часть: глаз, рука, письмо, кнопка, печать, замок, след, экран телефона.  
Типично: штамп на бумаге, палец на кнопке, текст в деле, кровь на перчатке.

## 2. Когда какой план ставить (по ситуации)

Выбирай план по вопросу: «что зритель должен понять в этот момент?»

### A. Новое место / ориентация
- Первый кадр новой локации, зритель ещё не понял где мы → **ДАЛЬНИЙ** или **ОБЩИЙ**.  
  ДАЛЬНИЙ — если важно пространство целиком. ОБЩИЙ — если сразу важен человек в этом пространстве.
- Уже были в этой комнате, просто новый угол того же места → не обязательно снова ДАЛЬНИЙ; чаще **ОБЩИЙ** или **СРЕДНИЙ**.

### B. Вход, выход, перемещение
- Входит в дверь / выходит → **ОБЩИЙ** (видно тело + дверь + куда идёт).  
- Идёт через комнату к другому человеку → **ОБЩИЙ**, затем можно **СРЕДНИЙ**, когда уже рядом.  
- Нельзя сразу после входа кидать ДЕТАЛЬ предмета на столе — зритель не поймёт, чьи руки.

### C. Приближение к человеку / диалог
- Двое только сошлись в кадре → **ОБЩИЙ** или **СРЕДНИЙ**.  
- Начался разговор, важны реплики и лёгкая мимика → **СРЕДНЕ-КРУПНЫЙ**.  
- Ударная эмоция одной фразы → **КРУПНЫЙ**.  
- Не начинай диалог с ДЕТАЛИ рта или глаз, пока не было хотя бы СРЕДНЕ-КРУПНЫЙ / КРУПНЫЙ контекста лица.

### D. Предмет и руки
- Человек только тянется к предмету → **СРЕДНИЙ** (жест + поза).  
- Предмет уже в руках и важен сам объект → **ДЕТАЛЬ** (после среднего/средне-крупного).  
- Кладёт / открывает / нажимает — если важен жест целиком → **СРЕДНИЙ**; если важен сам клик/печать → **ДЕТАЛЬ**.

### E. Реакция
- Короткая реакция в диалоге → **СРЕДНЕ-КРУПНЫЙ** или **КРУПНЫЙ**.  
- Реакция на то, что увидел на бумаге → сначала **ДЕТАЛЬ** бумаги (или вместе), потом **КРУПНЫЙ** лица — или наоборот, если сначала лицо, потом подтверждение деталью. Оба порядка ок, но не прыгай с ДАЛЬНИЙ сразу в КРУПНЫЙ.

### F. Перебивка / микродвижение (коротко по времени)
- Перебивка меньше секунды: чаще **ДЕТАЛЬ** или **СРЕДНЕ-КРУПНЫЙ**.  
- Закадр перебивки: **10–30** символов или короткий эмо/реакция (можно пустой).  
- Не ставь ДАЛЬНИЙ на полусекундную перебивку.  
- Микродвижение пальца / взгляд в сторону → ДЕТАЛЬ или КРУПНЫЙ глаз / СРЕДНЕ-КРУПНЫЙ.

### G. Группа людей / доска / схема
- Вся доска и кто у неё стоит → **ОБЩИЙ** или **ДАЛЬНИЙ**.  
- Кто-то пишет на доске → **СРЕДНИЙ**.  
- Текст/схема на листе → **ДЕТАЛЬ**.

### H. Сила / слабость (связка с ракурсом, план тот же логике)
План выбирается по смыслу выше; ракурс усиливает (см. раздел 5). Не меняй план только из-за ракурса.

### I. Если сомневаешься
1) Нужно место? → ДАЛЬНИЙ/ОБЩИЙ  
2) Нужно действие тела? → ОБЩИЙ/СРЕДНИЙ  
3) Нужны руки/диалог? → СРЕДНЕ-КРУПНЫЙ  
4) Нужна эмоция? → КРУПНЫЙ  
5) Нужен объект? → ДЕТАЛЬ  

Не закрывай всё одним СРЕДНИЙ «на всякий случай».

## 3. Последовательность внутри сцены

Базовый путь смысла:
**место → действие → эмоция → акцент предмета**

На каноне:
`ДАЛЬНИЙ / ОБЩИЙ → СРЕДНИЙ / СРЕДНЕ-КРУПНЫЙ → КРУПНЫЙ → ДЕТАЛЬ`

Нормальные цепочки (примеры):
1. ДАЛЬНИЙ → ОБЩИЙ → СРЕДНИЙ → ДЕТАЛЬ  
2. ОБЩИЙ → СРЕДНИЙ → СРЕДНЕ-КРУПНЫЙ → КРУПНЫЙ  
3. ОБЩИЙ → СРЕДНЕ-КРУПНЫЙ → КРУПНЫЙ → ДЕТАЛЬ  
4. СРЕДНИЙ → ДЕТАЛЬ → КРУПНЫЙ (жест → предмет → реакция)  
5. СРЕДНЕ-КРУПНЫЙ → КРУПНЫЙ → СРЕДНЕ-КРУПНЫЙ (диалог с ударом эмоции и возврат)

Допустимо «через шаг» по шкале:
ДАЛЬНИЙ → СРЕДНИЙ; ОБЩИЙ → СРЕДНЕ-КРУПНЫЙ; СРЕДНИЙ → КРУПНЫЙ; СРЕДНЕ-КРУПНЫЙ → ДЕТАЛЬ.

Возврат назад по шкале нормален, если сюжет уходит снова в пространство или жест (КРУПНЫЙ → ОБЩИЙ при выходе из комнаты).

## 4. Запреты склейки (монтаж)

Шкала ступеней (для кода R-PLAN-STEP):
1 ДАЛЬНИЙ  
2 ОБЩИЙ  
3 СРЕДНИЙ  
4 СРЕДНЕ-КРУПНЫЙ  
5 КРУПНЫЙ  
6 ДЕТАЛЬ

### Жёсткие запреты соседних склеек
Не ставить подряд (кадр N и кадр N+1):
- **ОБЩИЙ ↔ СРЕДНИЙ** (быт 2↔3) — слишком похожий «человек в кадре», дёргает. Между ними нужен другой план или смена места/оси.  
- **СРЕДНИЙ ↔ СРЕДНЕ-КРУПНЫЙ** (быт 3↔4) — соседние по телу; зритель почти не видит разницы. Клей через шаг или смени ракурс+план сильнее.

### Разрешено рядом
- ДЕТАЛЬ ↔ КРУПНЫЙ  
- ДАЛЬНИЙ ↔ ОБЩИЙ (осторожно: только если реально меняется масштаб места↔человек; не два почти одинаковых)  
- ОБЩИЙ ↔ СРЕДНЕ-КРУПНЫЙ (через шаг от СРЕДНИЙ)  
- СРЕДНИЙ ↔ КРУПНЫЙ  
- СРЕДНЕ-КРУПНЫЙ ↔ ДЕТАЛЬ  

### Запрет одинаковых подряд
Два одинаковых плана подряд — нельзя, если тот же объект и тот же смысл.  
Исключение: смена места или жёсткая смена оси 30°+ и другой объект — всё равно лучше сменить план на соседний допустимый.

### Запрет прыжка через 3+ ступени
Нельзя: ДАЛЬНИЙ → КРУПНЫЙ; ДАЛЬНИЙ → ДЕТАЛЬ; ОБЩИЙ → ДЕТАЛЬ; ДАЛЬНИЙ → СРЕДНЕ-КРУПНЫЙ как единственный мост без действия — плохо.  
Если нужен прыжок смысла — вставь промежуточный кадр (ОБЩИЙ/СРЕДНИЙ).

### Что делать коду при нарушении
1) Есть запрет соседей → сдвинуть второй кадр на допустимый план по смыслу объекта (не выдумывать новый сюжет).  
2) Прыжок 3+ → вставить или заменить промежуточный план.  
3) Нельзя из-за плана создавать лишний «общий вид» шаблон, если пользователь запретил авто-вставки места — лучше ошибка/добор GPT, чем молчаливый шаблон.

## 5. Ракурс (поле отдельно от плана)

План = крупность. Ракурс = откуда камера.

- **Снизу вверх** — сила, угроза, давление власти.  
- **Сверху вниз** — слабость, стыд, подавленность.  
- **Диалог** — уровень глаз.  
- **ДЕТАЛЬ предмета** — обычно уровень глаз или сверху (если на столе). Снизу — редко, только если предмет «давит»/угрожает.

Ракурс не отменяет запреты планов. Нельзя чинить плохой план сменой только ракурса.

## 6. Связка с нодами группы (чтобы не ломать)

| Кто | Что делает с планом |
|-----|---------------------|
| Действие сцены | План не пишет. Пишет шаги и площадку. |
| Сцены → кадры (GPT) | Может предложить план только из канона ИЛИ не писать план (как сейчас) — тогда ставит код по этой таблице ситуаций. |
| Код после кадров | Проверяет запреты; ставит/чинит план; не подставляет недостающие сюжетные кадры молча (нужен добор или ошибка). |
| QC | Может поменять план, если смысл кадра сменился; снова только канон. |
| Код после QC | Снова проверка запретов склейки. |

Поле `объект` (место/тело/двое/предмет/лицо/взгляд) — подсказка, не единственный закон.  
Приоритет: **смысл ситуации из раздела 2** > старая тупая таблица объект→план.

Мини-памятка объект → стартовый кандидат (потом проверить запреты и раздел 2):
- место → ДАЛЬНИЙ или ОБЩИЙ  
- тело / двое → ОБЩИЙ или СРЕДНИЙ  
- взгляд → СРЕДНЕ-КРУПНЫЙ или КРУПНЫЙ  
- лицо → КРУПНЫЙ  
- предмет → ДЕТАЛЬ (после жеста СРЕДНИЙ, если жест ещё не показан)

## 7. Короткие примеры «правильно / неправильно»

Правильно: ОБЩИЙ (вошёл) → СРЕДНИЙ (подошёл к столу) → ДЕТАЛЬ (штамп) → КРУПНЫЙ (реакция).  
Неправильно: ОБЩИЙ → СРЕДНИЙ подряд на одном жесте без смены оси.  
Неправильно: ДАЛЬНИЙ кабинета → сразу ДЕТАЛЬ печати.  
Неправильно: СРЕДНИЙ → СРЕДНЕ-КРУПНЫЙ → СРЕДНИЙ мельтешение без смысла.  
Правильно: СРЕДНЕ-КРУПНЫЙ диалог → КРУПНЫЙ удар → ДЕТАЛЬ письма в руках.

## 8. Чеклист перед записью плана в кадр

1. Каноническое имя?  
2. Что должен понять зритель (место/действие/эмоция/предмет)?  
3. Есть ли предыдущий кадр и не запрещена ли склейка?  
4. Не прыжок через 3+ ступени?  
5. Ракурс согласован с силой/слабостью/диалогом?  
6. Для короткой перебивки не поставлен ДАЛЬНИЙ?

Если пункт 3–4 ломаются — смени план или порядок кадров, не игнорируй.

## 9. Длина закадра на кадр (VO chunk)

Жёсткие лимиты для ноды «сцены → кадры» и QC (код после ноды проверяет):

| Тип кадра | Символов закадра |
|-----------|------------------|
| Обычный / длинный шаг сцены | **26–80** (цель ~45) |
| Перебивка | **10–30** или короткий эмо/реакция-кадр (можно пустой закадр) |

- Не валить весь `voiceover_text` ячейки в один кадр.
- Не дробить ниже 10 символов, кроме осознанной перебивки/реакции.
- Склейка непустых `закадр` кадров = весь `voiceover_text` ячейки.
- Нарушение → предупреждение / добор GPT / флаг incomplete, не молчаливый ignore.

Константы кода: `SHOT_VO_MIN=26`, `SHOT_VO_MAX=80`, `SHOT_VO_CUTAWAY_MIN=10`, `SHOT_VO_CUTAWAY_MAX=30` в `app/services/scene_shot_grammar.py`.
