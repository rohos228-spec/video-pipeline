# Design: img_pr — строгий RU-вариант Trash Polka

Дата: 2026-08-09  
Нода: `img_pr`  
Решение пользователя: вариант **A** (новый файл + global active; старый не трогаем).

## Цель

Новый мастер-промт картинок на базе `img_prompts_trash_polka_watercolor`, с ужесточённым форматом: ракурс, стиль (тон), эмоция и описание персонажей **вплетены** в мир/кадр/сцену; обязательный Negative (через пайплайн); один референс = один герой; запрет клонов/идентичных лиц; запрет нечитаемого мусорного текста; тело сцены — на русском.

## Не в scope

- Видео-промты (`anim_pr` / `anim_prompts_veo31_relax`) — не трогаем.
- Смена medium / другого визуального стиля (остаётся Archival Noir Watercolor Grunge).
- Переписывание `img_pr_style.py` STYLE_HEAD/TAIL (EN lock остаётся источником правды для Outsee).

## Архитектура

```
db_frames.json (+ characters[])
        ↓
мастер-промт (новый .md) + footer батча
        ↓

        ↓
img_pr_style.wrap_ops_styles → STYLE + Negative (EN)
        ↓
DB / R45 (промт_картинки)
```

## Формат `промт_картинки` (сцена от GPT)

Порядок обязателен. Данные только из `db_frames.json` + Entity; закадр не копировать.

| Блок | Метка (RU) | Источник |
|------|------------|----------|
| A | `Референс:` | `characters` + Entity; **один код = один герой/одно тело** |
| B | `Фон:` | `shot01_bg` + `place` |
| C | `Действие:` | `shot01_action` (mid-motion) |
| D | `Свет:` | `lighting` / `scene_lighting` |
| E | `Акцент:` | `accent` |
| F | `Смысл сцены:` | `scene_sense` (видимое) |
| G | `План/ракурс:` | `scene_feature` + `shot01_description` |
| H | `Эмоция:` | лицо/поза из действия + sense/accent (без закадра) |
| I | `Детали:` | `shot01_props` + continuity |
| J | `Место/время:` | `place` + кратко `general_plan` |

Стиль: в сцене допускается короткий тон («акварельный архивный нуар»), полный STYLE + **Negative** — только пайплайн.

### Жёсткие правила (новые/усиленные)

1. **1 референс = 1 герой:** один абзац `Референс:` на один `cXX`; несколько кодов → отдельные короткие строки; запрет «два тела одного id».
2. **Запрет идентичных персонажей / клонов** (twins, duplicate face, mirrored double).
3. **Текст:** только если надпись есть во входе; иначе явно «без читаемого текста / нечитаемые пятна»; запрет каши, случайной латиницы, captions/UI.
4. **Язык:** блоки сцены — русский; id (`c01`) и имена Entity — как во входе.
5. **Negative:** не дублировать длинный EN-хвост в JSON; обязателен через `wrap_ops_styles`.
6. **Фоны священны:** `shot01_bg` (+ continuity того же `place`) — подробный и узнаваемый; нельзя подменять односложным «интерьер/улица» или выдумывать другой фон. Приоритет выше сюжета/эмоции (после STYLE medium).
7. **Планы священны:** крупность/роль из `scene_feature`, камера из `shot01_description` — не подменять другим планом «для красоты».
8. **Лимит 4000:** тело `промт_картинки` (до STYLE wrap) ≤ **4000** символов; приоритет обрезки: вода → лишние детали → эмоция кратко; **фон и план/ракурс не выкидывать**.

`промт_картинки_2`: сохранить стартовую фразу про смену камеры; текст сцены — RU; no twins; тот же place/light/**bg** DNA; другой план/ракурс; тоже ≤ 4000.

## Данные и ошибки

- Нет `cXX` → блок A отсутствует (не выдумывать реф).
- Пустой action → жест из accent/sense, всё ещё mid-motion где возможно.
- Битый JSON / чужой uuid — как сейчас (retry батча).
- Лимит длины **тела сцены** (`промт_картинки` до wrap STYLE): **≤ 4000** символов.
  Не влезает — режь детали/воду, **не** жертвуй фоном (`shot01_bg`) и планом/ракурсом
  (`scene_feature` + `shot01_description`). STYLE/Negative после wrap — сверху/снизу, сверх лимита сцены.
