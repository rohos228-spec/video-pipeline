# Пример разбора стиля v2: два референса (ref1 «плот», ref2 «пшеничное поле»)

Это пример **полного** отчёта агента разбора стиля (`style_extract` v2) на двух
роликах, которые прислал пользователь: `ref1.mp4` (40.6 с) и `ref2.mp4` (72.6 с).
Оба — вертикальные 9:16, 720×1280, 29.97 fps, английская озвучка, вшитые
субтитры. Стиль узнаваем: 3D-анимация «Zack D. Films» (на футболке героев —
логотип ZACK D FILMS).

Как получен отчёт:

- **детерминированная часть** — реально прогнана кодом этой ветки
  (`app/services/style_agent/extract.py`): ffprobe, per-frame scene-score →
  адаптивный детектор склеек с подсказками по сменам субтитров, таймлайн
  кадров 120/мин (+ хук ×2, + кадры ±0.2 с у каждой склейки), OCR субтитров
  (`rapidocr_onnxruntime`), разделение голос/музыка, громкость, связка строк
  закадра с планами, метрики сценария. Все таймкоды и числа ниже — из неё
  (`style_passport.draft.json`, `linkage.json`, `shots.json`).
- **vision-часть** (что в кадре, камера, построение плана, приёмы) — в этой
  среде нет ключей к LLM, поэтому листы `shot_*.jpg` / `cuts_*.jpg` /
  сетки планов просмотрены вручную автором ветки, а описания записаны в том
  формате, который заполняет агент `shots`/`patterns` (анкеты
  `prompts/style_agent/shots.md`, `patterns.md`). В продакшене это делают
  7 LLM-вызовов на ролик-пару (лимит 12 по умолчанию, оценка ≈ $0.2).
- Ложные склейки детектора (вспышка-подсветка объекта, быстрый объект,
  всплывающая вставка) помечены и слиты так, как это делает `apply_false_cuts`
  после ответа агента `shots`.

1. **«Существительное → предмет в кадре, часто с подсветкой»**. Момент
   упоминания объекта совпадает с его появлением или вспышкой подсветки:

   (розовый), 0:57 strong one (зелёный).
2. **«Каждая фраза — новый план» в экшене** (ref1 0:03.8–0:11: 8 планов за
   7 с, по одному на строку «With it / he caught / a small fish / … / into
   strips / and dried it»).
3. **«План держится, пока длится мысль»** в объяснении (ref2 #12: 4.8 с на
   «But as you keep walking you start seeing bigger and bigger ones» — одна
   непрерывная прогулка; #26: 7.5 с на весь третий сценарий).
4. **Повтор фразы = jump-zoom**: «he survived 133 days / he survived 133
   days» (ref1 0:34.07 → 0:34.77), «you chose too early» ×2 (ref2 0:27 →
   0:28.5). Повтор в субтитрах — всегда резкий наезд на ту же мизансцену.
5. **Союз-бит «But» / «With it» / «So» получает свой короткий план 0.4–0.6 с**

6. **Вставка появляется на существительном-правиле**: «two rules» → блокнот,
   «Rule 1/2» → перелистывание страниц ровно на «walk forward» / «one
   choice» (ref2 6.4 / 8.0 / 11.0 с).
7. Склейка **никогда не опережает** фразу больше чем на 1 кадр: отрицательных
   смещений < 10 %. Это значит, что при генерации монтаж надо резать по
   таймкодам слов TTS **с +30…+50 мс**, а не по «музыкальной сетке».

## 6. Особенности стиля

- Речь занимает 98–99 % длительности, пауз между предложениями фактически нет
  (медиана пауз 0.0 с): ритм задаёт **монтаж, а не голос**.
- Герой — всегда «тот же парень в футболке»; второй персонаж — предмет.
  Лица второстепенных людей нет.
- Среда одна на ролик (море / поле), меняется только крупность и ракурс —
  это дешёвое и консистентное для генерации свойство.
- Юмор только визуальный (гэги, «!», укус чайки); текст сухой. При генерации
  нельзя писать шутки в сценарий — их надо класть в поле `gag` раскадровки.
- Цвет-код подсветок: жёлтый = полезный предмет, зелёный = правильный выбор,
  оранжевый = опасность, розовый/красный = удар/ошибка.
- Субтитры — единственный текст на экране постоянно; они не «караоке» по
  словам, а по фразам; шрифт один, без фона; расположены над 15 % нижнего
  края, поэтому в кадре нижняя треть всегда «пустая» (нет важных деталей).
- Все склейки — жёсткие. Единственный плавный переход — движение камеры
  внутри плана (дрон), а не dissolve.
- Длинный план допустим **только** когда действие непрерывно и
  фразы перечисляют (ref2 #12, #26); в экшене длиннее 2.7 с планов нет.
- Хвост после последней фразы 0.6 с, без end card, без CTA.
- Музыка — ровная подложка на −5…−6 dB, не меняется на кризисе.
- Объект, который упомянут, появляется **в том же плане**, а не в следующем
  (смещение +40 мс) — т.е. раскадровка идёт «от фразы к картинке», а не
  «картинка, потом комментарий».

## 7. Blueprint генерации (кратко; подробно — `docs/style-blueprint.md`)

Цепочка нод Studio (существующие — как есть; `NEW` — требуются):

`topic → plan → script → split → NEW shot_plan → hero → items → image_prompts → images → hitl_images → animation_prompts → videos → audio → NEW overlay_assets → music → sfx_plan → sfx_gen → NEW vo_sync_edit (или assemble) → NEW style_check → hitl_final → publish`

Ключевые параметры из этого разбора, которые пойдут в ноды:

| нода | параметр | значение |
|---|---|---|
| plan | duration_seconds | 40–75 |
| script | темп / биты | 170 слов/мин; 1 строка/с; 3 слова в строке; 10–14 слов в предложении |
| split | cell_min_chars / cell_max_chars | 12 / 27 (≈ 3 слова) |
| shot_plan | shot_len_s median / p10 / p90; sync | 1.2 / 0.6 / 2.5 с; `each_phrase_new_shot` для экшена, `shot_spans_phrases` для объяснений; `illustrates` обязателен; `gag` опционален; `highlight_color` из цвет-кода |
| image_prompts | style lock | «stylized 3D render, cartoon-realistic male character in plain white/grey tee, soft daylight, shallow DOF, single environment, subject centered, empty bottom third» |
| animation_prompts | clip_len_s; camera | 1.2–2.5 с; `slight handheld drift` / `slow push-in`; запрет dissolve/morph |
| audio | voice | мужской, ровный, 170 wpm, без пауз; stability 0.6 |
| overlay_assets | карточки / пузыри / подсветки | по таблице §5 |
| assemble / vo_sync_edit | cut_offset_ms; words_per_line; subtitles | +40 мс; 3; line / lower_third / white bold no box |
| music | level_vs_voice_db | −5.4 |
| style_check | допуски | cuts/min 25–46, shot_len median 1.0–1.5, words/line 3, cut_on_phrase ≥ 0.6, music −4…−7 dB |

## 8. Разброс и что проверить вручную

- `linkage.pattern`: each_phrase_new_shot (ref1) vs shot_spans_phrases (ref2)
  — это не разброс стиля, а **два режима одного стиля** (экшен-история /
  объяснение). В blueprint оба режима заданы параметром `sync`.
- `motion.cuts_per_min` 46 vs 25 — то же: зависит от жанра ролика; задавать
  в `plan` как `pace: action | explainer`.
- `visual.saturation` medium vs low — следствие среды (море / пшеница), не
  стиля.
- Таймкоды строк субтитров квантованы шагом 0.5 с (OCR на кадрах 2 fps; в
  хуке 4 fps); для точного `cut_offset` нужны таймкоды слов TTS при генерации
  — там погрешности нет.
- Детектор дал 6 ложных склеек из 75 (8 %) — все на подсветках/оверлеях/быстрых
  объектах; vision-агент `shots` их снимает по листам `cuts_*`.
- SFX оценены по кадрам, не по звуку (разделение стемов — полосовой фильтр);
  перед утверждением паспорта послушать 0:21–0:25 ref1 (удар) и 0:06–0:11 ref2
  (перелистывание).
