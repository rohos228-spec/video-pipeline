## C. ЗАПРЕТ: зависимость от колонок / uuid

**Неверно:** «во входе 199 uuid → надо 199 полных ops».
**Верно:** разрежь полный закадр на сцены → у каждой сцены `shots[]` по логике монтажа.

- Сцена ≠ колонка закадра.
- Число `shots[]` ≠ число колонок, попавших в отрезок текста.
- Серия кадров = `shots[]` сцены (establish → develop → insert…), сколько нужно смыслу.
- Пайплайн сам привяжет сцену к кускам закадра по `start_words`/`end_words`.

Запрещено:
- плодить сцены «1 колонка = 1 сцена»;
- писать отказ «не хватает объёма на N ops»;
- копипастить один shot-текст на все колонки сцены.

## D. ПОЛНЫЙ ЗАКАДР → ГРАНИЦЫ СЦЕН

1. Возьми цельный закадр (склейка / script).
2. Разрежь на сцены **по смыслу**, не по столбцам.
3. `start_words` / `end_words` = цитаты 3–12 слов, в тексте **ровно один раз**.
4. Сцены стык в стык, без дыр и наложений.
5. Не выдумывай слова, которых нет в закадре.

## G. ПАСПОРТ СЦЕНЫ (обязателен целиком) = ИСТОЧНИК ПРАВДЫ

У **каждой** сцены заполни ВСЕ слоты. Пустой слот = брак.

| Слот | Поле | Что писать |
|------|------|------------|
| границы | `start_words` / `end_words` | цитаты из полного закадра |
| переход | `переход_в_сцену` | cut / dissolve / fade / smash… |
| логика монтажа | `структура_сцены` + `тип_стыка` | continuity/associative/parallel/developing |
| окружение | `место` | конкретное пространство |
| персонажи | `персонажи_сцены` | c01 / … / "" |
| ракурс-доминанта | `особенность_доминанта` | главный вид сцены |
| стиль | `тип_сцены` | Кинематографический реализм / … |
| смысл | `смысл_сцены` | что зритель должен понять (1 фраза) |
| акцент | `акцент` | **один** визуальный центр сцены (конкретный объект/жест), уникален vs соседних сцен |
| кластер | `номер_кластера` | свет/ось/одежда |
| видео-логика | `shots[]` | серия битов сцены **по монтажу** (§I) |

`shots[]`: столько элементов, сколько **визуальных битов** нужно сцене.
Много шотов — нормально. Пайплайн дробит приём (outline → shot-батчи).

В `phase=outline` — `shots: []`. В `phase=shots` — полный `shots[]` только для
указанных `id_scene`.

Каждый shot (все поля обязательны):
`id_shot`, `роль` (establish|develop|insert|reaction|payoff),
`особенность_сцены` (**только** из словаря §I.5),
`акцент` (**уникальный** визуальный центр ЭТОГО шота — не копия сцены),
`действие`, `описание_кадра`, `логика_перехода` (cut/dissolve/… + зачем),
`фон`, `предметы`.

### G.0 Запрет одинаковых акцентов

- `scenes[i].акцент` ≠ `scenes[i±1].акцент` (разные объекты/жесты).
- Внутри сцены `shots[j].акцент` все **разные**; не копируй scene.акцент на каждый shot.
- `акцент` = конкретная вещь в кадре («пакет у двери», «канарейка в клетке»), не абстракция («напряжение», «власть»).
- `особенность_сцены` меняется по лестнице §I.3 (не «Средний план» на всех shots).

## I. FILM-PACK — КОГДА / ЧТО / НЕЛЬЗЯ (конкретные слова)

Сначала структура стыка, потом карточки кадра. Не начинай с «красивого» приёма.

### I.1 Когда какую структуру брать

| Задача сцены | структура_сцены | тип_стыка | переход_в_сцену | Типичные планы |
|--------------|-----------------|-----------|-----------------|----------------|
| Диалог, быт, жест «поднял→донёс», непрерывное время | continuity | action / screen_position | cut | Средний→Крупный, Диалог |
| Сжать день, смена места/времени, метафора | associative | form / concept | dissolve / fade | Деталь объекта, Сверхкрупный |
| Две линии «одновременно» | parallel | none (внутри) | cut / smash | Общий план + чередование |
| Один длинный путь/коридор | developing | combined / none | cut на финальный CU | Динамическая камера → Крупный |
| Удар идеи, не действия | associative | concept | cut / smash | Деталь → реакция (Крупный план лица) |
| Погоня + тиканье в другом месте | parallel | action | cut / smash | Динамическая + ужесточение |
| Глаз→луна / колесо→колесо | associative | form | dissolve | Макросъемка / Деталь формы |

Типичный ролик: `continuity → associative (скачок) → continuity → parallel → developing`.

### I.2 Когда какой план → `особенность_сцены` (словарь, только эти)

| Нужно зрителю | особенность_сцены | Не вместо этого |
|---------------|-------------------|-----------------|
| Где мы / масштаб | Панорамный вид / Общий план локации / Экстерьер | Крупный план лица |
| Кто целиком + место | Общий план локации / Интерьер | Макросъемка |
| Тело + жест | Средний план персонажа | Панорамный вид |
| Диалог до пика | Средний план персонажа → Крупный план лица | сразу Сверхкрупный на каждой реплике |
| Эмоция / поворот | Крупный план лица | Панорамный вид |
| Максимум чувства на миг | Сверхкрупный план глаз | длинный сверхкруп с речью |
| Символ / foreshadow / улика | Деталь объекта / Демонстрация предмета / Макросъемка | Средний «просто так» |
| Связь двоих | Диалог | только одиночные без master |
| География без героя | Панорамный вид / Архитектурный акцент | Портретный кадр |
| Удар / бег | Экшен-сцена / Динамическая камера | Статичная композиция |
| Толпа | Массовка / Групповая сцена | Крупный одного без причины |

Полный список допустимых значений `особенность_сцены`:
Крупный план лица | Сверхкрупный план глаз | Средний план персонажа | Общий план локации | Панорамный вид | Вид сверху | Вид с дрона | Вид от первого лица | Силуэт | Групповая сцена | Массовка | Экшен-сцена | Диалог | Интерьер | Экстерьер | Деталь объекта | Макросъемка | Динамическая камера | Статичная композиция | Симметричная композиция | Контровой свет | Ночной кадр | Закатный кадр | Рассветный кадр | Атмосферный туман | Историческая реконструкция | Документальная хроника | Замедленное действие | Демонстрация предмета | Художественная постановка | Портретный кадр | Бытовая сцена | Сцена природы | Сцена разрушения | Сцена катастрофы | Архитектурный акцент

**Hitchcock:** важный объект = больше площади кадра. Крошечный проп на фоне мусора = брак.

### I.3 Когда какой переход

| Переход | Когда | Не когда |
|---------|-------|----------|
| cut | то же время; parallel; action | мягкий эллипсис «прошла неделя» |
| dissolve | время/место; form match; грусть | каждая реплика диалога |
| fade | конец акта/темы | между MCU↔MCU в одном разговоре |
| wipe | sci-fi / комедия | серьёзная драма «просто так» |
| smash | удар контрастом (тишина→крик) | спокойный continuity |
| j_cut / l_cut | звук ведёт / реакция под речь | мир реально сменился → smash |
| exit_frame | смена локации без dissolve | телепорт внутри кадра |

### I.4 НЕЛЬЗЯ МЕШАТЬ

**continuity:** не action 2-shot→2-shot тех же; не axial punch-in без причины; не dissolve между репликами; не dutch+dolly-zoom+handheld сразу; один look одежды/света; insert → реакция; не CU на географию; не ELS на эмоцию лица.
**associative:** dissolve всегда «что-то значит»; form match только на похожей форме; concept должен угадываться; не dissolve между parallel-линиями.
**parallel:** укорачивай планы; между линиями только cut/smash; не dip-to-black каждый кусок.
**developing:** не рви take jump’ами; конец = CU/insert ок.

Друзья: LS→action→CU; MCU left↔right; OTS→single→CU; reaction→ELS reveal; ECU form dissolve ECU; static→steadicam→static→CU.
Враги: continuity+dissolve на репликах; parallel+dip-to-black; match-dissolve+jump-cut; dutch+zolly+handheld сразу.

### I.5 Справочники значений полей

структура_сцены: `continuity` | `associative` | `parallel` | `developing`  
тип_стыка: `action` | `screen_position` | `form` | `concept` | `combined` | `none`  
переход_в_сцену / логика_перехода: `cut` | `dissolve` | `fade` | `wipe` | `smash` | `exit_frame` | `j_cut` | `l_cut` (+ фраза зачем)

тип_сцены (стиль картинки, ≠ структура): Реализм | Кинематографический реализм | Импрессионизм | Экспрессионизм | Сюрреализм | Минимализм | Поп-арт | Ар-деко | Детская книжная иллюстрация | Детективная доска

роль шота: `establish` | `develop` | `insert` | `reaction` | `payoff`
