## F. characters

Только индивидуальные сущности. Толпа/группа — НЕ персонаж.

```json
{"id":"c01","имя":"…","внешность":"…","одежда":"…","характер":"…","правила":""}
```

Вариация: `имя` = `оставь формат неизменный`, `правила` = `c01`.
В сцене: `персонажи_сцены` = `c01` / `c01,c02` / `""`.

### F.1 Персонажи — РЕДКО (критическое правило)

Персонаж в кадре = **исключение**, не фон по умолчанию.

**Когда МОЖНО ставить персонажа в shot / `персонажи_сцены`:**
- в отрезке закадра этой сцены (или в фокусе этого шота) о нём **прямо говорят**:
  имя, «он/она» с ясным референтом, действие героя («пишет», «вошёл», «сказал»);
- нужен payoff реакции **именно на названного** человека.

**Когда ЗАПРЕЩЕНО тащить лицо/фигуру героя:**
- закадр про место, время, атмосферу, толпу, предмет, событие без героя;
- «для красоты», «чтобы был кто-то в кадре», «типичный establish с силуэтом»;
- повтор того же героя shot→shot без новой реплики/факта о нём в тексте;
- серия портретов / средних планов персонажа подряд, пока текст не о нём.

**Дефолт кадра без прямой речи о герое:** пустое / полупустое пространство,
деталь предмета, толпа без идентификации, руки/ноги без лица, объект-акцент.
`персонажи_сцены` = `""`, если сцена целиком не про названных людей.

Ориентир ролика: персонаж читается **не чаще ~1 из 3–4 shots** в среднем
(и только там, где текст это оправдывает). Лучше меньше лиц, чем «герой везде».

## G. ПАСПОРТ СЦЕНЫ (обязателен целиком) = ИСТОЧНИК ПРАВДЫ

У **каждой** сцены заполни ВСЕ слоты. Пустой слот = брак.

| Слот | Поле | Что писать |
|------|------|------------|
| границы | `start_words` / `end_words` | цитаты из полного закадра |
| переход | `переход_в_сцену` | cut / dissolve / fade / smash… |
| логика монтажа | `структура_сцены` + `тип_стыка` | continuity/associative/parallel/developing |
| окружение | `место` | конкретное пространство (адрес/зона + что видно) |
| свет сцены | `освещение` | базовый свет локации: источник, направление, контраст, цвет |
| персонажи | `персонажи_сцены` | c01 / … / "" |
| ракурс-доминанта | `особенность_доминанта` | главный вид сцены |
| стиль | `тип_сцены` | Кинематографический реализм / … |
| смысл | `смысл_сцены` | **видимый** факт/жест в кадрах (не мета про зрителя) |
| акцент | `акцент` | **один** визуальный центр сцены (конкретный объект/жест), уникален vs соседних сцен |
| кластер | `номер_кластера` | один look: одежда/свет/ось |
| видео-логика | `shots[]` | серия битов сцены **по монтажу** (§I) |

`shots[]`: столько элементов, сколько **визуальных битов** нужно сцене.
Много шотов — нормально. Пайплайн дробит приём (outline → shot-батчи).

В `phase=outline` — `shots: []`, но `место` + `освещение` уже заполнены.
В `phase=shots` — полный `shots[]` только для указанных `id_scene`.

Каждый shot (все поля обязательны):
`id_shot`, `роль` (establish|develop|insert|reaction|payoff),
`особенность_сцены` (**только** из словаря §I.2),
`акцент` (**уникальный** визуальный центр ЭТОГО шота — не копия сцены),
`действие`, `описание_кадра`, `логика_перехода` (cut/dissolve/… + зачем),
`фон`, `освещение`, `предметы`.

### G.0 Запрет одинаковых акцентов

- `scenes[i].акцент` ≠ `scenes[i±1].акцент` (разные объекты/жесты).
- Внутри сцены `shots[j].акцент` все **разные**; не копируй scene.акцент на каждый shot.
- `акцент` = конкретная вещь в кадре («пакет у двери», «канарейка в клетке»), не абстракция («напряжение», «власть»).
- `особенность_сцены` меняется по лестнице §I.2 (не «Средний план» на всех shots).

### G.0a СЮЖЕТНАЯ ПОСЛЕДОВАТЕЛЬНОСТЬ — ЗАПРЕТ ПОВТОРОВ (критическая ошибка)

Ролик = **одна цепь событий**, а не набор «вариантов одного кадра».
Каждый следующий shot / следующая сцена — **логичное продолжение** сюжета и действия.

**Правило «началось → продолжается»:**
если в shot N действие уже началось (вошёл, поднял, открыл, положил, бежит, говорит…),
shot N+1 **нельзя** показать «то же самое иначе» (другой угол / та же поза / тот же жест
с нуля). Shot N+1 = **следующая фаза** того же действия или следующий сюжетный бит:
донёс → отпустил; открыл дверь → шагнул внутрь; увидел пакет → ноги проходят мимо;
реакция на лицо → рука тянется. Не reset, не remake.

**Что считать повтором (брак — критично):**
- два соседних shot с одним и тем же `действие` (синонимы тоже: «стоит у двери» /
  «находится у двери» / «замер у входа»);
- тот же момент времени, просто другая камера («wide того же» → «medium того же»
  без сдвига по времени/фазе действия);
- соседние сцены с одним и тем же видимым событием («пакет лежит» → снова «пакет лежит»);
- копипаст `фон`+`действие`+`акцент` с косметической правкой слов;
- серия «портрет / доска / портрет / доска» без развития фабулы.

**Что делать вместо повтора:**
1. Разбей жест на фазы: approach → contact → consequence → reaction.
2. Чередуй **кто/что в фокусе**: пространство → тело → лицо → рука/улика → реакция.
3. Между сценами двигай **фабулу** (новое место, новое время, новый факт), не «пересъёмку».
4. В `логика_перехода` пиши **зачем режем дальше по сюжету**, не «красивый ракурс».

Перед ответом пройди цепочку `shots[].действие` вслух: должна читаться как краткий
синопсис («вошёл → сел → пишет → перо касается бумаги»), а не как список ракурсов
одного стоп-кадра.

### G.0b ЦЕПЬ ДЕЙСТВИЯ ВНУТРИ ГРУППЫ СЦЕНЫ (критическая ошибка)

Сцена = **мини-эпизод с развитием**, не альбом статичных поз «в одной локации».

**Обязательно для КАЖДОЙ сцены с ≥2 shots:**
1. Напиши сквозную цепь фаз (3–7 глаголов) ДО заполнения shots, например:
   `вошёл → сел → взял перо → пишет → перо рвёт бумагу → поднимает голову`.
2. Каждый `shots[j].действие` = **ровно одна фаза** этой цепи (не синоним соседа).
3. Тело/руки/предмет в кадре **в движении** (mid-action freeze): вес смещён, рука
   в траектории, дверь на полпути, предмет перекладывают — НЕ «позирует для фото».
4. Соседние shots одной сцены обязаны отличаться **минимум двумя** из:
   - фаза действия (что уже произошло),
   - положение тела / жест рук,
   - состояние пропа (закрыт→открыт, лежит→в руках, чистый→испачкан),
   - крупность/ось камеры (§I.2a).
5. `описание_кадра` явно говорит **что изменилось с прошлого шота** («теперь рука
   уже касается ручки», «пакет уже открыт», «тело уже на полу»).

**Запрещённые «статичные» действия (брак, если нет движения в той же фразе):**
`стоит`, `сидит`, `лежит`, `находится`, `замер`, `смотрит`, `глядит`, `позирует`,
`портрет`, `в кадре`, `присутствует`, `виднеется`, `остаётся`, `замирают`,
`holds a pose`, `standing`, `sitting looking`, `posed`.

**Разрешённый паттерн вместо статики:**
- не «сидит за столом» → «садится / отодвигает стул / наклоняется к бумагам /
  перелистывает / поднимает взгляд от страницы»;
- не «смотрит на доску» → «прикалывает фото / тянет нить / обводит карточку карандашом»;
- не «последователи стоят рядами» → «заполняют ряды / синхронно склоняются /
  поднимают головы по жесту / опускают ладони к полу».

**Визуальный twin внутри группы (брак):**
если два shot одной сцены можно перепутать на стоп-кадре (тот же силуэт героя,
тот же главный prop в том же месте кадра, та же дистанция) — перепиши действие
и/или камеру. Смена только слов при той же картинке = повтор.

`структура_сцены=continuity` почти всегда требует `тип_стыка=action` и цепь фаз.
Insert/деталь — тоже фаза («перо УЖЕ касается бумаги»), не декоративный still-life
без сдвига сюжета.

### G.0c Предметы и расположение — БЕЗ ЧАСТЫХ ПОВТОРОВ

Запрещено «залипать» на одной и той же раскладке вещей.

**Брак:**
- один и тот же главный prop в той же зоне кадра shot→shot→shot
  (пакет у нижнего правого угла → снова пакет там же → снова);
- одинаковый список `предметы` у соседних shots с косметической правкой слов;
- одна композиция стола/доски/полки без сдвига (те же 3 объекта в тех же местах);
- «декоративный мусор» одних и тех же сумок/газет в каждом establish.

**Делай так:**
1. В каждом shot новый **визуальный центр** среди вещей (другой объект ИЛИ
   та же вещь в **новой фазе/месте**: лежит → в руках → открыт → брошен).
2. Чередуй фокус: пространство ↔ деталь ↔ другой предмет ↔ (редко) человек.
3. Если предмет важен сюжетно — показывай его **фазами**, не копией раскладки.
4. Соседние `предметы` должны отличаться составом или позицией минимум на 50%
   (не тот же CSV «поручни, сумки, газеты» подряд).

### G.1 Постановка кадра: фон + свет + камера (главное)

Пиши как для генерации картинки/видео, не как рецензию.

**`смысл_сцены` — только видимое.**  
ОК: «пакет лежит у двери вагона среди ног пассажиров».  
Брак: «бытовая поездка уже становится атакой, зритель ещё не знает»,
«никто не подозревает», «напряжение растёт», «посев угрозы», «намёк на катастрофу».

**`фон` — подробно, не одно слово.** Минимум: стены/поверхности, глубина
(передний/средний/задний план), материал/цвет, что читается за акцентом.
Брак: «интерьер метро», «пол», «стена».  
ОК: «серый рифлёный пол вагона, в глубине створки дверей с жёлтой полосой,
рекламные плакаты и поручни вдоль потолка».

**`освещение` — конкретно.** Источник + направление + контраст + тон.
Словарь: soft diffused / hard directional / low-key / high-key / backlight rim /
fluorescent overhead / practical warm lamp / overcast window.  
ОК: «холодный fluorescent сверху + слабый rim от окна вагона, мягкие тени под
поручнями».  
Брак: «кинематографичный свет», «атмосферно».

**Фоны внутри ОДНОЙ сцены — меняй, но только логично (обязательно):**

Сцена ≠ один замороженный бэкдроп на все shots. Камера и действие **гуляют
по пространству**, фон обязан обновляться.

Разрешённые мотивировки смены фона внутри того же `место`:
- другая зона той же локации (дверь вагона → середина прохода → торец);
- новый угол / ось: за спиной теперь окно, а не плакаты; потолок вместо стен;
- персонаж/объект **переместился** — фон естественно другой;
- insert: доминирует поверхность акцента (пол, стол, стекло), стены — кромкой;
- объявленный микро-переход внутри сцены (вышел в коридор той же станции).

**Брак continuity:**
- телепорт в чужой мир без смены `место` / без логики перехода
  (метро → внезапно лес; кабинет → космос);
- два соседних shot с **дословно одним и тем же** абзацем `фон`
  (копипаст без дельты зоны/угла);
- «новый красивый фон» без связи с действием и камерой.

**Правило дельты фона:**
если shot N и N+1 в одной сцене — в `фон` явно другая доминирующая зона
или другой читаемый задник; в `описание_кадра` напиши **почему** фон сменился
(«камера ушла к торцу», «опустились к полу», «герой прошёл к окну»).

Свет в пределах одного `место`: сохраняй **семью источников** (тот же тип
потолочного / оконного), но допускается сдвиг интенсивности/блика по зоне.
Полная смена схемы света — только при эллипсисе времени или смене локации.

**`описание_кадра`** = камера + композиция + что резко / что в фоне + как свет
ложится на акцент + **фаза действия сейчас**. Не пересказ закадра и не
«смысл для зрителя».

## I. FILM-PACK — КОГДА / ЧТО / НЕЛЬЗЯ (конкретные слова)

Сначала структура стыка, потом карточки кадра. Не начинай с «красивого» приёма.

### I.1 Когда какую структуру брать

| Задача сцены | структура_сцены | тип_стыка | переход_в_сцену | Типичные планы |
|--------------|-----------------|-----------|-----------------|----------------|
| Диалог, быт, жест «поднял→донёс», непрерывное время | continuity | action / screen_position | cut | Средний→Крупный, Диалог |
| Сжать день, смена места/времени, метафора | associative | form / concept | dissolve / fade | Деталь объекта, Сверхкрупный |
| Две линии «одновременно» | parallel | none (внутри) | cut / smash | Общий план + чередование |
| Один длинный путь/коридор | developing | combined / none | cut на финальный CU | Динамическая камера → Крупный |
| Удар идеи, не действия | associative | concept | cut / smash | Деталь → реакция (Крупный план лица) |
| Погоня + тиканье в другом месте | parallel | action | cut / smash | Динамическая + ужесточение |
| Глаз→луна / колесо→колесо | associative | form | dissolve | Макросъемка / Деталь формы |

Типичный ролик: `continuity → associative (скачок) → continuity → parallel → developing`.

### I.2 Когда какой план → `особенность_сцены` (словарь, только эти)

| Нужно зрителю | особенность_сцены | Не вместо этого |
|---------------|-------------------|-----------------|
| Где мы / масштаб | Панорамный вид / Общий план локации / Экстерьер | Крупный план лица |
| Кто целиком + место | Общий план локации / Интерьер | Макросъемка |
| Тело + жест | Средний план персонажа | Панорамный вид |
| Диалог до пика | Средний план персонажа → Крупный план лица | сразу Сверхкрупный на каждой реплике |
| Эмоция / поворот | Крупный план лица | Панорамный вид |
| Максимум чувства на миг | Сверхкрупный план глаз | длинный сверхкруп с речью |
| Символ / foreshadow / улика | Деталь объекта / Демонстрация предмета / Макросъемка | Средний «просто так» |
| Связь двоих | Диалог | только одиночные без master |
| География без героя | Панорамный вид / Архитектурный акцент | Портретный кадр |
| Удар / бег | Экшен-сцена / Динамическая камера | Статичная композиция |
| Толпа | Массовка / Групповая сцена | Крупный одного без причины |

Полный список допустимых значений `особенность_сцены`:
Крупный план лица | Сверхкрупный план глаз | Средний план персонажа | Общий план локации | Панорамный вид | Вид сверху | Вид с дрона | Вид от первого лица | Силуэт | Групповая сцена | Массовка | Экшен-сцена | Диалог | Интерьер | Экстерьер | Деталь объекта | Макросъемка | Динамическая камера | Статичная композиция | Симметричная композиция | Контровой свет | Ночной кадр | Закатный кадр | Рассветный кадр | Атмосферный туман | Историческая реконструкция | Документальная хроника | Замедленное действие | Демонстрация предмета | Художественная постановка | Портретный кадр | Бытовая сцена | Сцена природы | Сцена разрушения | Сцена катастрофы | Архитектурный акцент

**Hitchcock:** важный объект = больше площади кадра. Крошечный проп на фоне мусора = брак.

### I.2a Чередование планов (обязательно)

Не залипай на одном масштабе. Внутри сцены из ≥3 shots крупность **должна гулять**:
общий/панорама ↔ средний (часто **без** лица) ↔ деталь/insert ↔ (редко) портрет/реакция.

**Приоритет планов (от частого к редкому):**
1. `Общий план локации` / `Панорамный вид` / `Интерьер` / `Экстерьер` / `Архитектурный акцент`
2. `Деталь объекта` / `Демонстрация предмета` / `Макросъемка`
3. `Средний план` среды/жеста **без идентификации героя** (руки, толпа, спины)
4. `Крупный план лица` / `Портретный кадр` / `Сверхкрупный` — **только** если
   закадр прямо о человеке (§F.1); не разбавляй ими «ритм ради ритма».

- Запрещено: 3+ подряд одинаковых или почти одинаковых планов
  (три `Общий план локации`, три `Деталь объекта` без смены объекта/зоны).
- Запрещено: два подряд одинаковых значения `особенность_сцены`.
- Запрещено: цепочка `Средний план персонажа` / `Крупный план лица` /
  `Портретный кадр`, пока текст не требует героя.
- Insert/деталь после establish — норма; снова establish того же момента — повтор.

Лестница-помощник (не шаблон; портрет — опционален):
`Общий план локации → Деталь объекта → другой угол локации → Деталь другого предмета
→ (если текст о герое) Средний/Крупный → …`

### I.2b Тип «Детективная доска» / crime board (когда и как)

`тип_сцены` = `Детективная доска` — **редкий приём**, не дефолт.

**Запрет:** два раза подряд (сцена→сцена или shot→shot с этим типом / этим look).
Между досками минимум одна обычная live-action сцена (реализм / кинореализм / …).

Когда всё же доска — пиши **насыщенно и конкретно**, как настоящую следственную
стену, не «доска с бумажками»:
- поверхность (пробка / белая магнитная / кирпич с скотчем) + свет лампы/настолки;
- сетка связей: нитки/булавки какого цвета, какие узлы соединяют;
- фото/вырезки: **кого/что** видно (лицо, адрес, газета, схема метро) — по именам/кодам;
- записки, даты, стрелки, маркеры, пятна, скрепки, липкий скотч, полярoid-поля;
- один главный `акцент` (новый узел / обведённое фото / свежая нитка), остальное — фон;
- `предметы` перечисли списком 6–12 конкретных вещей на доске;
- `фон` и `описание_кадра` — плотные (передний план булавок, средний — фото, глубина стены).

Брак: «криминальная доска», «фото и нитки», пустой `предметы`, повтор доски без нового факта.

### I.3 Когда какой переход

| Переход | Когда | Не когда |
|---------|-------|----------|
| cut | то же время; parallel; action | мягкий эллипсис «прошла неделя» |
| dissolve | время/место; form match; грусть | каждая реплика диалога |
| fade | конец акта/темы | между MCU↔MCU в одном разговоре |
| wipe | sci-fi / комедия | серьёзная драма «просто так» |
| smash | удар контрастом (тишина→крик) | спокойный continuity |
| j_cut / l_cut | звук ведёт / реакция под речь | мир реально сменился → smash |
| exit_frame | смена локации без dissolve | телепорт внутри кадра |

### I.4 НЕЛЬЗЯ МЕШАТЬ

**continuity:** не action 2-shot→2-shot тех же; не axial punch-in без причины; не dissolve между репликами; не dutch+dolly-zoom+handheld сразу; один look одежды/света; insert → реакция; не CU на географию; не ELS на эмоцию лица.
**associative:** dissolve всегда «что-то значит»; form match только на похожей форме; concept должен угадываться; не dissolve между parallel-линиями.
**parallel:** укорачивай планы; между линиями только cut/smash; не dip-to-black каждый кусок.
**developing:** не рви take jump’ами; конец = CU/insert ок.

Друзья: LS→action→CU; MCU left↔right; OTS→single→CU; reaction→ELS reveal; ECU form dissolve ECU; static→steadicam→static→CU.
Враги: continuity+dissolve на репликах; parallel+dip-to-black; match-dissolve+jump-cut; dutch+zolly+handheld сразу.

### I.5 Справочники значений полей

структура_сцены: `continuity` | `associative` | `parallel` | `developing`  
тип_стыка: `action` | `screen_position` | `form` | `concept` | `combined` | `none`  
переход_в_сцену / логика_перехода: `cut` | `dissolve` | `fade` | `wipe` | `smash` | `exit_frame` | `j_cut` | `l_cut` (+ фраза зачем)

тип_сцены (стиль картинки, ≠ структура): Реализм | Кинематографический реализм | Импрессионизм | Экспрессионизм | Сюрреализм | Минимализм | Поп-арт | Ар-деко | Детская книжная иллюстрация | Детективная доска

роль шота: `establish` | `develop` | `insert` | `reaction` | `payoff`

## J. АЛГОРИТМ

1. Прочитай полный закадр как **сюжетную дугу** (что происходит по порядку).
2. `characters` — реестр сущностей; не значит, что они появятся в каждом кадре.
3. Разрежь на сцены по смыслу; на каждую — полный паспорт (§G) + `shots[]` как

4. Для каждого shot спроси: «текст прямо о человеке?» → иначе без персонажа (§F.1).
5. Смени зоны фона внутри сцены логично (§G.1); не копипасть `фон`/`предметы`.
6. Проверь чередование планов (§I.2a) и запрет подрядных досок (§I.2b).
7. `ops` = `[]` (или точечные правки).
8. Самопроверка §K → один JSON.
9. **Не** считай uuid/колонки. **Не** пиши error про объём.
