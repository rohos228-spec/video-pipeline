Только индивидуальные сущности. Толпа/группа/народ — НЕ персонаж, ID не давать.

```json
{"id":"c01","имя":"…","внешность":"…","одежда":"…","характер":"…","правила":""}
```

Вариация: `имя` = ровно `оставь формат неизменный`, `правила` = `c01`, в полях только отличия.
Порядок: герой → вариации → остальные. ID подряд.
В ops: `"персонажи":"c01"` или `"c01, c03"` или `""` (не виден / только упомянут / массовка).
В ops меняй только нужные поля; uuid только из входа.

`тип_сцены` = стиль картинки (Реализм / Кинематографический реализм / …).

## I. ВСТРОЕННЫЙ FILM-PACK (рабочий словарь)

Это сжатая ЧАСТЬ I из FILM_LANGUAGE_COMPLETE. Полный том (~70k) не нужен в каждом вызове.

### I.1 Выбор структуры сцены

| Если в закадре… | структура_сцены | тип_стыка | переход_в_сцену |
|-----------------|-----------------|-----------|-----------------|
| жест, диалог, «здесь и сейчас» | continuity | action / screen_position | cut |
| скачок времени/места, метафора | associative | form / concept | dissolve / fade |
| две линии одновременно | parallel | none внутри; cut между | cut / smash |
| один длинный проход | developing | combined / none | cut на финальный CU |

### I.2 Крупность → особенность_сцены

| Нужно | особенность |
|-------|-------------|
| где мы | Общий план локации / Панорамный вид / Экстерьер / Интерьер |
| тело+жест | Средний план персонажа |
| эмоция | Крупный план лица |
| деталь/улика | Деталь объекта / Демонстрация предмета |
| двое | Диалог |
| удар/бег | Экшен-сцена / Динамическая камера |
| путь камеры | Динамическая камера (developing) |

### I.3 Переходы

| переход | когда | не когда |
|---------|-------|----------|
| cut | то же время; parallel; action | «прошла неделя» |
| dissolve | время/место; form; грусть | каждая реплика диалога |
| fade | граница акта | внутри одного разговора |
| wipe | sci-fi/комедия | серьёзная драма «просто так» |
| smash | жёсткий контраст | спокойный continuity |

### I.4 Нельзя мешать

**continuity:** не 2-shot→2-shot action; не dissolve между репликами; не axial punch-in без причины; один look одежды/света; один ударный приём.
**associative:** dissolve всегда значит скачок; form без похожей формы = брак; concept без считываемой идеи = брак; не dissolve между parallel-линиями.
**parallel:** укорачивай планы; между линиями только cut/smash.
**developing:** не рви проход montage’ем; конец = CU/insert ок.

Друзья: LS→action→CU; MCU left↔right; OTS→single→CU; reaction→ELS reveal; ECU form dissolve ECU; static→steadicam→static→CU.
Враги: continuity+dissolve на репликах; parallel+dip-to-black каждый кусок; match-dissolve+jump-cut aesthetic; dutch+zolly+handheld сразу.

### I.5 Справочники значений

структура_сцены: `continuity` | `associative` | `parallel` | `developing`
тип_стыка: `action` | `screen_position` | `form` | `concept` | `combined` | `none`
переход_в_сцену / переход_в_кадр: `cut` | `dissolve` | `fade` | `wipe` | `smash` | `exit_frame` | `j_cut` | `l_cut`

тип_сцены (стиль): Реализм | Кинематографический реализм | Импрессионизм | Экспрессионизм | Сюрреализм | Минимализм | Поп-арт | Ар-деко | Детская книжная иллюстрация | Детективная доска  
(дефолт-микс: Реализм 60% / Кинематографический реализм 30% / Детективная доска 10%; смена стиля → номер_кластера++)

особенность_сцены: Крупный план лица | Сверхкрупный план глаз | Средний план персонажа | Общий план локации | Панорамный вид | Вид сверху | Вид с дрона | Вид от первого лица | Силуэт | Групповая сцена | Массовка | Экшен-сцена | Диалог | Интерьер | Экстерьер | Деталь объекта | Макросъемка | Динамическая камера | Статичная композиция | Симметричная композиция | Контровой свет | Ночной кадр | Закатный кадр | Рассветный кадр | Атмосферный туман | Историческая реконструкция | Документальная хроника | Замедленное действие | Демонстрация предмета | Художественная постановка | Портретный кадр | Бытовая сцена | Сцена природы | Сцена разрушения | Сцена катастрофы | Архитектурный акцент

Внутри кластера: место/свет/ось/одежда непрерывны (кроме осознанного associative → новый кластер).
