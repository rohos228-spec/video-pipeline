## Калибровка стоимости по биллингу Kie (2026-10-01)

`scripts/calibrate_kie_cost.py`, балансы Kie до/после каждого платного вызова (1 кредит = $0.005). Подобраны тарифы gpt-5.6-sol: 1.6 / 8.4 / 0.0 $/М (свежий вход / выход / кэш);
расхождение с биллингом не более $0.0004 на вызов. Два измерения исключены как загрязнённые (посторонний потребитель ключа). Подробности: `docs/KIE_COST_CALIBRATION.md`.
Цены Outsee, ElevenLabs, Suno, Vibecode (наценка 3,0 в оценке) не откалиброваны; сверка с балансами поставщиков (`spend_reconcile`) покрыта тестами, живьём не выполнялась.
