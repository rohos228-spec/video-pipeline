# «кино С фоном»

Новая встроенная группа библиотеки, ID `cinema_with_background`. Старая
«Каркас → площадка → шоты + QC» не заменяется и существующие проекты автоматически
не переводятся на новую схему.

## Как использовать

1. Перезапустить backend Studio после обновления кода и обновить страницу.
2. В библиотеке групп (планирование) выбрать **«кино С фоном»**.
3. До запуска иметь готовый закадр. Выполнить цепочку:
   **Границы сцен → Каркас → Площадка → Шоты → QC → Стиль → Фон сцены → Отчёт**.
4. Подключить/запустить обычную ноду **Картинки** после группы. Группа создаёт
   отдельные фоны и промты кадров, но не заменяет ноду генерации кадров.

«Площадка» новой группы использует утверждённый каркас, а не придумывает сцену
заново из одного закадра. «Фон сцены» создаёт пустую локацию по зонам, предметам,
проходам и выбранному стилю. Люди и действие не включаются в её вход.
Это отдельный платный вызов выбранного генератора изображений на каждую сцену.

## Связи и хранение

- Сцена определяется UUID VO-родителя; номер кадра и `Frame.scene_id` не являются
  ключом фонового референса.
- PNG сохраняется в `backgrounds/`, запись/промт/hash/status — в
  `Frame.attrs.scene_background_ref` у VO-родителя.
- Фон не является монтажным кадром, не получает закадр и не попадает в `scenes/`.
- При повторном запуске готовый фон переиспользуется, если площадка и стиль не
  изменились и файл валиден. После изменения создаётся новая версия.
- На монтажной доске общий фон виден отдельно как «Фон сцены», без кнопки удаления
  ручного референса. При устаревании отображается предупреждение.

## Генерация кадров

- Главный кадр: фон + доступные референсы персонажей.
- Дочерний кадр: тот же фон + PNG родительского кадра.
- Обычная генерация и регенерация с монтажной доски используют общий resolver.
- Фон фиксирует место, материалы и свет; действие кадра может менять начальное
  состояние двери/предмета. Начальная закрытая дверь на фоне не должна сбрасывать
  её уже открытое состояние в следующем кадре.
- Без готового актуального фона генерация останавливается. При частичной загрузке
  референсов в Outsee запрос генерации не отправляется.
- После смены фона старые PNG автоматически не заменяются: их требуется явно
  перегенерировать с доски. Отметка hash фиксируется только после успеха.

## Ограничения

Текущий общий лимит — **2 референса**. Фон + два листа персонажей, либо фон +
родитель + дополнительный ручной реф превышают лимит. Новая группа выдаёт явную
ошибку, а не молча выбрасывает персонажа или фон. Коррекция, добавляющая текущий
PNG к обязательным референсам, также подчиняется этому ограничению.

В один проект можно вставить один экземпляр новой группы: повторная вставка
отклоняется до изменения канваса. Старую и новую группы не следует запускать
как альтернативных авторов одних и тех же карточек: данные сцен у проекта общие.

Проверки выполнены моками без платных API-вызовов. Визуальное качество фона,
сохранность геометрии при смене ракурса и результат конкретной модели требуют
проверки на реальном проекте.
