## Регрессия

Прежние runtime/diagnosis-артефакты содержали старые хеши шести загруженных
модулей. Выполнены последовательно существующие `runtime` (25) и `diagnose`
(25) в `--network none`; оба GREEN. Код `app/` не изменён относительно
исходного checkpoint. Долгий native exhaustion и браузер не повторялись.

Новые проверки однократного диагностического адаптера: 22 GREEN. Проверены
штатный `gpt_api.chat`, точные байты запроса, сохранение событий SSE/ответа/usage,
схема оценки и существующая схема рекомендации, запрет исполнителя,
перезапуск/неопределённость/обрыв/параллельное резервирование/ошибка аудита,
отсутствие GET/continuation/второго POST, Unix gateway, блокировка сети процесса
и его потомка. Внешний HTTP провайдера заменён MockTransport.

## Вход и формат

Исторический `online-real-20260924-04`, срез до события **4140** включительно.
9 отобранных событий, полный оригинальный первый QC prompt/контракт внутри
не доверенных входных данных, первый накопленный ответ и результат разбора.
Штатный JSON retry уже объявлен; новый POST зарезервирован. Его ответ и
результат на момент среза неизвестны. Исчерпание retry и commit/rollback не
выводятся из отсутствия данных. Успешный второй ответ и отчётный диагноз
исключены. Исходные архивы сохранены; отбор/обезличивание описаны отдельно.

Схема Decision-v1 не допускает дополнительных полей оценки. Поэтому
однократный диагностический ответ имеет `assessment` и `recommendation`.
Внутренний `recommendation` проверяет прежний `validate_proposal`; Actions
не вызывается. Разрешены только рекомендации `wait` и `human_review`, они
сохраняются, а не исполняются. Проверка схемы не доказывает правильность
диагноза: содержательная оценка по рубрике остаётся локальным следующим шагом.

## Карточка

| Поле | Значение |
|---|---|
| Модель | Kie `gpt-5-6-sol`, reasoning `low` |
| Маршрут | `https://api.kie.ai/codex/v1/responses` |
| Контекст | 15 210 байт JSON-файла, 9 событий и архивный контракт |
| Полное HTTP-тело | 17 355 байт UTF-8; его SHA-256 привязан к gateway |
| Лимит | 1 зарезервированный POST за отдельный execution, 1 024 выходных токена |
| Повторы | Нет retry, continuation, split, recovery, retrieval GET или второго turn |
| Исполнение | Нет tools, Actions, finish/resume, изменения профилей/статусов/БД проекта |
| Сеть | Приложение `--network none`; только Unix socket существующего gateway |
| Состояние online | Выключено; реальная доступность маршрута не проверялась |
| Цена | Не подтверждена; денежного потолка нет |

Предел запросов проверяется непосредственно перед отправкой, атомарно в
отдельном SQLite WAL/FULL. В gateway тоже отдельный постоянный ledger с
лимитом 1 и проверкой точного тела. Reserved после падения не переиспользуется.
Шлюз не следует redirect и направляет запрос только в согласованный маршрут.
Проверки выполнены локально: реальный upstream, доступность провайдера,
соблюдение провайдером токенового лимита и денежные списания не проверены.

Для online требуется новое отдельное разрешение и активация этой привязки
существующего gateway с чистым pilot-ledger. Старый ledger/разрешение не
используются. Не подтверждены тарифы input/output/reasoning текущего
аккаунта, пересчёт credits в USD и дополнительные/минимальные списания.
Исторические credits не гарантируют цену нового запроса.

Нельзя запускать эту обёртку внутри работающего приложения: локальные
подмены HTTP-фабрики рассчитаны на отдельный изолированный процесс.

В подготовке не менялись prompt/model/data рабочих нод, бизнес-логика,
архивные события, Docker Desktop и прежний журнал. Нет push/PR/deploy,
реальных ключей или чтения `.env`. Синтетическая рекомендация в проверках
не является рекомендацией настоящей модели и не доказывает её надёжность.
