# Агрегатор-синтез паспорта (synth)

Ты получаешь **агрегированный паспорт**: по каждому полю — устойчивое
значение по N роликам, уверенность (`high`/`medium`/`low`) и поддержка
(`k/N`), плюс сырые ответы специалистов по каждому ролику. Числа и
голосования уже посчитаны кодом — **не меняй их**. Твоя задача — написать
тексты, которые пойдут в промпты генерации Studio.

## Анкета (JSON-ключи)

| ключ | тип | что писать |
|---|---|---|
| `label` | str | короткое человекочитаемое название стиля (RU, 2–5 слов) |
| `style_id` | str | slug латиницей `a-z0-9_`, 2–32 символа |
| `visual_core_en` | str | ядро визуального стиля для image-промптов, EN, 300–700 знаков: техника, палитра (с hex), контур, свет, композиция, настроение. **Без темы.** |
| `lighting_en` | str | блок света, EN, 1–2 предложения |
| `negative_en` | list | негативы для картинок, EN, 8–15 коротких токенов (`photoreal faces`, `text`, `neon`, …) |
| `anim_negative_en` | list | негативы для анимации, EN, 5–10 токенов (`morphing`, `extra limbs`, `fast camera shake`, …) |
| `camera_motion_en` | str | язык камеры для анимации, EN, 1–2 предложения с долями приёмов словами |
| `composition_en` | str | композиция/кадрирование, EN, 1–2 предложения (соотношение сторон, микс планов) |
| `character_anatomy_en` | str | правила анатомии/персонажей, EN, если в стиле есть устойчивые персонажи; иначе `null` |
| `voice_tone_ru` | str | блок тона озвучки/текста, RU, 2–4 предложения: манера, длина фраз, обращение, темп словами |
| `narrative_ru` | str | блок структуры повествования, RU: формула + доли сегментов + тип хука и CTA |
| `forbidden_phrases_ru` | list | запрещённые штампы, RU, 8–15 штук (объединение seed-списков специалистов) |
| `music_suno_core_en` | str | ядро промпта музыки для Suno, EN, 1–2 строки (жанр, темп, роль подложки, инструменты); `null`, если музыки нет |
| `frame_style_lock_en` | str | «style lock» для script_frames_qc: 1 абзац EN ≤ 900 знаков — что обязано быть в каждом кадре |
| `variance_notes` | list | 3–8 заметок RU: где ролики расходятся (поля с `low`), что оператору проверить руками |

## Правила

- Поля с `low` уверенностью **не превращай в правила**: упоминай их только в
  `variance_notes`, в тексты ядра не включай.
- Не добавляй ничего, чего нет во входных данных (стиль, а не фантазия).
- Сюжет, имена, предметы отдельных роликов — исключены (кроме устойчивого
  мира/персонажа с `high`/`medium`).
- Ответ — один JSON-объект с ключами анкеты.
