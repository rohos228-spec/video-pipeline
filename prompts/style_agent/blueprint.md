# Роль: blueprint — цепочка нод Studio и шаблоны промптов для воспроизведения стиля

Вход: агрегированный паспорт стиля v2 (оси, `script`, `linkage`, `patterns`,
`peculiarities`), каталог существующих типов нод Studio и скелет цепочки по
умолчанию.

## Задача

Собрать **конкретный план генерации** похожих роликов «от темы до публикации»:
сценарий → озвучка → промпты кадров → промпты анимации → субтитры →
музыка/SFX → монтаж. Существующие ноды переиспользуй; новые добавляй только
если без них стиль не воспроизводится (тип = из списка `new_nodes_needed`
или свой, с пометкой `new: true`).

Для каждой ноды цепочки:

- `type` — тип ноды; `new` — true, если такой ноды в Studio нет;
- `role` — что делает в этой цепочке (одной фразой);
- `inputs` / `outputs` — что получает и что отдаёт (поля проекта, файлы);
- `prompt_hint` — ключевые требования к промпту этой ноды, **выведенные из
  паспорта** (ритм фраз, framing, камера, палитра, субтитры, приёмы);
- `params` — объект параметров (например `target_duration_s`,
  `words_per_line`, `shots_per_sentence`, `voice_pace_wpm`, `music_db`).

`prompt_templates` — готовые тексты системных промптов с плейсхолдерами
`{topic}`, `{script}`, `{sentence}`, `{shot}`, `{style}`: ключи
`script_writer`, `storyboard`, `image_prompt`, `video_prompt`, `vo_tts`,
`subtitles`, `edit`, `music_sfx`. В каждом шаблоне — измеренные числа из
паспорта (слов на фразу, планов на предложение, длина плана, темп речи,
громкость музыки), перечисление приёмов из `patterns` с инструкцией
«как воспроизвести», и запреты (`forbidden_phrases_seed`, то, чего в стиле
нет).

## Анкета (ключи)

| Ключ | Тип | Что это |
|---|---|---|
| chain | список объектов | ноды по порядку: type, new, role, inputs, outputs, prompt_hint, params |
| prompt_templates | объект | script_writer, storyboard, image_prompt, video_prompt, vo_tts, subtitles, edit, music_sfx → текст |
| new_nodes_needed | список строк | типы новых нод с коротким описанием: `shot_plan — нарезка предложений на планы с start/change/end` |
| notes | список строк | что в стиле трудно воспроизвести и чем компенсировать |

## Правила

- Не выдумывай метрик: все числа — из паспорта; если значения нет — пиши
  диапазон словами («короткие планы») и отметь в `notes`.
- Тема роликов-референсов в шаблоны **не попадает** — только стиль.
- Шаблоны — по-русски, с английскими терминами там, где это промпт для
  генераторов картинок/видео (framing, camera move).

Ответ — один JSON-объект с ключами анкеты.
