============================================================
1. ГЛАВНАЯ ТЕХНИЧЕСКАЯ СТРУКТУРА ЛИСТА «ПЛАН»
============================================================

Заполняется только первый кадр каждой сцены.

В каждом столбце:
- id scene = scene_01, scene_02, scene_03 и далее;
- id shot = всегда shot_01;
- номер кадра = id scene + id shot, например scene_01_shot_01;
- создаётся и заполняется только shot_01;
- shot_02 и shot_03 не создаются, не описываются и не заполняются.

Строки первого кадра:
- строки 2–15 относятся к первому кадру текущей сцены;
- агент заполняет строки 2–15 строго по названиям строк в таблице;
- если в конкретной версии таблицы первый кадр заканчивается на строке 14, строку 15 не трогать;
- если строка 15 входит в блок первого кадра, заполнять её по её названию.

Строки второго и третьего кадра:
- строки 16–29 относятся ко второму кадру и НЕ заполняются;
- строки 31–44 относятся к третьему кадру и НЕ заполняются;
- нельзя дублировать туда данные первого кадра;
- нельзя создавать shot_02;
- нельзя создавать shot_03.

Если в таблице уже есть блоки для кадров 2 и 3, они остаются пустыми.

============================================================
2. КАК ЗАПОЛНЯТЬ СТРОКИ 2–15
============================================================

Агент не придумывает новую структуру строк.
Агент смотрит на название каждой строки в листе «план» и заполняет её только тем типом данных, который эта строка требует.

Обязательная техническая логика:

1. Строка id scene:
   Записать id сцены:
   scene_01, scene_02, scene_03 и далее по порядку столбцов.

2. Строка id shot:
   Всегда записать:
   shot_01.

3. Строка полного номера кадра / id кадра:
   Записать полный id:
   scene_01_shot_01,
   scene_02_shot_01,
   scene_03_shot_01 и далее.

4. Строки, относящиеся к персонажам:
   Заполнять только если персонаж реально присутствует в главном действии кадра.
   Если ГГ или другой персонаж отсутствует, не вписывать его id.
   Не придумывать id.
   Использовать только существующие id из листа «персонажи».

5. Строки, относящиеся к предметам:
   Заполнять только если предмет действительно важен для смысла кадра.
   Не добавлять случайные предметы.
   Не придумывать id.
   Использовать только существующие id из листа «предметы».

6. Строки, относящиеся к месту / фону / среде:
   Писать конкретное место, а не абстрактный фон.
   Плохо: «комната», «город», «улица», «пространство».
   Хорошо: «узкая съёмная комната с мокрым окном», «мостовая у газетной тумбы», «больничный коридор с погасшей лампой».

7. Строки, относящиеся к действию:
   Писать только конкретное физически наблюдаемое действие или состояние.
   Не писать абстракцию, смысл, тему или пересказ.

8. Строки, относящиеся к композиции / плану / ракурсу / свету / цвету:
   Заполнять конкретно, если такая строка есть в блоке 2–15.
   Не превращать это в промпт.
   Не писать параметры генерации.
   Не писать video prompt или image prompt.

9. Строки, которые по названию относятся к prompt, video prompt, image prompt, negative prompt, camera motion, render settings, generation settings:
   НЕ заполнять.
   Оставить пустыми.
   Агент не выполняет функции генератора промптов.

============================================================
3. ХРОНОМЕТРАЖ И ЗАПРЕТ СТРОКИ 50
============================================================

1 столбец = 4 секунды экранного времени.

Хронометраж используется агентом для понимания длительности сцены:
- scene_01 = 00:00–00:04;
- scene_02 = 00:04–00:08;
- scene_03 = 00:08–00:12;
- scene_04 = 00:12–00:16;
- далее по формуле: начало = (номер сцены - 1) × 4 секунды, конец = начало + 4 секунды.

ГДЕ ПИСАТЬ ВРЕМЯ:
- время кадра записывать только в строку, которая явно называется «время», «хронометраж», «таймкод», «time», «timing» или аналогично;
- если такая строка находится внутри разрешённого блока первого кадра 2–15, её можно заполнить;
- если такой строки в блоке 2–15 нет, время не записывать вообще.

ЖЁСТКИЙ ЗАПРЕТ:
- строку 50 не использовать для времени;
- строку 50 не использовать для хронометража;
- строку 50 не использовать как служебное место для таймкода;
- если агент не видит явной строки для времени в блоке 2–15, он не должен искать другое место.

Строка 50 не заполняется хронометражом ни при каких обстоятельствах.

============================================================
4. ИСТОЧНИКИ СМЫСЛА
============================================================

Глобальный источник — лист «сценарий».
Он нужен для понимания:
- всей истории;
- хронологии;
- причинно-следственных связей;
- возраста / состояния ГГ;
- предшествующих и последующих событий;
- периода повествования;
- переходов между прошлым, настоящим, будущим, воспоминанием, последствием и общественным контекстом.

Локальный источник — строка 49 текущего столбца.
Она задаёт конкретную фразу или мысль, которую нужно визуализировать в данной сцене.

Правильная иерархия:
лист «сценарий» → общий контекст → строка 49 текущего столбца → один конкретный 4-секундный кадр.

Запрещено:
- трактовать строку 49 отдельно от сценария;
- механически пересказывать строку 49;
- брать из соседних строк новые события, если они не относятся к текущему кадру;
- игнорировать общий сценарный контекст.

Разрешено:
- использовать соседние строки и лист «сценарий» для понимания хронологии, возраста, причин и последствий;
- использовать строку 49 как локальный фокус текущей сцены.

============================================================
5. ГЛАВНОЕ ДЕЙСТВИЕ В КАДРЕ
============================================================

Главное действие кадра должно быть конкретным, физически наблюдаемым и пригодным для изображения.

Строка главного действия не должна быть промптом.
Она должна быть сухим визуальным описанием того, что видно в кадре.

Формула:
[кто / что] + [конкретный глагол] + [конкретный объект или состояние] + [конкретное место] + [передний план] + [средний план] + [задний план] + [свет] + [цветовая логика].

Запрещено писать:
- «центр внимания — конкретное действие»;
- «выбранный предмет»;
- «раскрывает тему»;
- «связывает с делом»;
- «фиксирует крах»;
- «становится подозрительным материалом»;
- «появляется как версия»;
- «визуализирует сомнение»;
- «показывает внутреннее состояние»;
- «символизирует»;
- «олицетворяет»;
- «намекает»;
- «создаёт атмосферу» без физического источника.

Плохо:
«Ницше-кот у окна прижимает календарный лист; в среднем плане центр внимания — конкретное действие лап и выбранный предмет».

Хорошо:
«Ницше-кот прижимает загнувшийся календарный лист к холодному стеклу окна; на переднем плане расплывшееся чернильное пятно на письме, в среднем плане когти держат край листа с датой “1889”, за стеклом мокрые крыши Турина; бледный утренний свет, серо-охристая палитра».

============================================================
6. ТЕКСТ В КАДРЕ
============================================================

По умолчанию текст в кадре не добавлять.

Если текст нужен как часть предмета, а не как объяснение зрителю, допустимо:
- одно слово;
- короткая дата;
- номер;
- короткая пометка из 1–2 слов;
- фрагмент документа как визуальная улика.

Запрещено:
- длинные предложения на изображении;
- закадровый текст на изображении;
- речь героев;
- объяснительные подписи;
- философские фразы;
- канцелярские формулировки;
- предложения вроде «поздний стиль становится подозрительным материалом».

============================================================
7. СВЯЗНОСТЬ СОСЕДНИХ СЦЕН
============================================================

Сцены должны быть монтажной цепочкой, а не набором случайных похожих картинок.

Если новая сцена продолжает предыдущую мысль, она обязана менять:
- масштаб;
- фокус;
- функцию;
- объект внимания;
- физический результат;
- реакцию;
- препятствие;
- точку зрения.

Максимум 2 соседних кадра могут относиться к одной мысли.

Правильная пара:
1. ГГ перебирает папки на столе архива.
2. Крупный план карточки, которую он вытянул из папки.

Неправильная цепочка:
1. ГГ перебирает документы.
2. ГГ собирает бумаги.
3. ГГ раскладывает карточки.

Это повтор, а не развитие.

Если второй кадр не меняет масштаб, фокус или функцию — он запрещён.

============================================================
8. АНТИПОВТОР
============================================================

Перед записью новой сцены сравнить её с предыдущими пятью сценами.

Сцена считается повтором, если совпадает 3 или более признака:
- тот же персонаж в той же роли;
- та же локация;
- тот же тип места;
- тот же масштаб;
- тот же ракурс;
- тот же свет;
- тот же основной предмет;
- тот же глагол действия;
- та же структура предложения;
- та же монтажная функция.

Запрещено повторять подряд:
- персонаж у окна;
- персонаж у стола;
- персонаж в комнате;
- персонаж у доски;
- карточки на доске;
- документы на столе;
- письма и чернила;
- архивист прикалывает карточку;
- календарный лист с датой;
- общий вид мокрой улицы без нового действия.

Если ничего принципиально не меняется по сравнению с предыдущим кадром — сцена запрещена.

============================================================
10. СМЕРТЬ, БОЛЕЗНЬ, КРАХ
============================================================

Если речь о смерти:
показать физическое проявление смерти или её последствия:
- накрытое тело;
- пустая койка;
- закрытая дверь палаты;
- чёрная лента на фотографии;
- свеча у портрета;
- мокрая земля у свежей могилы;
- брошенная вещь умершего;
- стул, на котором больше никто не сидит.

Если речь о болезни:
показать физическое проявление болезни:
- дрожащая лапа;
- лекарство;
- таз с водой;
- мокрое полотенце;
- медицинская карточка;
- неровный почерк;
- врачебная сумка;
- пустой коридор клиники.

Если речь о крахе:
показать видимый слом:
- сорванные объявления;
- закрытые ставни;
- разбитая чернильница;
- письмо в воде или чернилах;
- упавший стул;
- толпа у двери;
- вещь, выпавшая из рук;
- пустая комната после ухода.

11. СИЛЬНЫЕ И СЛАБЫЕ ГЛАГОЛЫ
============================================================

Использовать сильные физические глаголы:
вытаскивает, роняет, сжимает, разрывает, прижимает, разворачивает, поднимает, прячет, снимает, кладёт, отодвигает, отрывает, прикалывает, вытряхивает, переворачивает, закрывает, распахивает, опускает, тянет, обхватывает, отступает, приседает, протягивает, заслоняет, вытирает, перечёркивает, заворачивает, запирает, развязывает, поднимает с пола, проводит пальцем, смахивает пыль, сдирает объявление, вытаскивает ключ, вешает ленту, гасит лампу, закрывает книгу, ломает печать, прячет конверт.

стоит, сидит, смотрит, думает, находится, появляется, присутствует, отражает, символизирует, демонстрирует, раскрывает смысл, показывает тему.

============================================================
12. ПРОВЕРКА ПЕРЕД ЗАПИСЬЮ
============================================================

Перед записью каждой сцены проверить:

1. Заполняется только блок первого кадра?
2. Строки 16–29 пустые?
3. Строки 31–44 пустые?
4. Хронометраж не записан в строку 50?
5. Если нет явной строки времени в блоке 2–15, время вообще не записано?
6. id scene записан по порядку?
7. id shot = shot_01?
8. Полный id кадра записан как scene_XX_shot_01?
9. Есть ли конкретное физическое действие?
10. Можно ли это нарисовать без пояснения?
11. Нет ли пересказа закадрового текста?
12. Нет ли длинного текста в кадре?
13. Нет ли мета-фраз?
14. Нет ли фразы «центр внимания — конкретное действие»?
15. Не повторяет ли сцена предыдущие сцены?
16. Если это продолжение, есть ли смена масштаба или фокуса?
17. Не является ли это тем же кадром с заменой предмета?
18. Есть ли передний, средний и задний план?
19. Есть ли физический источник света?
20. Есть ли цветовая логика?
21. Не злоупотребляет ли сцена комнатой, столом, окном, архивом или доской?
22. Строка звучит как конкретный кадр, а не как инструкция или промпт?

Если хотя бы один пункт нарушен — переписать до записи.

============================================================
13. ИТОГОВЫЙ ПРИНЦИП
============================================================

Техническая структура строк не меняется.

Агент обязан:
- работать внутри исходной логики листа «план»;
- заполнять только строки первого кадра;
- не трогать блоки второго и третьего кадра;
- не писать время в строку 50;
- использовать строку 49 как локальный фокус;
- использовать лист «сценарий» как общий контекст;
- делать сцены связными;
- избегать повторов;
- писать конкретные физические действия;
- не превращать ячейки в промпты.

Главный вопрос перед записью:
«Я заполняю правильную строку правильным типом данных, или снова пишу лишнее не туда?»
