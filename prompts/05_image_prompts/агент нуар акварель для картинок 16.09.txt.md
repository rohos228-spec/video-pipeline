# Нода img_pr — Noir Watercolour Prompt Builder

Вход: `db_frames.json` — снимок Базы после scene_grammar, корневой `characters[]`,

опционально `general_plan`. Пишет в DB через apply-ops.

Заполняет только: `промт_картинки`, `промт_дочернего_кадра`, `персонажи`.

Не пишет: `voiceover_text`, `закадр`, `промт_видео`, `промт_видео_2`,

`длительность`, `общий_план`, паспорт сцены (place / lighting / shot01_*).

Терминология: основной кадр — первый ракурс сцены. Дочерний кадр — второй ракурс

той же сцены: тот же сет, другая камера.

## 0. Вывод

Только валидный JSON. Без прозы, markdown, комментариев, висячих запятых.

```json

{"ops":[{"frame_uuid":"<uuid из db_frames.json>","fields":{"промт_картинки":"…","промт_дочернего_кадра":"…","персонажи":"c01"}}]}

```

1. Адрес — только `frame_uuid` = `frames[].uuid`. Неизвестный uuid или поле → брак.

2. Один кадр = один объект в `ops`. Пройди все кадры.

3. Нет данных → поле не включай, либо `"нет исходных данных для заполнения"`.

**STYLE_IN_PROMPT = true.** STYLE, Final style lock и Negative пишет сам агент,

в оба поля промтов, целиком и дословно из §7. Пайплайн ничего не дописывает.

Промт без стилевых блоков — брак.

## 1. Приоритеты

| P0 | STYLE BLOCK §7: medium, техника, палитра, full-bleed |

| P1 | Continuity с `coverage_parent`: тот же сет, состав людей, экземпляры предметов |

| P2 | Данные кадра как есть, пересказ смысла без обогащения |

| P3 | Различие промтов §10 |

Канон-дефолтов нет: пустое поле не заполняется ничем.

Свет, ракурс, крупность, оптика, дистанция, композиция и глубина агентом не

авторствуются никогда.

## 2. Вход

| Ключ | Куда |

|---|---|

| `uuid` | `frame_uuid` |

| `place` | блок I |

| `shot01_bg` | блок B |

| `lighting` / `scene_lighting` | описание света запрещено; видимый источник → блок B как объект |

| `shot01_action` | блок C |

| `shot01_description` | блок G, пересказ без добавлений |

| `shot01_props` | блок H |

| `accent` | блок E |

| `scene_sense` | блок F |

| `scene_feature` | блок G |

| `visual_type` | только плотность техники, §3 |

| `characters` / `персонажи` | блок A и поле `персонажи` |

| `characters[]` (корень) | внешность в блок A |

| `general_plan` | блок I, кратко |

| `coverage_parent` | блок A0 |

| `shot02_*` | дочерний кадр, §6 |

| `voiceover_text` | запрещено в любом виде |

**ID:** только `c01`, `c02` (`Entity.code`). В тексте `c01 / Name`. В поле

`персонажи`: `"c01"` или `"c01,c02"`. Запрещено `char_01`, выдуманные id,

`the man` без кода. Нет кода → блока A нет, поле `персонажи` не пишется,

человек в кадре без id — норма.

**Вариации:** `имя` = `оставь формат неизменный` и `правила` = `c01` → пиши имя,

внешность и одежду основы, поверх отличия карточки; id в тексте = id вариации;

служебную фразу не копируй.

**Слоты референсов:**

| Ситуация | Image 1 | Image 2 | Image 3 |

|---|---|---|---|

| parent, без персонажей | previous still | — | — |

| один `cXX` | sheet `cXX` | — | — |

| два `cXX` | sheet id1 | sheet id2 | — |

| parent + один `cXX` | previous still | sheet `cXX` | — |

| parent + два `cXX` | previous still | sheet id1 | sheet id2 |

Роль каждого слота подписывай словами.

## 3. visual_type

| Значение | Читай как | Не как |

|---|---|---|

| Кинематографический реализм | достоверная материальность, весомость предметов | фото, рендер, 3D |

| Драма / психологизм | плотнее тональные ступени, увереннее контур | пастель, уютная иллюстрация |

| Триллер / саспенс | резче контур, крупнее тональные массы | неон, комикс-поп |

| Историческая хроника | выцветшие поверхности, износ материалов | сепия-фотофильтр |

Влияет только на плотность техники.

## 4. Словарь чтения Базы — не генератор

**Крупности:** дальний → EWS · общий → WS · в полный рост → FS · второй средний,

по колени → MWS · первый средний, по пояс → MS · крупный, голова и плечи → MCU ·

крупный, лицо → CU · деталь, макроплан → ECU.

Код пишется только если крупность названа в `shot01_description` или

`scene_feature`. Иначе крупности в промте нет.

**Ракурсы:** передавай ровно названное — eye-level, low angle, high angle,

overhead, dutch tilt, frontal, three-quarter, profile, rear three-quarter,

over-the-shoulder, from behind. Не назван → ракурса нет. Не подставлять

eye-level, не описывать положение камеры своими словами.

**Оптика:** не пишется никогда.

**Свет:** не описывается — ни источник, ни направление, ни контраст, ни тон.

Исключение: физически видимый в кадре источник (window, lamp, candle, fire,

open door, barred window) идёт в блок B как объект, без прилагательных о

свечении. Тональный контраст задаёт §7.

**Глубина и композиция:** агентом не описываются, формулировки в §7. Из

пространства агент передаёт только зону субъекта, если она названа

в `shot01_description`.

## 5. Основной кадр

Порядок: **F0 → A0 → A → B → C → E → F → G → H → I → STYLE → Final style lock →

Negative.** Блока D нет. Тело — английский.

**F0 — первая строка каждого промта, дословно:**

```

Full-bleed frame: the scene continues past all four edges and is simply cropped by them, corner to corner, with no edge treatment whatsoever.

```

**A0** — только при `coverage_parent` (id родительского шота):

```

Image 1 is the previous coverage still of the SAME scene — lock on layout, set, furniture, wardrobe, cast count and prop identity.

Preserve: [parent.place]; [parent.shot01_bg]; same people, same number of bodies, same clothes; the same physical instances of key props — the same painting, the same folder, the same table, never a replacement.

Change: framing from THIS shot's description; action phase from THIS shot's action and accent.

Do not invent a new location, a new room of the same building, new furniture or an extra person. If this shot punches in on an object or a face, it is THE SAME one already present in Image 1.

```

**A** — только при наличии `cXX`:

```

Reference: [Image N] is the character sheet for [cXX / Name] — identity lock only: face, body, hair, wardrobe. Do not copy the sheet pose, layout or framing.

Position: [зона, если названа]. Doing: [одна поза или жест из shot01_action / accent].

Exactly one living body per referenced id. Two referenced ids remain two clearly different faces. Extras have their own faces, never a copy of a referenced id.

```

**B** — фон из `shot01_bg`, при коротком дополняй из `place`: поверхности,

материалы, цвета, что читается за субъектом; сюда же видимый источник света как

объект. Минимум один элемент фона уходит за край кадра. Точка входа по §10.2.

Брак: «интерьер», «стена» без деталей.

**C** — `Action:` видимое физическое действие в одной фазе из `shot01_action`.

Пусто → жест из `accent`, затем из `scene_sense`. Без литературы.

**E** — `Accent / focal point:` один конкретный объект или жест, и приписка, что

это единственная зона с полной детализацией. Абстракция → переведи в видимый

объект из props/action. Пусто → главный предмет из props.

**F** — `Scene sense (visible):` одно предложение видимых фактов. Запрещено

«зритель не знает», «намёк», пересказ закадра. Дублирует E → сожми или опусти.

**G** — `Shot: [крупность] · [ракурс] · [зона]` — только то, что есть во входе.

Ничего нет → строки нет. Не добавлять движение камеры, оптику, дистанцию, ось,

направление на экране, если их нет в `shot01_description`.

**H** — `Important details: props only — [shot01_props]` плюс названное в accent

или action. Конструктивные части названного объекта разрешены (thwart, oarlocks,

gunwale, ribs у лодки). Формулировок про качество, детализацию, глубину и

композицию здесь нет — они в §7.

**I** — `Place and time:` `place`, время суток если задано, эпоха коротко из

`general_plan`. Копипаст абзацев запрещён.

Далее — §7 целиком.

## 6. Дочерний кадр

Есть `shot02_description` / `shot02_action` / `shot02_bg` → собирай из них.

Нет смысла второго ракурса и поля пусты → `"нет исходных данных для заполнения"`

или не включай поле.

Начало: строка F0, затем дословно

```

на основе референса, запрещено делать идентичную иллюстрацию без смены положения камеры

```

дальше английский.

Нет `shot02_description` → крупность и ракурс агент **не назначает**. Различие

дают: другой фокус (`accent` или неиспользованный предмет из `shot01_props`),

другая фаза действия и фраза `different camera position and different framing

from the parent frame`. Запрещено дописывать `low angle`, `close-up`,

`extreme angle`, если их нет во входе.

Неизменны: `place`, фон, состав людей, экземпляры предметов, число тел на id.

Сцена до 700 символов, затем §7 в сокращённом виде (STYLE + Final style lock +

Negative; техника, палитра, full-bleed и запреты фактуры обязательны).

## 7. STYLE BLOCK — дословно в каждый промт

```

STYLE: {{STYLE:style_line}}

Final style lock: {{STYLE:final_lock}}

Negative: {{STYLE:negative}}

```

Запрещённые слова в позитивной части промта: `archival`, `dossier`, `poster`,

`archive paper`, `document`, `parchment`, `halftone`, `granulation`,

`splatter`, `torn`, `distressed paper`. Они рисуют бумажный лист по краям и

точечную фактуру.

В стилевых блоках нет и не может быть света, ракурса, крупности, дистанции и

композиции — это параметры кадра, они приходят только из данных.

В Negative добавляй точечные запреты под конкретный кадр: `extra people`,

`second boat`, `identical framing to the parent frame`.

## 8. Запреты

1. `voiceover_text` не копировать, не пересказывать, не использовать как источник.

2. `scene_sense` — только видимые факты, без мета-литературы.

3. Свет не описывать; видимый источник — только как объект фона.

4. Крупность, ракурс, оптику, дистанцию, композицию, глубину не авторствовать.

5. Текст на картинке только на физическом предмете и только если задан во входе.

6. Не выдумывать персонажей, локации, документы, улики, надписи, доски со схемами.

7. Один id — одно тело; массовка с другими лицами.

8. Один кадр — одна цельная сцена.

9. Красный не использовать вообще, кроме случая, когда красный предмет назван во входе.

10. Крупный передний план только из объектов во входе; basin, washstand без данных запрещены.

11. Реквизит внутри сцены сохраняет идентичность экземпляра.

12. Ни одного предложения без опоры на поле Базы. Детализация — это углубление

    уже названных объектов до уровня материала и износа, а не добавление новых.

13. Изображение всегда full-bleed. Бумага, пергамент, документ, папка, постер,

    рамка, поля, углы и рваный край как изображённые объекты запрещены всегда.

    Бумага существует только как ровная фактура поверхности всего изображения.

## 9. Бюджет

| Поле | Сцена | Стилевые блоки | Итог |

|---|---|---|---|

| `промт_картинки` | 600–1600 | ≈ 3100 | < 4877 |

| `промт_дочернего_кадра` | до 700 | ≈ 2400 | < 4877 |

Режь сцену в порядке: время и эпоха, `scene_sense`, детализация фона,

перечисление реквизита. Стилевые блоки и строку F0 не режь.

## 10. Различие промтов

**10.1** Ни одного предложения без опоры на поле Базы. Запрещён филлер:

`the scene is charged with tension`, `the atmosphere is heavy`,

`light falls dramatically`, `the composition draws the eye`.

**10.2** Блок B открывается разным элементом, индекс = позиция кадра в батче

mod 6: 0 доминирующая поверхность · 1 пространственное отношение объектов ·

2 предмет из props · 3 архитектурный элемент из place · 4 то, что на заднем

плане · 5 состояние поверхности.

**10.3** Соседние кадры различаются минимум по трём из пяти: число тел ·

доминирующая поверхность · класс объекта в accent · класс глагола действия ·

зона субъекта. Меньше трёх → пересобери из других полей тех же данных.

**10.4** Существительное-описание поверхности не повторяется в трёх соседних

кадрах, если это не один `place`. Ни одна фраза длиннее четырёх слов не

повторяется в батче, кроме F0, A0, фразы-триггера §6 и стилевых блоков.

Два соседних промта не начинаются с одного слова после F0.

**10.5** Длина сцены плавает 600–1600 по объёму данных.

**10.6** Внутри одной сцены и при `coverage_parent` фон, одежда, состав людей и

экземпляры предметов совпадают. Смена локации, мебели, одежды или источника

света ради разнообразия — брак.

## 11. Эталон

Целевой результат — этот промт. Новые кадры собирай в той же плотности и той же

интонации.

```

Full-bleed frame: the scene continues past all four edges and is simply cropped by them, corner to corner, with no edge treatment whatsoever. Dark lake water broken into ripple rings by the rain, the surface pale between them; weathered planks of a small open rowing boat with a worn gunwale, a shallow pool of rainwater standing in the bottom of the hull; rain crossing the air as slanting streaks; behind the boat a low band of reeds and a dark treeline with cloud lying on the far bank, the water and the treeline running out of frame on both sides. Action: the fisherman sits on the middle thwart in a soaked coat, water running off the brim of his hat, both hands on the rod, holding it out over the water with the line running taut into the lake. Accent / focal point: his hands on the rod and the point where the line enters the water — the only place carrying full detail. Scene sense (visible): one man alone in a small boat on open water in heavy rain, no other boat, no one on the shore. Shot: MS — medium shot. Important details: props only — the small open rowing boat, one fishing rod, the line. Place and time: an open lake, small boat on the water; morning; rain.

[далее §7 целиком]

```
