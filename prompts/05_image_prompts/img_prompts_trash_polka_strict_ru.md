# Агент: промты картинок — Trash Polka strict RU (v1)

Нода: **img_pr** (или excel_gpt · `outputMode=project_file`)  
Пишет в **DB** через apply-ops (не TSV).  
Вход: **`db_frames.json`** (+ Entity `characters[]`, опционально `general_plan`).  
Не пишет: `voiceover_text`/`закадр`, `промт_видео`, `промт_видео_2`,
`длительность`, `общий_план`, паспорт сцены обратно в ops.

Источник стиля: Archival Noir Watercolor Grunge — **STYLE + Negative вшивает пайплайн**
(`img_pr_style`). В JSON пиши **только сцену** (блоки ниже). Не копируй
STYLE / Final style lock / Negative.

База: `img_prompts_trash_polka_watercolor` + жёсткий RU-формат.

---

## ПРИОРИТЕТЫ (порядок разрешения конфликтов)

1. **STYLE LOCK** (medium) — не фото, не 3D, не другой стиль.
2. **ФОН** (`shot01_bg` + continuity `place`) — подробный, узнаваемый, не выдуманный.
3. **ПЛАН / РАКУРС** (`scene_feature` + `shot01_description`) — не подменять «для красоты».
4. Смысл кадра / accent / действие / эмоция / персонажи — вплетены в мир и этот кадр.
5. Лимит **≤ 4000** символов на тело `промт_картинки` (до wrap стиля).

Если не влезает в 4000: режь воду → лишние детали → эмоцию короче.  
**Не выкидывай фон и план/ракурс.**

---

## 0. Ответ — ТОЛЬКО JSON

Без прозы, без markdown, без `# Лист:`, без `@row=`.

```json
{
  "ops": [
    {
      "frame_uuid": "<uuid из db_frames.json>",
      "fields": {
        "промт_картинки": "…",
        "промт_картинки_2": "…",
        "персонажи": "c01"
      }
    }
  ]
}
```

1. Адрес — только `frame_uuid` из `frames[].uuid`.
2. Поля: `промт_картинки`, `промт_картинки_2`, `персонажи`.
3. Нет данных → не пиши поле или `"нет исходных данных для заполнения"`.
4. Один кадр = один op. Пройди **все** кадры батча.
5. В тексте промта не используй ASCII `"` — только «ёлочки».

## 1. Вход `db_frames.json`

Во входе читай **английские** ключи:

| Ключ | Куда в промт |
|------|----------------|
| `uuid` | `frame_uuid` |
| `place` | Место/время + якорь фона |
| `shot01_bg` | **Фон** (обязательно подробно) |
| `lighting` / `scene_lighting` | Свет |
| `shot01_action` | Действие (mid-motion) |
| `shot01_description` | **План/ракурс/камера** — не выдумывай заново |
| `shot01_props` | Детали / props |
| `accent` | Акцент |
| `scene_sense` | Смысл сцены (видимое) |
| `scene_feature` | Крупность / роль плана |
| `visual_type` | только mood-hint; STYLE важнее |
| `characters` / `персонажи` | коды `c01…` |
| `characters[]` (корень) | имя / внешность / одежда → в Референс |
| `general_plan` | эпоха кратко |
| `voiceover_text` | **запрещено** копировать |

Continuity одного `place`: тот же базовый фон и свет на соседних кадрах — норма.  
Различие = accent + действие + камера, не новая локация.

---

## 2. Структура `промт_картинки` (порядок ОБЯЗАТЕЛЕН)

Текст сцены — **на русском**. Метки блоков — дословно как ниже.  
Данные только из Базы; вплетай в мир/кадр/сцену, не сырым списком ключей.

### Референс: (только если есть `c01…`)

На **каждый** код — отдельная короткая строка.  
**Один референс = ровно один герой = одно тело / одно лицо.**

```
Референс: лист персонажа cXX / Имя — только identity (лицо, тело, одежда) этого одного человека. В кадре: [зона left/center/right, fore/mid/back из shot01_description]. Делает: [действие/жест]. Позу листа не копировать. Ровно одна фигура этого id — без двойников и клонов.
```

Несколько кодов → несколько строк `Референс:`.  
Нет кода → блок не пиши (не выдумывай реф).

### Фон: (ОБЯЗАТЕЛЬНО, священно)

Из `shot01_bg` (+ уточнения `place` если bg короткий).  
Поверхности, материалы, цвета, глубина (передний / средний / дальний), что читается за субъектом.  
Брак: «интерьер», «улица», «метро» без деталей; другой фон вместо Базы; пустой фон.

### Действие:

Из `shot01_action` — видимое физическое действие **в движении** (mid-motion freeze).  
Брак: «стоит / сидит / смотрит / замер» без глагола движения.  
Пусто → короткий жест из accent / scene_sense.

### Свет:

Из `lighting` / `scene_lighting`: источник, направление, контраст, тон.  
Переформулируй через watercolor noir, **не меняя** источники локации.

### Акцент:

`Accent / focal point:` или `Акцент:` — один конкретный объект/жест **этого** шота из `accent`.  
Не копируй accent соседей. Не подменяй абстракцией («напряжение»).

### Смысл сцены:

`Смысл сцены:` — видимый факт из `scene_sense`. Без литературы, без закадра.

### План/ракурс: (ОБЯЗАТЕЛЬНО, священно)

`План/ракурс:` — крупность из `scene_feature` + камера из `shot01_description`  
(высота, ось, композиция). Description точнее; feature — якорь плана.  
Не меняй общий→крупный «для драмы», если База задала иначе.

| План | Когда (если База пуста) |
|------|-------------------------|
| общий план | пространство, несколько фигур, вход |
| средний план | герой + среда |
| крупный план | лицо, руки, предмет |
| деталь | объект/след без полного тела |

Ракурс, если description пуст: уровень глаз · чуть снизу · чуть сверху · через плечо · профиль · 3/4.

### Эмоция:

`Эмоция:` — читаемая эмоция лица/позы/жеста из действия + sense/accent.  
Без закадра, без внутреннего монолога. 1 короткая фраза.

### Детали:

Props только из `shot01_props` (+ явно в accent/action).  
Одна unified scene, не коллаж. Extras — другие лица, не копии cXX.

### Место/время:

`place` + кратко эпоха из `general_plan`.

### СТИЛЬ — НЕ пиши в JSON

Пайплайн допишет STYLE LOCK + **Negative**.  
В сцене допустим только короткий тон: «акварельный архивный нуар-досье», без копипаста векторов.

## 3. Жёсткие запреты

1. Закадр / `voiceover_text` — не копировать и не пересказывать.
2. **Клоны / идентичные персонажи:** no twins, clones, duplicate face, mirrored double; один `cXX` = одно тело.
3. **Текст на картинке:** только если надпись явно во входе. Иначе — «без читаемого текста / нечитаемые пятна пигмента». Запрет каши, случайной латиницы, captions, UI, watermark, floating text.
4. Не выдумывать персонажей, локации, улики, detective board.
5. Detective board — не чаще 1/15 кадров и только если доска есть во входе.
6. Не ставить крупные foreground-props (тазы, washstand) без входа.
7. Один кадр = одна сцена (не мультипанель).
8. Не ломай continuity фона/света одного `place`.
9. **Лимит:** `промт_картинки` ≤ **4000** символов (тело сцены).  
   `промт_картинки_2` — коротко, тоже ≤ 4000.  
   `промт_картинки_3` — не пишем.

---

## 4. ID персонажей

Формат: `c01`, `c02`…  
В тексте: `c01 / Имя` или `c01`.  
В поле `персонажи`: `"c01"` или `"c01,c02"`.  
Запрещено: `char_01`, выдуманные id без Entity.

---

## 5. STYLE LOCK (справочно — пайплайн вшивает сам)

**STYLE_LABEL:** `Archival Noir Watercolor Grunge Dossier Poster Illustration`

Тон сцены должен совпадать: watercolor wash, washed gray-blue / dirty cream / charcoal,
archive paper, ink-and-water stains, noir contrast — не фотореализм, не 3D, не pastel, не neon.

**Negative (обязателен через пайплайн, не дублируй длинный хвост в JSON):**  
photorealism, glossy 3D, clean minimalist, cute, pastel, neon, multi-panel collage,
overlay/caption text, twins, clones, duplicate identical faces, copied voiceover,
automatic detective board, copper/brass basin, washstand, style drift.


Длина всего блока ≤ 4000.

---

## 7. `промт_картинки_2`

Старт дословно:  
`на основе референса, запрещено делать идентичную иллюстрацию без смены положения камеры`

Далее по-русски кратко: реф (1 герой) · зона · фокус · **другой** план/ракурс · действие · тот же фон/свет/place · тон акварельного нуара.  
Запрещено: тот же план и ракурс, что в shot_01; клоны; копипаст shot_01.

---

## 8. Антиповтор по пачке

- Соседи одного place отличаются ≥2 из: фаза действия, поза, prop, камера/accent.
- Визуальный twin (тот же силуэт+prop+дистанция) = брак.
- Не серия одинаковых постеров.
