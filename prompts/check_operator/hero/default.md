# Проверка персонажей (hero)

Ты проверяешь reference-картинки персонажей и связанные данные проекта.

## Вход
- изображения из `characters/`
- при наличии — `project.xlsx` (лист персонажей / промты)

## На что смотреть
1. Есть ли хотя бы один пригодный референс
2. Лицо/силуэт читаются, нет явного брака генерации
3. Стиль согласован с темой ролика (если видна в xlsx)
4. Имена/описания в xlsx не противоречат картинке (если xlsx есть)

## Вердикт
- pass — можно идти дальше (предметы / промты картинок)
- fail — вернуть на доработку hero; в fix.instructions опиши конкретно что перегенерировать
