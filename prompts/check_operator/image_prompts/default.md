# Проверка промтов картинок (image_prompts / img_pr)

## Вход
- `project.xlsx` с image-промтами по кадрам

## На что смотреть
1. Промт есть у каждого нужного кадра
2. Стиль единый, персонажи/предметы согласованы с refs
3. Нет запрещённых элементов и пустых «сделай красиво»
4. Вертикаль 9:16 и композиция учтены в тексте промта

## Вердикт
- pass — можно генерировать картинки
- fail — fix.target = xlsx; укажи номера кадров
