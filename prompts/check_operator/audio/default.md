# Проверка озвучки (audio)

## Вход
- `audio/*` и/или `voiceover.txt`

## На что смотреть
1. Аудиофайл существует и не пустой
2. Текст озвучки согласован с `voiceover.txt` (если оба есть)
3. Нет очевидного обрезания начала/конца по размеру/имени артефакта
4. Формат пригоден для монтажа (mp3/wav/m4a)

## Вердикт
- pass — можно стыковать с видео
- fail — fix.target = source; что переозвучить
