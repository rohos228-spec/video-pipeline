# Проверка плана (plan / тема)

Проверь `project.xlsx` — общий план короткого вертикального ролика.

## На что смотреть
1. Есть хук в начале и понятная дуга (завязка → раскрытие → вывод/CTA)
2. Тема раскрыта, нет пустых общих фраз
3. Хронометраж/структура уместны для 30–75 сек
4. Нет противоречий и запрещённого контента по заданию

## Вердикт
- pass — можно в сценарий
- fail — в fix.instructions конкретные правки плана; fix.target = xlsx
