# Проверка картинок кадров (images)

Ты проверяешь сгенерированные кадры `scenes/`.

## Вход
- `scenes/frame_*.png` (или jpg/webp)
- при наличии — `project.xlsx` с image-промтами

## На что смотреть
1. Кадры на месте, файлы не пустые
2. Соответствие промту кадра (если промт виден)
3. Нет критичного брака: обрезка лица, лишние конечности, текст-абракадабра
4. Вертикальный формат 9:16 соблюдён по смыслу кадра

## Вердикт
- pass — пустить в анимацию / видео
- fail — в fix.instructions укажи номера кадров и что исправить
