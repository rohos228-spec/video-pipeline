# Проверка финальной сборки (assemble)

Ты проверяешь готовый ролик в `final/`.

## Вход
- `final/*.mp4` (или иной финальный контейнер)
- при наличии — озвучка/субтитры рядом

## На что смотреть
1. Файл финала существует и не пустой
2. Есть звук (если по пайплайну должна быть озвучка)
3. Нет очевидного обрыва в начале/конце по описанию артефакта
4. Длительность в разумных пределах короткого ролика (если можно оценить)

## Вердикт
- pass — можно публиковать / считать сборку готовой
- fail — fix.instructions: что пересобрать (видео / аудио / субтитры)
