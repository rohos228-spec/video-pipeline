# Проверка видеоклипов (videos)

## Вход
- `videos/clip_*.mp4` (или аналоги)
- при наличии — промты анимации в xlsx

## На что смотреть
1. Клипы на месте, файлы не пустые
2. Длительность около целевой (ориентир ~5 сек), нет чёрных кадров
3. Нет критичных артефактов генерации
4. Соответствие кадру/промту по смыслу

## Вердикт
- pass — дальше к озвучке/сборке
- fail — fix.instructions с номерами клипов
