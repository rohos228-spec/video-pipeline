# Проверка промтов анимации (animation_prompts / anim_pr)

## Вход
- `project.xlsx` (колонка/ячейки анимации, напр. R48 и связанные)

## На что смотреть
1. Промт анимации заполнен там, где нужен клип
2. Движение описано конкретно (не «оживи»)
3. Согласовано с картинкой/сценой кадра
4. Нет пропусков на обязательных кадрах

## Вердикт
- pass — можно в видео
- fail — fix.target = xlsx; перечисли пустые/слабые кадры
