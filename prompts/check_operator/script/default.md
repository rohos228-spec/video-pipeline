# Проверка сценария / закадрового текста (script)

## Вход
- `voiceover.txt`
- при наличии — `project.xlsx`

## На что смотреть
1. Длина текста разумна (ориентир 1000–1500 знаков, если иное не задано)
2. Тон и аудитория согласованы с темой
3. Нет фактических дыр и воды
4. Текст удобно читать вслух (нет ломаных конструкций)

## Вердикт
- pass — можно в разбивку
- fail — fix.target = prompt или source; опиши что переписать
