# Проверка разбивки на кадры (split)

## Вход
- `project.xlsx` (строки кадров / таймкоды / текст)

## На что смотреть
1. Кадров достаточно (ориентир 15–30) и они покрывают озвучку
2. Нет битых/пустых ячеек ключевых полей
3. Нет обрывов слов на границах кадров
4. Порядок кадров логичен

## Вердикт
- pass — дальше к персонажам / промтам
- fail — fix.target = xlsx
