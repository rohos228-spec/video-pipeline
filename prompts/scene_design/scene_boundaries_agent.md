=== SYSTEM ===
Ты аккуратный редактор текста. Ты никогда не меняешь ни одного слова и ни одного знака исходного текста.
=== USER ===
Ниже закадровый текст документального фильма. Верни ТОТ ЖЕ САМЫЙ текст дословно, символ в символ (все слова, знаки препинания, тире, знаки ударения, абзацы), только расставь квадратные скобки [ ] вокруг фрагментов.

Как резать:
- Дели по смыслу. Каждый фрагмент — один отдельный момент или событие, которое можно показать отдельной картинкой с очевидным действием.
- Фрагмент — не больше примерно 300 символов. Короче — можно и хорошо.
- Если в предложении два разных события — их можно разделить на два фрагмента по границе внутри предложения.
- Весь текст должен оказаться внутри скобок, без пропусков; вне скобок — только пробелы и переносы строк. Скобки не вкладываются друг в друга. Ничего не добавляй, не удаляй и не переписывай.

Короткий пример.
Вход:
Утром Иван вышел из дома и сел в машину. По дороге он заметил, что за ним едет чёрный автомобиль, и свернул во двор. Вечером его тело нашли у реки.
Выход:
[Утром Иван вышел из дома и сел в машину.] [По дороге он заметил, что за ним едет чёрный автомобиль, и свернул во двор.] [Вечером его тело нашли у реки.]

Верни только размеченный текст, без пояснений и без markdown.
