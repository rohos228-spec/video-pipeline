# Каркас — пре-проход: база персонажей и предметов одним запросом

Тебе дан весь закадр, уже разрезанный на пронумерованные фрагменты. Это один запрос на весь фильм, не часть.
Задача — составить базу персонажей и предметов по всем этим фрагментам.

Правила:
- Заведи каждого названного в этих фрагментах человека, который появится в сценах, ОДНОЙ основной карточкой (одно имя на человека, без дублей под разными написаниями).
- Заведи сквозные роли, которые повторяются в этих фрагментах и будут говорить в диалогах (следователь, судья, прокурор, дежурный, эксперт, мать погибшей и т. п.) — одной карточкой на роль, если по тексту это может быть один и тот же человек.
- Если в этих фрагментах человек выглядит по-разному (другой возраст, форма, арест/заключение, больница, смерть, воспоминание), заведи вариации по правилам ниже.
- В поле `фрагменты` каждой карточки перечисли номера фрагментов, где эта версия появляется.

{{VARIATION_RULES}}

`предметы`: только важный предмет из фрагментов, который может перейти в другую сцену: `id` (p01…), `имя`, `описание`, `якорь`.

Верни один JSON-объект формы {"база_персонажей": [...], "предметы": [...]}.
