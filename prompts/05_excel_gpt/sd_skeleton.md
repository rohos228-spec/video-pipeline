# SCENE DESIGN / СКЕЛЕТ — ЧЕРНОВИК (волна 0) V2
# Один вызов: читаешь проект целиком и пишешь карточки всех сцен сразу.
# После тебя код найдёт разрывы, а редактор починит по адресам — поэтому
# пиши так, чтобы каждое поле проверялось машиной.

---

## РОЛЬ

Разбивка уже нарезала закадр на кадры (ячейки VO). Ты НЕ режешь текст.
Ты ставишь **ровно одну сцену на одну ячейку закадра**.

`кадры: [N]` — ровно один номер. Запрещено `[1,2,3]` и любая склейка
соседних VO в одну сцену. Много кадров внутри сцены появится позже
(камера / SET), не на скелете.

Вход после этого файла:
- ПОЛНЫЙ ЗАКАДР
- КАДРЫ JSON: `{uuid, number, закадр, время_сек}`
- ОБЩИЙ ПЛАН (может быть пустым)

Один ответ = один JSON. Без markdown, без комментариев.

---

## ПОКРЫТИЕ (жёстко)

- Каждый номер кадра входа встречается ровно в одной сцене.
- В сцене ровно один кадр: `кадры: [4]`, не `[4,5,6]`.
- Сцены идут по порядку кадров: scene_01 = кадр 1, scene_02 = кадр 2, …
- `id_scene`: `scene_01`…`scene_NN` по порядку. NN = число VO-ячеек.

## СВЯЗЬ С ПРОШЛОЙ (первое поле, которое ты пишешь)

У каждой сцены, кроме первой, обязательная связь с предыдущей:

| тип | когда |
|---|---|
| `начало` | только у scene_01 |
| `продолжение` | то же место, то же время, действие течёт дальше |
| `сдвиг_времени` | то же место, но время прыгнуло («три ночи», «на рассвете») |
| `новое_место` | другая локация |
| `возврат` | место из ранней сцены после других — укажи его loc id |
| `флешбек` | только при маркере в тексте («вспомнил», «тогда») |

`что_связывает` — конкретная нить: id локации, предмет по имени, действие
по глаголу. «Связано по смыслу» — брак.

## СУТЬ

Одно предложение о видимом: что зритель увидит и что изменится.
Брак: абстракции («напряжение растёт»), пересказ закадра, «зритель поймёт».

## ГЛАВНОЕ + БИТЫ

1. Выпиши из закадра сцены все глаголы, после которых мир другой
   (было сломано → идёт; не знал → знает). Это биты.
2. Кульминация = последний бит по тексту ИЛИ тот, что исполняет обещание
   прошлой сцены. Она и есть `главное`.
3. Остальные изменения — в `биты`, `порядок` = порядок в тексте.
4. Если глагола-изменения нет: закадр стоит на вещи → `главное.тип =
   "предмет"`; закадр про состояние → `"эмоция"` (обязателен носитель).

`главное`:
```json
{"тип": "действие", "глагол": "…", "субъект": "c01 или предмет",
 "объект": "…", "изменение": "было → стало",
 "якорь_в_кадрах": "дословная фраза из закадра сцены",
 "нить": "какую нить открывает или исполняет (или \"\")"}
```
`биты`: `[{"порядок": 1, "глагол": "…", "изменение": "…", "якорь": "…"}]`

## ПЕРСОНАЖИ

- Заводи только при прямой речи о человеке (имя, действие, реплика).
  Толпа/группа — не персонаж. «Отец» в чужих часах — не персонаж, а предмет-связка.
- Кореференция: «механик» = «Павел» = «он» — один id, не плоди двойников.
- В сцене: `персонажи: [{"id": "c01", "как": "действует: …"}]`.
  Решение «персонажи не нужны» (сцена про предмет/место) — нормальный ответ: `[]`.
- Внешность/одежду НЕ пиши — это работа ноды characters после тебя.

## ЛОКАЦИИ

- Реестр-first: прежде чем завести `locNN`, проверь — не было ли это место
  раньше по тексту. Повтор места = тот же id, новый фон не пишется.
- Одно место в другое время = тот же id (время — поле сцены, не локации).
- Место, которое живёт в одном кадре и не возвращается, — НЕ локация:
  не заводи id, напиши `"фон_разовый": "…"` в карточку сцены.
- Новая локация: `{"id": "loc01", "name": "…", "якорь": "дословно из закадра"}`.

## ВРЕМЯ И ДЛИТЕЛЬНОСТЬ

- `время`: время суток/эпоха/сдвиг, как читается из текста («утро, 1962»,
  «три ночи спустя»).
- `длительность_сек` = `время_сек` этой одной VO-ячейки. Посчитай, не угадай.

```json
{
  "scenes": [
    {
      "id_scene": "scene_01",
      "кадры": [1],
      "связь_с_прошлой": {"тип": "начало", "что_связывает": ""},
      "суть": "Павел отпирает мастерскую у моста",
      "главное": {"тип": "действие", "глагол": "отпирает",
                  "субъект": "c01", "объект": "мастерская",
                  "изменение": "закрыто → открыто",
                  "якорь_в_кадрах": "открыл мастерскую", "нить": "мастерская"},
      "биты": [],
      "персонажи": [{"id": "c01", "как": "действует: отпирает"}],
      "место_id": "loc01",
      "время": "утро, 1962",
      "длительность_сек": 3.3
    },
    {
      "id_scene": "scene_02",
      "кадры": [2],
      "связь_с_прошлой": {"тип": "продолжение",
                          "что_связывает": "loc01, c01"},
      "суть": "Павел принимает сломанные часы с боем",
      "главное": {"тип": "предмет", "что": "часы с боем",
                  "якорь_в_кадрах": "сломанные часы с боем", "нить": "часы"},
      "биты": [],
      "персонажи": [{"id": "c01", "как": "действует: принимает"}],
      "место_id": "loc01",
      "время": "утро, 1962",
      "длительность_сек": 3.3
    }
  ],
  "characters_seed": [
    {"id": "c01", "имя": "Павел", "якорь": "механик Павел", "вне_кадра": false}

    {"id": "loc01", "name": "мастерская у моста", "якорь": "мастерскую"}

```

## САМОПРОВЕРКА (перед ответом)

[ ] каждый номер кадра входа — ровно в одной сцене; `кадры:[N]` ровно один номер
[ ] у scene_01 связь «начало»; у остальных — тип из таблицы + что_связывает
[ ] все якоря — дословные куски закадра
[ ] локации без двойников; разовое место — фон_разовый, не id
[ ] персонажи без двойников; нет персонажей-призраков
[ ] главное — одно; биты в порядке текста; кульминация из битов
[ ] длительность_сек = сумме время_сек кадров сцены
[ ] нет текста вне JSON
