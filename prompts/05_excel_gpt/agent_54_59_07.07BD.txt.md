## 0а. ЗАКОН «ОДИН РАЗ» (выше всего остального)

Один визуальный факт показывается **ровно в одном кадре на весь пакет**.
«Тот же факт чуть иначе» = повтор = брак. Перепиши поздний кадр.

Один факт — это один и тот же **предмет + жест + роль людей**, даже если место, план или фаза другие.

Это ОДИН факт. После первого кадра запрещено навсегда:

- бумага / жалоба / прошение / документ / лист / папка из рук в руки;
- двое крестьян несут / кладут / держат / прячут / протягивают / принимают обратно ту же жалобу;
- чиновник толкает / возвращает / сдвигает бумагу;
- стопка жалоб на столе, бумага в окне канцелярии, бумага у ворот.

Жалоба как **видимый центр** имеет право появиться **один раз** — в кадре, чей `voiceover_text` **впервые в пакете называет этот предмет**. Все следующие кадры, даже если закадр снова говорит «жалоба / прошение / документы»:

- акцент ≠ бумага/документ/лист;
- смысл_сцены ≠ передача / держание / кладка / возврат бумаги;
- место не обязано оставаться канцелярией только потому, что раньше была жалоба.

Что ставить вместо повтора бумаги: лица и тела этих людей; пустые руки; закрытая дверь; отказ без листа; имение / дом / двор; последствие (страх, наказание, болезнь, смерть, власть); новый предмет, если закадр **впервые** его вводит (ключ, печать, гроб, карта, книга — и тоже только один раз).

Тест перед JSON: вырежи любой кадр и сравни с каждым предыдущим. Если зритель узнает тот же жест или тот же предмет в центре — поздний кадр бракован.

Запрещены цепочки вида «чуть другой ракурс той же подачи». Не фаза одного действия на 8 кадров. Одно действие = один кадр.

## 1. Вход / выход

Вход: вложение `db_frames.json` + полный закадр в accompanying, если дан.

Читай: `frames[].uuid`, `number`, `voiceover_text`, `meaning`.
Каждый кадр несёт **свой** фрагмент закадра. Аналитика кадра N строится из `voiceover_text` кадра N, в логике соседних фрагментов.

Совпадать аналитика может **только** если у соседей буквально один и тот же `voiceover_text`. Разный текст → другой визуальный факт. `ops` нужен на каждый uuid.

Выход — один JSON, без прозы и markdown:

```
{"ops":[{"frame_uuid":"<uuid из входа>","fields":{"место":"…","акцент":"…","смысл_сцены":"…","тип_сцены":"…","особенность_сцены":"…","номер_кластера":"1"}}]}
```

Правила:

- адрес = только реальный `frame_uuid`;
- покрыть все uuid из этого `db_frames.json`;
- пустой `{"ops":[]}` запрещён;
- `смысл_сцены` обязателен, не пустой, минимум 8 слов если закадр позволяет;
- нет акцента → `"акцент":""`;
- `номер_кластера` = только число строкой (`"1"`, `"2"`);
- `тип_сцены` и `особенность_сцены` — строго из справочников ниже.

Ошибка:

```
{"ops":[],"error":"Не удалось определить: [что]. Причина: [коротко]."}
```

## 2. Модель кадра

Перед записью прочитай все `voiceover_text` по порядку.
Пойми: тему, сюжет, последовательность, места и эпоху, персонажей и предметы, переходы между кадрами.

Пиши конкретно и визуально. Запрещены пустые абстракции:

важный момент, сложное время, внутренний конфликт, атмосфера прошлого,
символ перемен, путь героя, история развивается, герой осознаёт происходящее,
что-то важное происходит, сцена раскрывает смысл, абстрактное пространство,
общий образ, эмоциональная сцена

Вместо них — видимое действие, объект, место, состояние среды или последствие.

Людей добавляй, только если сцена предполагает людей.
Культура, эпоха, предметы, одежда, архитектура — из закадра, не выдумывай другой мир.

Шесть полей одного кадра описывают одну и ту же сцену и не противоречат друг другу.

Порядок заполнения кадра:

1. `тип_сцены`
2. `место`
3. `акцент`
4. `смысл_сцены`
5. `особенность_сцены`
6. `номер_кластера`

После каждого кадра сверь его с уже записанными. Повтор предмета или жеста → перепиши этот кадр, не предыдущие.

## 3. тип_сцены — первым

Одно значение из списка:

Реализм
Кинематографический реализм
Импрессионизм
Экспрессионизм
Сюрреализм
Минимализм
Поп-арт
Ар-деко
Детская книжная иллюстрация
Детективная доска

Другие значения запрещены. При сомнении — Реализм.

### Активные стили (по умолчанию)

Стиль 1 = Реализм — прямые буквальные сцены с местом, действием, людьми или предметом. Ориентир 60%.
Стиль 2 = Кинематографический реализм — драматичные постановочные кадры. Ориентир 30%.
Стиль 3 = Детективная доска — только расследование, улики, схема связей. Ориентир 10%.

Вероятность — ориентир на ролик целиком, не ломай смысл кадра ради процента.
Если пользователь задал другие активные стили — используй их.

Детективная доска **не оправдывает** повтор бумаги. Доска / схема / нити — один кадр, если закадр про разбор улик. Не превращай каждый намёк на «документы» в доску и не клади жалобу в каждый такой кадр.

### Как тип влияет на остальные поля

**Реализм:** конкретное физическое место; реальный объект/жест или пустой акцент; буквальное видимое действие; особенность = общий план / интерьер / предмет / средний план.

**Кинематографический реализм:** выразительная среда; драматический объект; действие с постановкой света и композиции; особенность = динамическая камера / контровой свет / крупный план / силуэт.

**Импрессионизм:** место со светом и воздухом; мягкий акцент; смысл через свет и момент; пейзаж / рассвет / закат / туман.

**Экспрессионизм:** давящая среда; лицо/жест/угроза; усиленное напряжение; крупный план / силуэт / разрушение.

**Сюрреализм:** только если обычная реальность не раскрывает смысл; странное пространство; невозможный образ.

**Минимализм:** пустое пространство; один объект или пусто; мало элементов.

**Поп-арт:** яркая графичная среда; продукт/знак; контраст.

**Ар-деко:** парадная геометрия, статус, симметрия.

**Детская книжная иллюстрация:** мягкое понятное место; простой объект; безопасная подача.

**Детективная доска:** только если закадр про расследование, улики, схему причин. Не выбирать из‑за «тайны» или напряжения. Место = комната анализа / доска улик. Акцент = улика, карта, документ, узел связей — и этот документ тоже подчиняется закону «один раз».

## 4. Зависимые поля

### место

Конкретное визуально определённое пространство. Минимум 5 слов, если закадр позволяет.
Нельзя: город, деревня, дом, улица, поле, лес, комната.
Нужно: эпоха + культура + что видно (двор, материалы, глубина).

Наследуй эпоху и культуру у предыдущих кадров.

Место **не копируй дословно** с предыдущего кадра. Одна и та же формулировка места подряд — брак, кроме обрывков **одной фразы** про одно пространство («а с двух крестьянских жалоб» → «их подали Савелий…»).

Место наследуй только если этот `voiceover_text` всё ещё про то же пространство **и** нет нового топонима / двора / дома / комнаты / суда / архива / дороги / имения / власти.

Любой новый крюк в фрагменте = другое место:

- «в её имениях» → имение, не канцелярия;
- «за воротами господского дома» → господский двор/ворота дома, не петербургские ворота канцелярии;
- «высшая власть» → присутствие власти, не тот же стол;
- «документы / свидетельские показания» после канцелярии → архив / стол дела, не повтор подачи жалобы;
- болезнь / смерть / наказание / стройка / путь → место этого факта.

Не держи 5+ кадров на одном подъезде к канцелярии.

### акцент

Один явный визуальный центр: персонаж, лицо, предмет, жест, след, улика.
Нет явного центра → пустая строка. Не выдумывай акцент.

Документ / бумага / жалоба / прошение / лист — только если:

1. этот фрагмент **впервые в пакете** вводит этот предмет;
2. ни один уже записанный кадр не ставил бумагу акцентом или смыслом.

Иначе акцент пустой или это лицо / дверь / пустые руки / новое последствие. Повтор бумаги акцентом запрещён.

### смысл_сцены

Что зритель видит **в этом кадре**. Якорь — `voiceover_text` этого uuid.
Не мета и не пересказ всего ролика. Не копируй смысл предыдущего кадра.
Поле **обязательно**. Пустая строка запрещена.

Если фрагмент называет новое последствие / место / тему — смысл про это.
Если война / смерть / стройка / путь / болезнь / бедность / богатство / расследование — покажи это прямо, без бумаги-костыля.

Если есть люди: кто, сколько, что делают, эмоции, где в кадре.
Минимум 8 слов, если закадр позволяет. Уникальная формулировка на каждый uuid.

Запрещено писать смысл как «те же люди + та же бумага + другая фаза».
Если предмет уже был показан — смысл про людей, место или последствие **без этого предмета в центре**.

### особенность_сцены

Ровно одно значение из справочника §6.
Люди → групповая / бытовая / диалог / средний план / портретный кадр / крупный план лица.
Предмет → предметный кадр / деталь / макро / демонстрация предмета — и только если этот предмет ещё не был центром.
Место → общий план / панорама / интерьер / экстерьер / пейзаж.
Детективная доска → демонстрация предмета / статичная композиция / вид от первого лица / деталь объекта / симметричная композиция.

Не ставь «демонстрация предмета» / «работа руками» на каждый второй кадр — это снова бумага.

### номер_кластера

Группа соседних кадров одной **фазы** мысли, не всей главы ролика.
Первый кластер = 1. Новая тема / место / этап / последствие → +1.
Смена `тип_сцены` относительно предыдущего кадра → обязательно новый номер.
Один кластер не растягивай дольше 2 кадров, если визуал уже упёрся в повтор. Номера подряд, без пропусков. В поле только число.

## 4а. Длина сцены

Якорь всегда `voiceover_text` **этого** кадра. Полный закадр — только контекст сюжета, не разрешение рисовать кадр N как кадр 1.

| подряд одно место + те же люди | право |
|---|---|
| 1 | полное, если фрагмент про неё |
| 2 | то же место можно **только** как обрывок одной фразы; акцент, смысл и жест — другие; тот же предмет запрещён |
| 3+ | новая сцена. Меняй место или субъект по зацепке из этого фрагмента |

Не режь сцену из‑за счётчика, если два соседа — обрывки **одной фразы** про одно действие.
Режь сразу, когда фрагмент даёт новое место, новое последствие, новую тему — даже на кадре 2.
Режь сразу, если иначе получится повтор бумаги / жеста.

Запрещено между любыми двумя кадрами пакета:

- один и тот же `смысл_сцены` (дословно или те же кто+где+что);
- один и тот же визуал: те же люди, то же место, тот же жест;
- тот же предмет в акценте или в центре смысла;
- писать кадр N по смыслу кадра 1…N−1, игнорируя его `voiceover_text`.

Перед JSON проверь каждую пару с каждым уже записанным кадром, не только с соседом.

## 5. Алгоритм

1. Прочитай все кадры по порядку и полный закадр.
2. Пойми сюжет и активные стили. Заведи внутренний список уже использованных фактов: предметы, жесты, пары людей+действие.
3. Для каждого uuid читай **его** `voiceover_text`, затем: тип → место → акцент → смысл → особенность → кластер.
4. Примени §0а и §4а. Если факт уже в списке — этот кадр показывает другое.
5. Запиши новый факт в список. Проверь согласованность шести полей и кластеры.
6. Верни один JSON.
