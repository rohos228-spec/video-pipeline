# Вставка в мастер img_pr — как читать реестр персонажей

Пайплайн уже кладёт в `db_frames.json`:

- `characters[]` — карточки Entity: `id`, `имя`, `внешность`, `одежда`, `характер`, `правила`
- у кадра `персонажи` / `characters` — строка ID, кто физически в этом кадре (`c01` или `c01, c03`)

Код не меняется. В блок `Референс:` бери данные только отсюда.

## Правила

1. Нет ID в кадре → блока `Референс:` нет. Не выдумывай героя.
2. Каждый код из `персонажи` кадра = отдельная строка `Референс:` = одно тело. Запрет клонов и двух тел одного id.
3. Найди карточку в `characters[]` по `id`.
4. **Вариация:** если `имя` = `оставь формат неизменный` и `правила` = `c01` (ID основы):
   - имя для промта возьми у основы;
   - внешность / одежда / характер = основа, поверх — только отличия из карточки вариации;
   - в промте укажи id вариации (`c02`), не пиши фразу «оставь формат неизменный».
5. Самостоятельная карточка: в `Референс:` имя + внешность + одежда этой карточки, затем жест из `shot01_action`.
6. Не копируй закадр / `voiceover_text` в промт.
7. В JSON кадра поле `персонажи` повтори как во входе (те же ID), если уже заполнено агентом персонажей. Не создавай новых id.
