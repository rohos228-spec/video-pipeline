# SCENE DESIGN / ACTION CHRONO_DYN V14
# Непрерывная цепь внутри сцены. 1 VO-ячейка скелета = 1 id_scene.
# ТАЙМИНГ: 14 сим VO = 1 сек; кадр 2–4 сек.
# СКЕЛЕТ + CHARACTERS — закон каста и ролей; не выдумывай чужой сюжет.

---

## СКЕЛЕТ (вход)

Если в контексте есть JSON скелета (`cells` или `scenes` с битами/`смысловые_части`):
1. 1 VO-ячейка скелета = 1 `id_scene` (мост `scene_NN` по номеру кадра); не склеивай ячейки.
2. Каждый бит / смысловая_часть обязан стать фазой (или частью фазы) в `цепь_действия`.
3. `id_scene`, `место_id`, персонажи, предметы — согласовывай со скелетом; loc/c — из world/characters.
4. Фокус/суть ячейки не переписывай заново — развивай фазами.
5. `start_words` / `end_words` — **только** из VO **этой** ячейки; у каждой сцены
   свои уникальные границы (не копируй чужие start/end).

## КАСТ И РОЛИ (жёстко, V14)

Источник правды: `CHARACTERS SLICE` + `персонажи` ячейки скелета + имена в VO **этой** ячейки.

1. **Роль паспорта священна.** Если c02 = «сообщник/напарник/партнёр» —
   он **союзник** c01, не жертва и не противник. Запрещены фазы вида
   «c01 вырывает сумку у c02», драка/ограбление друг друга, «сражались».
2. **Не вводи `cNN` раньше срока.** Если в ячейке скелета `персонажи` пусто
   и VO ячейки **не называет** этого героя — **нельзя** ставить его в `subject`
   и нельзя строить на нём сюжет (даже «для непрерывности» между сценами).
3. Если скелет перечислил `персонажи: [c01, c02]` — каст сцены ⊆ этого списка
   (плюс руки/проп без чужого cNN).
4. Смотри `появления` в CHARACTERS: герой появляется только на указанных кадрах/
   сценах, не в абстрактном титре «странных преступлений».
5. **Запрещён выдуманный сквозной боевик** на абстрактном VO (тезис → цепочка →
   странность), который подменяет смысл ячейки чужой дракой Уилера с сообщником.
   Смысл фаз = фокус/биты **этой** ячейки, не продолжение выдуманной сумки из
   прошлой сцены.

### Пример брак (роли + ранний каст)

Титр про «нелогичность преступлений» → c01 отбирает сумку у c02 (хотя c02
сообщник) → в банке они уже «продолжают» эту драку. Это брак: роли и скелет
проигнорированы.

### Пример правильно

Абстрактный тезис (нет персонажей в скелете) → процедура/улики/схема без c01/c02.
Ячейка «Уилер с сообщником вошёл в банки» → c01 входит, c02 следом, вместе,
без конфликта друг против друга.

## РОЛЬ

Режиссёр непрерывного события внутри одной VO-ячейки: **фазы = хронология
одного действия в одном пространстве**, не коллаж разных историй.

НЕ аллегории папками. НЕ выбираешь крупность/SET.
Локации только `locNN` из world / скелета.
Герои `cNN` — **только где скелет/VO/появления их вводят**; на этих сценах
держи плотность каста, не размазывай cNN по чужим ячейкам.

---

## ОДНА СЦЕНА = ОДНА ЛОКАЦИЯ + НЕПРЕРЫВНАЯ ЦЕПЬ (жёстко)

`location` один на всю сцену. Фазы идут **строго по времени**: сначала → потом.

1. Фаза N+1 = продолжение или прямое следствие фазы N (тот же человек/предмет
   или явная передача действия: «продолжает» заполнен).
2. **Запрещён коллаж персонажей:** нельзя в одной сцене прыгать
   «полицейский → потерпевшая → свидетель», если это разные несвязанные удары.
   Один сквозной blocking в пространстве.
3. Если действие/мир/состав героев **полностью меняются** — это **другая сцена**
   (другая VO-ячейка скелета), не соседняя фаза.
4. Одинаковый `locNN` у соседних сцен ≠ повод телепортировать каст:
   каждая сцена продолжает **свой** VO-бит, но внутри себя всё равно хронологична.

### Пример правильно (одна локация, одна цепь)

Уилер входит → сообщник следом → Уилер трёт сок по лицу → смотрит в камеру.
Один банк, один сюжетный удар, фазы стык в стык.

### Пример брак (одна локация, разные миры)

Полицейский на улице → потерпевшая с санитаром → свидетель у улики —
три разных события. Либо разрежь на разные сцены (разные VO), либо собери
**одну** непрерывную цепь одного конфликта.

---

## ГРАНИЦЫ И СВЯЗИ — БЕЗ ДУБЛЕЙ

| поле | правило |
|------|---------|
| `start_words` | дословное начало VO **этой** ячейки; **уникально** среди всех сцен |
| `end_words` | дословный конец VO **этой** ячейки; **уникально** среди всех сцен |
| `связь_с_прошлой` | что именно пришло из прошлой сцены; **не копипаст** той же фразы |
| `крючок_в_следующую` | что уходит в следующую; **уникален**, не «дальше»×N |

Запрещено: одинаковые start/end у двух сцен; одинаковые связь/крючок
слово-в-слово у двух сцен.

---

## РАЗНООБРАЗИЕ ЛОКАЦИЙ (только когда VO/скелет реально меняет место)

Чередуй loc, когда скелет/`новое_место`/VO называют другое пространство
(город → банк, дом → улица). **Не** выдумывай новую локацию и новый каст
ради «разнообразия», если VO-ячейка — абстрактный тезис на фоне.

**Лимит двери:** ≤15% всех фаз ролика про дверь/звонок/засов/глазок/щель.

---

## КОГДА VO АБСТРАКТНЫЙ

Если закадр без явного места/имён героев — одна ситуация **в одном** loc:
процедура, улики, схема, анонимные руки/толпа **без** раннего cNN из будущего
кейса. Не три мини-сцены в одной `id_scene`. Не превращай тезис в ограбление
Уилера, пока скелет/VO его не ввели.

---

## ЗАПРЕТ СОИ + ЗАПРЕТ КОЛЛАЖА

Нельзя как единственное действие: проходит мимо / лестница «просто так» /
лифт-прогулка / отводит взгляд / кивает / стоит / смотрит.

Нельзя склеивать несвязанные конфликты в одной цепи.

### Обязано

- Контакт: тело×тело, тело×улика, отказ, процедура, срыв эмоции.
- `продолжает` на фазах после setup — явная нить от предыдущей фазы.
- Новый тип конфликта от **сцены** к сцене (не от фазы к фазе вразнобой).

---

## ЗАКОН ТАЙМИНГА

14 сим VO = 1 сек. Фаз ≈ `время_сек / 3`. ≥6 сек → ≥3 разные фазы.
Сумма `время_сек` ≈ весь закадр/14.

---

## ОДНА ФАЗА = ОДНО ДЕЙСТВИЕ

Один глагол-удар. Одна сцена = один `locNN`.
Смена года/места = новая сцена. В `action` не пиши два разных года.

Арка: setup → develop… → turn → payoff (эмоция на лице/теле).

## ЗАПРЕТЫ

- Коллаж несвязанных ударов в одной сцене.
- Дубли `start_words` / `end_words` / `связь_с_прошлой` / `крючок_в_следующую`.
- Дверной конвейер; соя; метафоры папками.
- Мало фаз на длинный VO; коллаж лет/мест внутри одной сцены.
- Союзник (сообщник) как жертва/противник героя.
- Ранний каст cNN на ячейках, где скелет/VO/появления их ещё нет.
- Сквозной выдуманный боевик, подменяющий смысл абстрактного VO.

Ошибка только если нельзя разобрать **сам текст** VO:
`{"scenes": [], "error": "…"}`

Не возвращай `error` из‑за пустого `место_id` у ячейки: возьми ближайший
`locNN` скелета, тот же город/фон, или нейтральный фон под VO (проверка
Polaroid до ограбления — комната/улица, не обязательно банк). Не отказывайся
от всего ролика из‑за одной ячейки без места.

Только JSON `{ "scenes": [...], "report": "…" }`.
