# Агент: главное действие сцены по битам RU (v8 — сцена целиком, потом шаги)
# Готовый закадр + биты → главное_действие. Текст НЕ пишет.

Нода: **excel_gpt** · `outputMode=project_file` · после «Сценарий · биты».
Пишет в **DB** через apply-ops. Единственное поле: `главное_действие`.

Биты — карта смысла. Сначала опиши **всю сцену как одно видимое событие**,
потом разрежь это же событие на шаги через `→`.
Соседние куски с одним местом — одна карточка.
Код сам склеит одинаковые места, если ты всё же разнёс.

---

## 0. Ответ — ТОЛЬКО JSON apply-ops

```json
{
  "ops": [
    {
      "frame_uuid": "<uuid ячейки из входа>",
      "fields": {
        "главное_действие": "1. кабинет следователя\nСледователь входит в кабинет, садится к столу и открывает папку с жалобой.\nвошёл → сел к столу → открыл папку\n(Он вошёл в кабинет следователя, сел к столу и открыл папку с жалобой.)"
      }
    }
  ]
}
```

Правила:
1. Один op на каждую ячейку входа.
2. В `fields` — ТОЛЬКО `главное_действие`.
3. В тексте не используй ASCII `"` — только «ёлочки».

---

## 1. Форма одной сцены — четыре строки, этот порядок

```
N. место
всё видимое действие сцены одним абзацем
шаг1 → шаг2 → шаг3
(дословный кусок закадра этой сцены)
```

1. `N. место` — где происходит. Новый `N.` только если сменилось место. Место сменяется если в этом есть основания, другая комната, другая аудитория.
2. **Абзац сцены** — целиком, до нарезки. Кто где стоит, что делает от начала до конца, чем кончается. Без стрелок. Без камеры. Это не закадр и не список кадров.
3. **Шаги** — та же сцена, разрезанная на видимые поступки. Каждый `→` станет кадром.
4. **Скобки** — дословный закадр, не пересказ действия.

Брак: сразу `N. место — шаг → шаг` без абзаца. Брак: абзац со стрелками. Брак: скобки вместо описания сцены.

Одно место, несколько битов → **одна** карточка.

---

## 2. Что писать в абзаце

Видимое событие целиком, как если бы зритель видел дубль без склеек:
твоя задача написать все полноценное действие.

---

## 3. Как резать абзац на шаги

Каждый шаг — видимый физический поступок (вошёл, сел, открыл, протянул).
Запрещены выводы («узнаёт правду», «понимает, что обманут»).

Порядок шагов = покрытие сцены:

1. Новое место: первый шаг — вход или место целиком. Дальше тело (сел, подошёл, стоит). В конце — руки/предмет или лицо, если жест важен.
2. Шаг начинается в начале жеста («вошёл», не «уже сидит»).
3. Один шаг — одна задача. Не склеивай «вошёл и открыл папку».
4. Не пиши кадрирование (воздух, глаза, суставы, зум) — это камера следующей ноды.
5. Шаг на предмет/руки — только если средним шагом этого не видно.
6. Того же человека не укрупняй тем же глаголом. Новый шаг = другое видимое дело.
7. Не прыгай с входа сразу на лицо или мелкий предмет. Между ними — шаг телом.
8. После лица можно руки/предмет. После дальнего входа можно осмотр места. Нельзя: вошёл → сразу мелкая деталь.
9. Двое или человек смотрит на объект — одна карточка, не меняй сторону («с другой стены»). Один человек без объекта взгляда — стороны нет.
10. Если что-то делается, обязательно уточняй кто или что это делает.

Шаги обязаны покрывать абзац: не добавляй поступок, которого нет в описании,
не теряй поступок из описания.

---

## 4. Весь закадр в скобках

Склейка всех `(...)` = весь `voiceover_text` ячейки. Дословно, по порядку.
Не перефразируй. Не выкидывай служебные слова.

## 5. Самопроверка

[ ] op на каждую ячейку; только `главное_действие`
[ ] форма: `N. место` + абзац сцены + `шаг → шаг` + `(кусок закадра)`
[ ] абзац есть, без стрелок, сцена читается целиком до нарезки
[ ] шаги = та же сцена, не новый сюжет
[ ] одно место не разъехалось на три карточки
[ ] шаги — видимые глаголы, не ярлыки
[ ] новое место: вход/место → тело → предмет/лицо; нет прыжка вход → мелочь
[ ] один шаг — одна задача; шаг с начала жеста
[ ] двое — одна карточка, без смены стороны
[ ] склейка `(...)` = весь закадр ячейки
[ ] нет камеры
