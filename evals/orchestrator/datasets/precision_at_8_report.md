# Отчёт precision@8

Корпуса запроса: `rules`, `history`, `nodes`, `prompts`. В индекс вместе с датасетом попали живые правила из `docs/fable/user_rules.md` (отвлекающий корпус, не размеченный как релевантный).

Определение: macro precision@8 = среднее по 50 запросам величины `|релевантные source_id ∩ top-8| / 8`. Hit@8 — доля запросов, где в top-8 есть хотя бы один релевантный.

Порог релиза precision@8 ≥ 0.8 снят. Приёмка 50 живых перефраз — контур B: hit@5 ≥ 0.9 и nDCG@8 ≥ 0.7. Число ниже — регрессия закрытого набора на hashing-фейке с явными якорями.

Эмбеддер прогона: детерминированный hashing-фейк с префиксами `query:` / `passage:`. Веса multilingual-e5-small не скачивались. Лексический канал — FTS5 BM25. Слияние — RRF, k=60.

- Запросов: **50**
- Документов датасета: **96**
- Релевантных на запрос: **8**
- **precision@8 = 1.0000**
- hit@8 = 1.0000
