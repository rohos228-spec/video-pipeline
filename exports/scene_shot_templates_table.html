Слоты: {место} {A} {B} {предмет} {кто} {откуда} {куда} — подставляешь под конкретный ролик. Не оставляй {} в ответе.
Одно действие на кадр. Два жеста = два кадра.
Кадры сцены — причинная цепь: каждый следующий кадр продолжает предыдущий (подошёл → заговорил → пишет), а не набор открыток.
Текст короткий — выкидывай кадры с конца лестницы (drop_order / варианты сжатия). Первый ОБЩИЙ нового места не выкидывай.
required=1 не выкидывай никогда.
Один и тот же T* на РАЗНЫХ местах — норма (биография T8>T8>T8). На ТОМ ЖЕ месте новый ОБЩИЙ не ставь — бери вариант сжатия «место уже было».
У каждого кадра свой дословный кусок закадра. Пустой закадр запрещён.
Иди по вопросам сверху вниз. Первое «да» → шаблон. Остальные не смотри.
T3 — это «ТОЛЬКО смена места». Если в сцене двое говорят / руки работают / смысл во взгляде / идёт из A в B / удар — это НЕ T3, а T1/T5/T4/T6/T7.
T5 — только ДЛИТЕЛЬНАЯ работа руками (процесс). «Передают прошение» — T1 (двое). «Раскрывает и читает жалобу» — T2 (предмет). «Указывает на дом» — T4 (объект). Один жест руками ≠ T5.
Один и тот же T* три и больше раз подряд — СТОП: прогони дерево заново для каждой такой сцены. Часть из них почти всегда T1/T2/T4/T7, а не повтор.
«То же место, что у прошлой сцены» НЕ меняет шаблон — меняет сжатие: бери вариант «место уже было» (без нового ОБЩЕГО).
X1/X2 — только стык двух ЯЧЕЕК закадра. Сцены внутри одной ячейки на том же месте — это сжатие (T1-c2, T2-c3, T5 без K0…), не X1.
T7 — не реплика в текущем диалоге: реплика в диалоге = хвост T1 (K4–K5), не отдельная сцена.
T8 = один ОБЩИЙ на один новый мир/жизнь. Семь действий в одном кабинете — не T8, а T5/T4/T2/T9/T1.
Эталонная цепь «заявление_о_краже»
закадрМихаил пришёл к отделению полиции, зашёл внутрь, рассказал дежурному о краже и написал заявление.
1. улица — Михаил идёт к зданию полиции → T6 (путь A→B); короткий переход → T6-c2: ОБЩИЙ улица, вышел + ОБЩИЙ отделение, подходит к крыльцу
2. отделение полиции — заходит внутрь → T3 (только смена места): ОБЩИЙ холл отделения + СРЕДНИЙ входит, снимает кепку
3. отделение полиции — общается с дежурным полицейским → T1 (двое говорят); место уже было → T1-c2: СРЕДНИЙ с плеча Михаил + СРЕДНИЙ с плеча дежурный, без нового ОБЩЕГО
4. отделение полиции — пишет заявление о краже → T5 (руки работают); место знакомо → без K0: СРЕДНИЙ пишет + ДЕТАЛЬ рука и заявление
Каждая сцена — следующий шаг того же действия. Место сцен 2–4 одно → один ОБЩИЙ (у T3), дальше только сжатие. Шаблоны разные, потому что РАЗНЫЕ ответы на дерево вопросов, а не ради разнообразия.

ДОЧЕРНИЕ КАДРЫ — когда используются
Дочерний кадр = у кадра есть parent_id (по таблице T/X): он генерируется из PNG родителя (тот же сетап, другая камера), а не с нуля.
Дочерние: то же место + другая крупность/ракурс того же действия; крупный того же лица/предмета (punch-in, тот же экземпляр); путь в том же здании; X1 и сжатие «место уже было» (parent = master локации из прошлой сцены/ячейки).
НЕ дочерние (parent_id = null, генерация с нуля): новое место / первый кадр сетапа; прибытие в {куда} после пути (T6-K3); монтаж мест (T8 — каждый); объект взгляда вне сетапа (T4-K2 в другом месте); X2 (два мира — два master).
У дочернего кадра тот же состав, что у родителя: не добавляй людей, не подменяй предмет, тот же свет. Меняются только камера и действие этого кадра.
Каждый дочерний несёт свой дословный кусок закадра сцены (или пустой — покрытие без нового текста, если клауз меньше, чем кадров).
