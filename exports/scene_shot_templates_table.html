Шаблоны сцена → кадры

Как читать id:
T = тип сцены (T1 диалог, T2 находка…)
K = кадр внутри типа (T1-K2 = 2-й кадр диалога)
X1/X2 = связь между соседними ячейками закадра
Сначала открой README и rules_ai — там словами для ИИ, без «буквы V».

README

вопросответ
Что этоСправочник схем: какая сцена → какие кадры снять. Для ИИ-агента: выбрать шаблон, заполнить слоты {}, выписать кадры.
Буква TT = тип сцены (template). T0, T1, T2… — номера типов. Не кадры, а схемы.
Буква XX = хвост между ячейками закадра. X1 = следующее действие в том же месте. X2 = следующее действие в другом месте.
Буква KK = кадр внутри шаблона. T1-K2 = второй кадр схемы «диалог».
Цифра в TНомер типа сцены. Больше номер ≠ важнее. Просто id.
Цифра в KПорядок кадра внутри схемы: K1 первый, K2 второй…
Как агент работает1) По листу select выбрать template_id. 2) Взять строки shots с этим template_id. 3) Подставить слоты. 4) Если текст короткий — удалить кадры по drop_order, но не трогать required=1.
Лист READMEЭто объяснение. Читать первым.
Лист rules_aiПравила оси/parent/сжатия языком команд для ИИ. Без метафор.
Лист templatesСписок типов сцен.
Лист shotsКаждый кадр каждой схемы — одна строка. Главный рабочий лист.
Лист selectПорядок вопросов: первое совпадение → шаблон.
Лист chainsКак склеивать шаблоны подряд в ролике.
Лист enumsРазрешённые значения полей. Другие писать нельзя.

rules_ai

темазначениекак понятькоманда_для_ии
axisнетНе проверять стороны персонажей. Подходит для одного человека, пути, монтажа мест.Ничего не делать с сторонами.
axiskeep_sidesВ сцене двое. В первом кадре где оба видны, зафиксируй: кто слева кадра, кто справа. Во всех следующих кадрах этой сцены эти стороны НЕ менять.ЗАПРЕЩЕНО: в одном кадре {A} смотрит вправо, а в следующем кадре той же сцены {A} смотрит влево без смены места. ЗАПРЕЩЕНО: поставить камеру так, будто герои поменялись местами.
axislook_chainСначала кадр того кто смотрит, потом кадр того НА ЧТО он смотрит, потом кадр реакции ТОГО ЖЕ человека.ЗАПРЕЩЕНО: реакция другого человека вместо смотрящего. ЗАПРЕЩЕНО: прыжок лицо→лицо без кадра объекта взгляда, если смысл именно во взгляде.
parentnullКадр самостоятельный. Новое место или новая сторона диалога или новый объект.В выходном JSON parent_id = null.
parentmasterКадр продолжает первое место этой схемы. Parent = shot_id первого кадра этой локации в ячейке.В выходном JSON parent_id = id master-кадра места.
parentside_of_faceКрупный лица продолжает сторону того же человека (его предыдущий средний/плечо).parent_id = shot_id последнего кадра этого же who в этой сцене.
parentprev_location_masterЯчейка новая, место то же что в прошлой ячейке.parent_id = id первого кадра этой локации из предыдущей ячейки. Новый ОБЩИЙ не создавать.
parentT4-K1Жёсткая ссылка на конкретный shot_id схемы.parent_id = id кадра, который получился из T4-K1 после подстановки.
compressdrop_orderЕсли суммарный закадр слишком короткий для всех кадров — удаляй shot_id из drop_order по порядку.ОСТАНОВИСЬ, если остались только required=1. Не удаляй required=1. Не удаляй единственный кадр нового места, если when требует новое_место.
slots{}Всё в фигурных скобках надо заменить конкретными словами из входа.Не оставляй {место} в ответе. Не выдумывай структуру кадров — только подставляй значения в готовые строки shots.
selectfirst_matchИди по select сверху вниз. Первое истинное if → бери then_template. Остальные не смотри.Если ничего не совпало → T0.
